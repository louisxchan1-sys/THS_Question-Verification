# THS 題目驗證清單（六維｜內容導向）
> 驗證任何工作紙／小測／模擬卷時逐項對照｜只驗證題目與答案內容，不驗證排版格式｜更新：2026-09-26

**驗證心法：每一維的判準都是「與最新三年公開試相比」，不是抽象的「良好標準」。** 每維度評 ◎佳／○合格／✗不合格，並記錄具體問題（註明題號）。

## 範本依據

高品質題目／答案的範本＝`參考資料/公開試/` 內**最新三年**、對應類別（MC／DBQ／LQ）的公開試真題及官方答案，驗證時須直接對照比較，非只憑規格摘要判斷。現況年度對照見 `考評標準/範本對照表.md`。

## A. 規格與分值合規（對照現行制卷式）

- [ ] 題型規格符合對應標準（考評標準/MC_出題規格／DBQ_出題規格／LQ_出題規格）
- [ ] 分值結構正確（DBQ 每題 10 分；LQ 18+2；分題加總無誤）
- [ ] 指令動詞與分值對應（「以兩項例證」=2 分；LQ 點數=分值÷2）
- [ ] DBQ 資料 100–400 字含非文字元素；LQ 背景 50–80 字（上限 90 字，不計標點；逐題點算並在報告列出字數）
- [ ] MC 組合題陳述邏輯獨立成立、選項組合無歧義；題型比例對標最新一年（見 MC_出題規格 §2.2，逐題核對組合題是否純正新格式）

## B. 知識準確性（對照 參考資料/課本資料/）

- [ ] 理論框架元素及名詞與課本一致（正式譯名）
- [ ] 機構名稱、職能正確；真實景點／地理資料準確
- [ ] 數據、時事資料為最新（旅監局 2019 後已成立等）
- [ ] 無超綱內容（對照課程綱要）
- [ ] 工作紙自報的章節／課題編號與課本實際章節相符（**須實際翻開課本對應檔案核對標題，不可只信工作紙自報**）
- [ ] 表格內容完整，無因 md→docx 轉檔遺漏欄位（屬內容完整性問題；如有缺漏，核對同名 .md 源檔）

## C. 題目質素與公開試貼題度（對照最新三年公開試同類題）

- [ ] 題幹清晰無歧義、單一最佳答案成立
- [ ] MC 誘答項基於真實誤解、長度語法平衡、答案分布平均
- [ ] DBQ 設問與資料扣連（非脫離資料的背誦題）
- [ ] 情境真實、貼近最新三年 DSE 風格（具名人物、具體數字、香港/亞太案例優先）
- [ ] 措辭句式貼近公開試慣例（指令動詞、「以下何者」「最適當」等用語、負面題否定詞加粗）
- [ ] 無重複考點；題與題之間有區分度
- [ ] 逐題自問「這題放入最新三年公開試會否違和」——違和者記錄原因（考點過時／風格過舊／設問方式公開試不用）

## D. 參考答案與評分準則（對照 評分準則撰寫標準.md；給分邏輯比照最新三年公開試評卷參考）

- [ ] 按點給分、每點標 (1)、點數=分值
- [ ] 點＋例證分離；例證源自資料
- [ ] 「任何 X 項」答案池充足、點不重疊
- [ ] 答案正確（知識上站得住腳）
- [ ] MC 逐題題解齊備（每題說明答案及各選項對錯原因）
- [ ] 可直接供 AI／同儕批改
- [ ] 逐題標註只有「難度｜參考DSE題目」兩項（格式見 評分準則撰寫標準.md 二.6）；不得有錯點、目標誤解、資料立足點、誤解來源、易混提示
- [ ] LQ 答案要點以有框線表格列出（要點｜概念（1 分）｜應用（1 分）），不是段落列點

## E. 難度校準與認知層次（核心維度｜對照最新三年公開試＋考生表現）

> 本維度是判斷題目是否貼近公開試水平的**關鍵維度**。驗證時須翻查 `參考資料/公開試/07_考生表現/` 最新可用年份的逐題答對率／表現評語作為校準基準；各題型的具體難度基準見對應出題規格的「難度錨點」一節。

### E1. 逐題難度分級（附公開試錨題）
- [ ] 每題歸類為三級之一（驗證報告須列出分級結果）：
  - **基礎**（對應公開試答對率 ≥70%）：直接記憶、定義辨識、簡單配對、單一概念指出
  - **中等**（對應答對率 40–69%）：情境應用、概念區分、簡單推理、點＋例證
  - **挑戰**（對應答對率 <40%）：跨概念整合、多步驟推理、分析評鑑、易混框架辨析
- [ ] 分級基於認知要求判斷，不可僅憑直覺；有疑問時對照公開試同類題的考生表現
- [ ] **錨題要求**：凡評為「挑戰」的題目，必須引一道公開試錨題（年份＋題號＋相似點；修訂版評卷參考內標作「參考DSE題目」）證明公開試確有此難度層級的同類題；「基礎／中等」抽樣引錨，全卷合計**至少 3 題**有錨題

### E2. 難度分布對標（與公開試比較）
- [ ] **MC**：基礎約 30–40%／中等約 40–50%／挑戰約 15–25%（15 題卷：約 5–6／6–7／2–4 題）；全卷預估答對率 **50–60%**；以最新可用年份 `07_考生表現` MC 逐題答對率作校準
- [ ] **DBQ**：每題 10 分呈階梯——(a) 起首 1–3 分基礎（指出類）→ 中段約 4–5 分中等 → 末段約 2–3 分挑戰（解釋/建議/評估類）；三題難度相若（選答制下不平衡＝選題不公）
- [ ] **LQ**：每題 18 分＝框架層約 9 分（基礎–中等）＋應用層約 9 分（中等–挑戰）；卷內各題難度相若
- [ ] 整體不偏離公開試範圍：全卷不可全為基礎題（無區分度），亦不可全為挑戰題（脫離考生實際水平）

### E3. 難度來源合理性
- [ ] LQ 背景沒有寫出答案線索（刪去背景後，應用層是否仍須考生自行推想情境；如背景句子可直接對應答案要點，E 維評 ✗ 並列入修訂）
- [ ] 挑戰題的難度來自**合理的認知要求**，而非：
  - ❌ 措辭含糊或故意歧義
  - ❌ 超綱冷門知識（課本及課程綱要未涵蓋；TIER 4 課題硬出挑戰題）
  - ❌ 不合理的計算複雜度
  - ❌ MC 選項之間差異過微（技術性陷阱而非概念辨析）
  - ❌ DBQ 資料過長或刻意隱藏關鍵資訊
- [ ] 基礎題確實容易——不因措辭不當、雙重否定或選項排列而人為提高難度
- [ ] 對照公開試：公開試的難題靠「情境應用＋易混概念＋跨課題整合」製造難度，而非「刁鑽措辭」

### E4. 認知層次比例
- [ ] 三層比例與最新三年公開試相若：**知識記憶**（指出／寫出／配對／定義）／**理解應用**（解釋／舉例／情境判斷／計算）／**分析評鑑**（比較／建議／評估／多角度分析／跨概念）
- [ ] MC：情境應用題佔半數以上（公開試趨勢：純記憶題佔比逐年下降，2026 年組合題幾乎全為情境題）
- [ ] DBQ/LQ：每題必含應用層（例證扣連資料、框架應用於情境），不可全為「指出」類背誦

### E5. 區分度設計
- [ ] 起點題讓中等生入手（MC 首 3–5 題、DBQ 每題 (a)、LQ 框架列舉部分）
- [ ] 後段題能區分中等生與高分生（對照考生表現：公開試常在「易混框架」「跨課題整合」「限定範圍審題」處拉開差距）
- [ ] MC 答案分布平均之外，難度亦分散（不集中於某一區段）

## F. 應試增值（對照 考生常見弱點與應試要訣.md）

- [ ] 針對至少一項歷屆考生弱點
- [ ] 訓練「點＋例證」作答格式
- [ ] 含限定範圍／審題訓練元素
- [ ] 含易混概念辨析（誘答或對比）
- [ ] 課題與 TIER 對照恰當（TIER 3 不配 LQ 等；見 課題出題頻率與TIER對照.md）

## 總評等級

- ✅ **通過**：六維全部○以上，無重大知識錯誤，難度分布與公開試基準無顯著偏差
- ⚠️ **需修訂**：1–2 個維度✗，或有個別知識錯誤，或難度分布略偏（列修訂清單）
- ❌ **建議重做**：3 個維度以上✗，或核心設計偏離最新三年公開試（如 LQ 用舊式開放論述），或**難度嚴重偏離公開試水平**（如全卷皆基礎題／全卷皆挑戰題／難度來源不合理）

## 驗證後修訂（用戶常規要求）

驗證完成後，按報告「優先修訂次序」產出**修訂版**（另存「【修訂版】原檔名.docx」，**原檔保留不動**），修訂版內容須落實上述六維建議；版面沿用原檔或校內慣用格式（排版非驗證項）。修訂後必須逐題核對「答案總表」與「逐題題解」的答案一致，再通讀全文一次。
