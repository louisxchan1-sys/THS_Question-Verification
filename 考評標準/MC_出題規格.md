# MC（多項選擇題）出題規格
> 出題與驗證共用正本｜基準：卷式跟 2026，錨題及難度依 2020–2026｜總則見 `出題總則.md`｜更新：2026-11-22（合併驗證器 MC 規格與製作器《選擇題製作指南》v4）

## 一、基本規格

| 項目 | 標準 |
|:----|:----|
| 題數 | 公開試 30 題全部必答；校內卷按使用者指定 |
| 選項 | 4 個（A–D），單一最佳答案 |
| 指示語 | 「選擇各題中最佳答案」／「選取最恰當的答案」 |
| 題目內 | 不逐題標「(1分)」 |
| 課題覆蓋 | 全卷涵蓋全部五大課題（旅遊導論／款待導論／地理名勝／客務關係及服務／趨勢及議題），大致按課程比重 |

## 三、各題型設計

### 3.1 3 陳述組合題（2026 新格式，主力）

```
X. 以下哪項／些有關〔課題〕的陳述是正確的？
   (1) …  (2) …  (3) …
   A. 只有(1)   B. 只有(3)   C. 只有(1)及(2)   D. 只有(2)及(3)
```

- 選項恆為 **2 個單選項＋2 個雙選項**，**不含 (1)(2)及(3) 全選項**。混入單選項但保留全選項的混合形態不算新格式，須逐題核對 4 個選項。
- 2026 模式分布：甲 A 只有(1)／B 只有(2)／C 只有(1)及(3)／D 只有(2)及(3)（約 37%）；乙 A 只有(1)／B 只有(3)／C 只有(1)及(2)／D 只有(2)及(3)（約 42%）；丙 A 只有(1)／B 只有(2)／C 只有(1)及(2)／D 只有(2)及(3)（約 11%）；其他約 10%。A 通常為「只有(1)」、D 通常為「只有(2)及(3)」（各約 80%）。
- 允許「只有一個正確」作答案。
- 真偽配合：最強干擾選項與正解只差**一個陳述**的判斷；不可「兩個明顯對、一個明顯錯」或「一個明顯對、兩個明顯錯」；三個陳述中**至少兩個**須「初讀似真」或「似錯實對」。
- 三個陳述考三個不同子概念，不可同一知識點三種說法。
- 全卷正確陳述數量須有變化。

示例（DSE 2026 Q4，答案 A）：(2)「在理所當然階段，當地人仍然對旅客友好，並積極與他們互動」錯在階段錯置；(3)「在煩厭不快階段，旅客開始對當地人的行為感到不滿」錯在主體調換——兩個錯誤陳述初讀都似真，這是基準水平。

### 3.2 直接選項題

適用：地理（城市、貨幣、時區、氣候、半球）、計算（賠償金額、時差）、情境判斷（最合適酒店、最佳行動）、因果推理。

- 最強干擾項與正解只差一個判斷點；四個選項中至少三個「可被中游學生辯護」。
- 題幹優先用「**最**能解釋」「**最**合適」「**主要**」等比較級限定詞。
- 計算題干擾項必須是具體常見錯誤的結果（時差方向算反、漏算附加費、百分比基數用錯；旅遊業賠償基金按外遊費 90%）。
- 地理題干擾項用同區域／同類型易混城市。
- 因果推理題：選項由「方向×機制」交叉組成，每個選項邏輯外觀完整（如 2026 Q9 高／低流失 × 提升／降低乘數效應）。

### 3.3 表格配對題

適用：多維度配對（景點×地區、設施×需求層次）、理論配對（推動×拉動）、情境×分類、地理×氣候。

- 錯誤行**只錯一格**（一格對、一格錯），不可兩格皆錯。
- 至少一個錯誤行的錯點屬「歸類方向調換」（如拉動因素放入推動欄）。
- 升級版：三欄配對（如半球×氣候×城市，2026 Q18），錯誤行只錯一欄。

### 3.4 NOT 題（反向提問）

- 跟 2026（只有 Q21「並非」一題）：**30 題制最多 1 題；少於 30 題的卷不設**。
- 格式：「以下哪項**不是**／**不正確**／**不適合**」，否定詞加粗；不可雙重否定。

## 四、錯誤陳述／干擾項設計

### 4.1 三條鐵律

1. **一字之差**：每個錯誤陳述都有一個「正確版本」，兩者只差一個關鍵元素（主體、階段、範圍詞、因果方向、部門名稱或數字），其餘部分完全正確。
2. **初讀皆似真**：把陳述單獨抽出，「一個讀過課文但只記大概的學生會否點頭？」答案必須是「會」。
3. **課文可追溯**：錯誤陳述的正確版本必須能在課本找到依據；不可虛構課文沒有的細節。

### 4.2 錯點類型（按難度排序，優先用上半部）

| 技巧 | 說明 | 示例 |
|:----|:----|:----|
| **對而不答** | 陳述本身正確，但不屬題幹限定的理論範圍 | 題問 Doxey，陳述描述 Butler 的正確內容 |
| 因果倒置 | 原因與結果互調，機制敘述完整 | 「高流失提升乘數效應」 |
| 階段／層次錯置 | 甲階段特徵放入乙階段 | 「欣喜」特徵放入「理所當然」 |
| 主體調換 | 結構不變，行為主體互換 | 「旅客開始對當地人感到不滿」 |
| 定義偏差 | 術語作微妙但關鍵的竄改 | 認識差距／溝通差距定義對調 |
| 角色錯配 | 部門／機構職能互調 | 禮賓部 vs 管家部；旅發局 vs 旅監局 vs TIC |
| 分類錯置 | 項目歸入錯誤分類 | 拉動因素寫成推動因素 |
| 條件附會 | 加入看似合理但不存在的條件 | 「高級臥鋪設有特大床」 |
| 時效錯誤 | 引用過時政策或數據 | 已修訂的旅監局職能 |
| 範圍錯誤 | 「部分」誇大為「全部」、加入「只有」「必定」 | 「所有房間都有海景」 |

- 高頻真實混淆：旅遊業 vs 款待業範圍（航空屬旅遊業不屬款待業）、外部 vs 互動行銷、負責任旅遊 vs 可持續旅遊、相近機構職能（另見 `考生常見弱點與應試要訣.md` 二.4）。
- 配額（15 題制；30 題制倍增）：對而不答／因果倒置／階段錯置／主體調換合計 **≥6 次**；範圍錯誤全卷 **≤3 次**，範圍詞不置句首顯眼位置。

### 4.3 似錯實對

每卷至少 **3 題**的正確陳述屬「初讀似錯但實際正確」：用課文較少注意但準確的細節、反直覺但成立的關係、或用準確但不同的措辭重述課文（避免照搬課文句式令學生靠眼熟作答）。

## 五、偏易紅旗（禁止模式；任何一項出現即重寫）

| # | 禁止模式 | 修正方向 |
|:--:|:----|:----|
| 1 | 直接問定義，選項為課文原句±明顯錯句 | 改為情境中辨識概念應用 |
| 2 | 錯誤陳述整句虛構或荒謬，或靠絕對化字眼（完全／永遠／唯一／必定／毫無）令人一眼排除 | 用一字之差原則 |
| 3 | 組合題只需判斷一個陳述便可排除三個選項 | 至少兩個陳述須似真或似錯實對 |
| 4 | 正確選項明顯較長、完整、措辭嚴謹 | 四個選項長度、語氣、結構一致 |
| 5 | 錯項用顯眼絕對詞、正項用「通常」「可能」 | 絕對詞偶爾也放入正確陳述（課文確有絕對關係時） |
| 6 | 兩個選項互相矛盾且涵蓋所有可能 | 選項間保持獨立 |
| 7 | **假情境**：刪去情境後仍可作答 | 令情境細節成為判斷的必要條件 |
| 8 | 干擾項與題幹課題無關 | 干擾項須與正解同屬一個概念框架 |
| 9 | 三個陳述考同一知識點 | 三個不同子概念 |
| 10 | 照搬課文句式作正確陳述 | 用準確但不同的措辭 |
| 11 | 組合題三陳述全對（必選全選項） | 新格式本身不設全選項 |
| 12 | NOT 題超出 §3.4 上限 | 改為正面提問 |

## 六、難度（配合 `出題總則.md` §四）

| 指標 | 15 題制門檻（30 題制倍增） |
|:----|:----|
| 三級分布 | 基礎 4／中等 6–7／挑戰 4（30 題：8–9／12–14／8–9） |
| 全卷預估答對率 | 約 52%（容許 50–57%） |
| 需兩步或以上推理（中等上沿＋挑戰） | ≥5 題 |
| 跨課題整合題 | ≥2 題 |
| 計算／表格／數據判讀題 | ≥2 題 |
| 可單憑一句課文直接作答 | ≤1 題（且須情境包裝） |
| 以一道 2026 真題為結構藍本 | ≥1/3（保留其陳述結構、選項邏輯與資訊密度，只換概念與情境） |
| 參考DSE題目 | 100%，全屬 2020–2026 |
| 校準來源 | 逐題答對率查 `04_選擇題答案/`（`07_考生表現/` 只載少數題，不可作答對率來源；刪題無百分率，不可作錨） |

難度提升技巧：3 陳述新格式（「只有一個正確」的可能本身提高推理要求）；真實場景（真實酒店／景點，並令細節參與判斷）；跨課題整合（Butler＋Plog＋Doxey；經濟流失×乘數效應）；方向×機制因果推理；時事素材；數據判讀（賠償計算、房間狀態代碼、入境數據）。

## 七、命題特徵（貼題度）

1. **情境化**：小情境開首，考應用而非背誦。
2. **真實名稱入題**：香港真實機構（旅發局、旅監局、TIC）、真實酒店及其地理位置、真實景點及其擁有權屬性；不用「酒店A」「景點B」。
3. **時事題**：每年 2–4 題考近一兩年行業時事；Q29–Q30 每年必為時事政策題。
4. **地理名勝**：每年約 4–6 題（大陸、時區、貨幣、官方語言、節慶、地理方位推理），歷屆考生最弱。
5. **理論框架題**：整合模式、Butler、Plog／Cohen／Doxey、Maslow、乘數效應、Kotler 產品三層次、服務金三角、Parasuraman 等，常以情境對號入座。

### 7.1 題序（DSE 穩定排列）

| 題號 | 範疇 |
|:----|:----|
| Q1–Q9 | 旅遊概論、旅客定義、分類理論、動機、影響 |
| Q10–Q15 | 酒店業（分類評級、部門、房間狀態、PMS、計價方式） |
| Q16–Q17 | 餐飲與食物安全 |
| Q18–Q22 | 地理知識 |
| Q23–Q28 | 服務質素、顧客關係、市場學、全球化、環保 |
| Q29–Q30 | 時事政策 |

跨章卷按上表；單章卷由淺入深，最後 1–2 題為時事政策題或高難度綜合題。

## 八、答案分布

- 30 題：A／B／C／D 各 7–8 題（2020–2025 每年均如此）；15 題：各 3–4 題（±1）。
- 任一字母不超過全卷 35%；不可連續 3 題同答案。

## 九、驗證要點（只驗內容，不驗排版）

1. 難度分布與預估答對率符合 §六；難度來源全部合理（`出題總則.md` §五）
2. 題型比例跟 §二；組合題逐題核對是否純正新格式；NOT 題不超標
3. 逐題對照 §五偏易紅旗
4. 四選項、單一最佳答案成立；措辭清晰
5. 誘答項基於真實誤解（§四）；答案分布符合 §八
6. 真實機構／景點／地理資料準確、最新
7. 每題有 2020–2026 參考DSE題目（`出題總則.md` §六）
