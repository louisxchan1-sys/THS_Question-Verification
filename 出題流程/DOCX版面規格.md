# DOCX 版面規格（跟足範本）
> 出題流程專用；驗證不評版面（AGENTS.md 鐵律 1）｜範本在 `範本/`｜更新：2026-11-22（由出題器 CLAUDE.md §5 遷入；規格 2026-09-25 從範本讀取，評卷參考頁碼及 LQ 表格 2026-10-02 使用者決定）

## 一、範本選用（lineage）

| 年級 | 試卷一 | 試卷二 |
|:----|:----|:----|
| 中四 | `範本/中四THS/2025-2026_中四THS_試卷一_{問題紙,答題簿,評卷參考}.docx` | `範本/中四THS/2025-2026_中四THS_試卷二_{…}.docx` |
| 中五、中六 | `範本/中五THS/THS終期試_試卷一_{…}.docx` | `範本/中五THS/THS終期試_試卷二_{…}.docx` |

- 工作紙一律用正式試卷格式：MC／DBQ 用試卷一範本，LQ 用試卷二範本。
- 統測等非全卷考試沿用試卷一範本，按題數刪減（如 MC 答題格由 30 格減至 20 格），其餘版面不變。
- 舊輸出、Drive 上任何「封存」、`99_非最新資料封存_*`、`_tmp_*`、`backup` 內的 DOCX 不可作範本。
- 範本內的**題目內容**不作難度或題型參照。

## 二、範本版面規格

| 項目 | 規格 |
|:----|:----|
| 紙張 | A4（21.0 × 29.7 cm）；評卷參考 20.7 × 29.3 cm |
| 邊界 | 試卷一問題紙、答題簿：四邊 2.00 cm；試卷二問題紙、評卷參考：四邊 1.27 cm |
| 預設字型 | 西文 Times New Roman；中文 PMingLiU（新細明體）；Normal 樣式 12 pt |
| 卷首（置中五行） | 學校名稱 → 「2026-2027年度」 → 考試名稱 → 「中X級　旅遊與款待科」 → 「試卷一／二」（評卷參考加「評卷參考」） |
| 卷首資料行 | 「級別：中X　時限：X小時X分鐘　總分：X分」；「日期：d/m/yyyy　擬卷老師：CMC」（以 Tab 分隔，沿用範本 Tab 位置） |
| 答題須知 | 粗體「答題須知」，其下（一）（二）（三）條文 |
| 部標題 | 樣式「編輯注意」（粗體 11 pt、段前 6 pt／段後 12 pt，範本為紅字，保留原樣）；新一部前分頁 |
| MC 題幹 | 樣式「T 0_1」（Times New Roman 11 pt，左縮排 0.85 cm、首行凸排 0.85 cm），格式「題號＋全形空格＋題幹」 |
| MC 陳述及選項 | 樣式「T 2_3」（左縮排 2.55 cm、凸排 0.85 cm），陳述「(1) …」，選項「A　…」 |
| 表格配對題 | 沿用範本表格樣式（首列為欄名，A–D 列） |
| 試卷二 LQ | 樣式「T 0_1」：「題號＋Tab＋背景」；分題「(a)＋Tab＋題目 (X分)」 |
| 部完標記 | 「甲部完」「乙部完／全卷完」：置中、粗體 16 pt（華康新特黑體(P)，沿用範本 run 格式） |
| 頁尾 | 問題紙、答題簿：沿用範本頁尾（保留，不改）。**評卷參考：頁腳置中「第 X 頁，共 Y 頁」**（`PAGE`、`NUMPAGES` 欄位，10 pt）；四份評卷參考範本已於 2026-10-02 加入此頁腳（頁腳距離 340 twips），照範本複製即自動有頁碼 |
| 答題簿 | 卷首同上＋「答題簿（試卷一）」；日期／得分、姓名／班號表；MC 答案格 10 欄；作答線表格及「寫於邊界以外的答案，將不予評閱」旁註全部保留 |
| 評卷參考（試卷一） | MC 答案表（2 × 11，每表 10 題）→「甲部題解及課題附表」（題號｜答案｜課題｜題解）→ 乙部按分題以「答案要點｜分數」或「概念｜例證」表格列分 |
| 評卷參考（試卷二及任何 LQ） | 標題、評分說明、常見錯誤提示用段落（標題「T 0_1」、內文「T 1_1」）；**答案要點一律用有框線表格**：三欄「要點｜概念（1 分）｜應用（1 分）」（解釋類末欄寫「解釋（1 分）」）；表頭粗體置中並設為重複標題列；列不跨頁；首欄粗體；表格左縮排對齊「T 1_1」內文（482 twips）；儲存格段落用「T 0_0」並沿用原文 run 格式（試卷二答案原為紅字，保留）；套用「Table Grid」，四邊及內框線單線 0.5 pt，並在每格加 tcBorders（以免 Google Drive 預覽不顯示線）。中五試卷二評卷參考範本已是此格式，照範本表格複製即可 |

## 三、修改範圍

- 只替換：年度、考試名稱、級別、時限、總分、日期、答題須知的數字、題目內容、答案。
- 不可改：樣式定義、頁邊距、頁首頁尾、頁碼欄位、表格框線與欄寬、作答行數、分頁位置（除因題數增減必須調整）。
- 評卷參考必須有頁碼。範本或舊檔沒有頁腳時：新建 `word/footer1.xml`，在 `[Content_Types].xml` 登記 footer 類型、在 `word/_rels/document.xml.rels` 加關係，並在每個 `sectPr` 開頭加 `<w:footerReference w:type="default" r:id="…"/>`；有 `titlePg` 的分節另設 `first` 頁腳。
- 新增題目以**複製範本內同類段落**（連 pPr／rPr）再改文字的方式加入，不用 `add_paragraph()` 預設樣式。
- 逐題標註只寫「難度｜參考DSE題目」（`考評標準/評分準則撰寫標準.md` 二.6）：MC 寫在「題解」欄末行；DBQ／LQ 寫在各分題答案表格之後一行；LQ 難度可分層寫（如「難度：概念 5 分中等＋應用 5 分挑戰」）。
- 問題紙不得出現任何標註、製作說明或模型自述。

## 四、已知範本瑕疵（不可照抄）

- 中五試卷一問題紙：時限寫成「1小時30\`分鐘」（多了反引號）；MC 題號與題幹黏連（「1根據……」）→ 輸出時改為「1　根據……」。
- 中四試卷二問題紙：紙張為 Letter（21.6 × 27.9 cm）；第 1 題缺題號及 T 0_1 樣式 → 輸出時改為 A4，並統一用 T 0_1。
- 文件屬性「標題」曾為外校名（2026-09-26 已改）：輸出前檢查正文及 `docProps/core.xml`，**不得出現本校以外的校名**；把輸出檔標題屬性設為本校校名「香海正覺蓮社佛教馬錦燦紀念英文中學」。
- 範本題目內容（MC 多題 NOT 題、送分選項；中五試卷二 Q2–Q5 背景超過 120 字、Q5(a)「三種／10 分」點分不配）只屬舊卷，不作內容參照。

## 五、檔名

- `{學年}_{年級}THS_{考核形式}_{試卷X}_{問題紙|答題簿|評卷參考}.docx`，例：`2026-2027_中五THS_第一次統一測驗_試卷一_問題紙.docx`；草稿：`…_試卷草稿.md`。
- 工作紙：考核形式寫「工作紙_{範圍}」，範圍用閎博章節簡稱，例：`2026-2027_中四THS_工作紙_課題一單元1第2章_試卷一_問題紙.docx`。
- 修訂版不在檔名前加「【修訂版】」，改在檔名末加 `_v2`、`_v3`。

## 六、版面驗證（交付前必做）

1. `soffice --headless --convert-to pdf` 轉 PDF，再 `pdftoppm -png -r 80` 轉 PNG，逐頁目測。
2. 檢查：卷首五行及資料行、部標題分頁、題號連續、選項縮排對齊、表格不跨頁斷裂、無壓邊／截字／空白頁、答題簿 MC 格數與題數一致、作答頁數足夠；評卷參考每頁頁腳都顯示「第 X 頁，共 Y 頁」，數字連續、總頁數正確，沒有欄位代碼或空白。
3. 列明範本 lineage（每個輸出檔由哪個範本複製）。
4. 雲端環境只有文泉驛字型，沒有新細明體／PMingLiU／華康新特黑體：視覺檢查以分頁、壓邊、截字、表格、空白頁為準，不以字形判斷；交付時註明「字形以學校電腦為準」。
5. 不能渲染時，回覆寫明「未經視覺驗證」。
