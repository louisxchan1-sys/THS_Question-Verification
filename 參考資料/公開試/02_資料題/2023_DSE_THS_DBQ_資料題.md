乙部：資料回應題**

本部分共設三題，選答**兩題**。

1. 某旅行社為約翰－某著名旅遊達人提供了一次驚喜的旅遊體驗。約翰提供了可以出遊的日期、預算，並提出了一些偏好。然後旅行社安排了所有的旅遊服務，直到他在 7 月 8 日晚上到達香港機場前，都沒有告訴他目的地和行程。旅行社僅為他提供以下旅遊指南：

| 旅遊指南 | |
| :--- | :--- |
| 7 月 9 日： | 在早上降落前 14 小時的直航中，安穩地睡一覺。目的地的天氣沒有香港那麼炎熱。在香檳區享受陽光和品酒，確是樂事。 |
| 7 月 10 日至 11 日： | 參觀城中兩個著名的景點，然後再探索農村地區兩個冷門的景點。在這個安全且受歡迎的目的地，即使口頭溝通可能未必太暢順，你也可嘗試在咖啡店與當地人交流。當地人大多非常友好。 |
| 7 月 12 日至 13 日： | 記得在迪士尼樂園與你最喜歡的角色合照。 |
| 7 月 14 日： | 歡度國慶慶典。需要穿燕尾服前往五星級酒店享用豐盛晚宴。 |
| 7 月 15 日： | 用半天時間去買名牌手袋和香水，然後飛回香港。 |
| <br>當地地圖、火車/巴士路線、一些有用的句子和緊急聯絡電話都在本旅遊指南內。以前的旅遊人士在我們官網上也有獨到的分享。好好享受你的旅程。 | |

<br>

參考所提供的資料，回答下列問題：

| | | | |
| :--- | :--- | :--- | :--- |
| (a) | (i) | 指出約翰出遊的城市，及當地使用的官方貨幣。 | (2 分) |
| | (ii) | 除資料中提及的景點外，舉出當地兩個著名的景點。 | (1 分) |
| (b) | | 根據蒲樂(Plog)的旅客分類，以兩個例證解釋為何約翰**不是**保守型旅客。 | (2 分) |
| (c) | (i) | 指出 7 月 14 日晚宴的餐飲服務類型，以例證加以說明。 | (1 分) |
| | (ii) | 舉出這類餐廳菜單的兩個特徵。 | (2 分) |
| (d) | | 根據 Parasuraman 的模式，該旅行社滿足了哪兩個顧客服務特點？以例證加以說明。 | (2 分) |

2. 「西九龍 ARTOUR」活動於 2022 年 7 月至 2023 年 1 月期間推出。有興趣遊覽下表各景點人士可按時乘搭免費巴士前往：

| 景點 | 訪客可以體驗的活動 |
| :--- | :--- |
| M+ 博物館及香港故宮文化博物館 | 藝術和文化活動、歷史博物館、高級和休閒餐飲 |
| 饒宗頤文化館 | 歷史遺址、旅舍、展覽和工作坊場地、藝術表演、高級和休閒餐飲 |
| 美荷樓 | 歷史遺址、展示本地住屋歷史和昔日居民日常生活的博物館、提供休閒餐飲的特色餐廳、旅舍 |
| D2 Place | 娛樂、高級和休閒餐飲、現代購物中心 |
| 南昌街 | 本地工藝店、藝術畫廊、主題咖啡館、休閒和本地餐飲 |

<br>

參考所提供的資料，回答下列問題：

(a) 指出這次活動將促進哪兩種旅遊形式。以例證加以說明。 (2 分)

(b) 參考以上所提供的特徵，美荷樓除了可被歸類為旅舍外，可改建成為哪類型酒店？以例證加以說明。 (1 分)

(c) (i) 試為美荷樓的餐廳，建議一個合適的主題。 (1 分)
(ii) 為了更有效地配合在 (i) 所建議美荷樓餐廳的主題，指出三項可以改變環境氣氛的元素，使餐廳對顧客更具吸引力。各以一個例子說明。 (3 分)

(d) (i) 以上五個景點中，哪個最可能被視為次選景點？ (1 分)
(ii) 提出兩個原因，解釋 (i) 的次選景點如何有別於首選景點。 (2 分)

3. 2019年A國的旅客數目創新高，下表為三個主要旅客來源地及其旅客資料的一些統計：

| | 中國 | 美國 | 日本 |
| :--- | :--- | :--- | :--- |
| 最受歡迎旅遊景點 | 國際主題公園 | 地質公園 | 歷史博物館 |
| 住宿類型 | 國際連鎖酒店 | 旅舍 | 本地酒店 |
| 旅遊目的 | 商務旅遊 | 閒暇旅遊 | 文化旅遊 |
| 最常購買的物品 | 當地食品 | 國際連鎖快餐店食品 | 進口名牌手袋 |
| 主要消費 | 住宿 | 餐飲 | 購物 |
| 主要年齡層 | 40-49歲 | 20-29歲 | 60-69歲 |

A國政府發現旅客雖然多，但經濟流失嚴重。當地旅遊業的承載力已不勝負荷，為確保旅遊業的可持續發展，政府建議限制旅客的數目。

參考所提供的資料，回答下列問題：

(a) 根據景點分類，分別指出中國及美國旅客的最受歡迎旅遊景點屬於哪類景點。
<p align="right">(2 分)</p>

(b) 上表反映了哪兩個旅遊統計資料範疇？以例證加以說明。
<p align="right">(2 分)</p>

(c) (i) 根據年齡層的資料，日本的旅客屬於哪個世代？
<p align="right">(1 分)</p>

(ii) 舉出該世代在餐飲方面的一個偏好。
<p align="right">(1 分)</p>

<p align="right">(2 分)</p>

(e) 建議該國政府可引進的兩個政策，以限制旅客的數目。
<p align="right">(2 分)</p>
