| ABC 旅行社 | 旅行代理商牌照號碼：123456 |
| :--- | :--- |
| | **東平洲一天地質導賞團** |
| **08:00** | 於中環碼頭集合導遊及乘船往東平洲 |
| **10:00** | 到達後，由導遊帶領進行石質地貌導賞 |
| **11:30** | 於岩石地形上進行燒烤午餐 |
| **13:30** | 自由時間。將為團員安排以下活動：<br>• 觀鳥<br>• 在林地上捕捉稀有蝴蝶品種<br>• 收集岩石或礦物作為紀念品<br>• 在島上踏單車<br>• 於海岸公園限制區內垂釣<br>• 拍照<br>• 於岩石上雕刻<br>• 步行於郊遊徑上 |
| **16:00** | 乘船返回中環 |

(a) 按行程上的內容，回答以下問題：

(i) 哪些在島上的活動是被視為不適當的？ (4分)

(ii) 解釋為什麼在題(i)中所指出的活動不適當。 (4分)

(iii) 指出該地質導賞團的一類潛在旅客群組。 (1分)

(iv) 什麼是東平洲作為旅遊目的地 的拉動因素？ (3分)
