# 2022 DSE THS 考生表現_論述題
<!-- formal_source: 2022\2022 CP.pdf -->

卷二**

卷二共設五題，考生須選答二題。在每題中，內容佔18分，傳意能力佔2分。下表是考生表現的總結：

| 題號 | 選題百分率 | 一般表現 |
| :--- | :---: | :--- |
| 1 (a) | 19 | 欠佳。大部分考生未能掌握「全面優質服務(TQS)」概念，對要採用的策略也缺乏認識，舉出說明管家部員工如何提升服務質素的例子也不準確。部分能力稍遜的學生錯誤地以優質顧客服務的指標作答。 |
| (b) | | 欠佳。大部分考生未能根據顧客流程的階段，提出「指定檢疫酒店」可採用的兩項措施。 |
| 2 (a) | 71 | 令人滿意。超過一半的考生能指出營舍活動可能造成的兩種環境污染及兩種擾亂生態問題，並清楚描述每種污染及生態問題的源頭，答案展示出他們對相關概念有一定的認識。 |
| (b) | | 令人滿意。超過一半的考生能指出營舍內餐飲設施在用餐階段浪費食物的五個源頭，並建議五種可在這階段減少浪費食物的措施。 |
| 3 (a) | 62 | 良好。大部分的考生能指出並描述過度旅遊對東道國社會及文化造成的四項負面影響。 |
| (b) | | 令人滿意。超過一半的考生能提出具體措施說明如何有效減低過度旅遊對東道國的負面影響。 |
| 4 (a) | 26 | 欠佳。大部分的考生對主題公園為訪客提供物有所值體驗方法認識不足，多不能以支援產品例子對每種方法加以闡釋。 |
| (b) | | 尚可。約一半的考生能指出科技提升所帶來的五個好處，但能力稍遜考生未能以主題公園的例子說明。 |
| 5 (a) | 21 | 令人滿意。超過一半的考生能解釋在目的地發展 MICE 市場的五個價值及根據這些價值，舉例說明商務旅客及休閒旅客的差異。 |
| (b) | | 尚可。約一半的考生能指出並說明會展業專才如何使用這些非口頭溝通技巧以助溝通。 |
