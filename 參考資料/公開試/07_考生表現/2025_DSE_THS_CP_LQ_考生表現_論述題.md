# 2025 DSE THS 考生表現_論述題
<!-- formal_source: 2025\2025 C.pdf -->

卷二**

卷二共設五題，考生須選答三題。每題內容佔18分，創意能力佔2分。下表是考生表現的總結：

| 題號 | 選題百分率 | 一般表現 |
| :--- | :---: | :--- |
| 1 (a) | 29 | 尚可。約一半考生對旅遊形式及自然、文化景點具備一定理解，能作基本說明；惟部分考生未能以現有自然或文化景點作例子說明，或重複使用例子，亦有部分考生未能按題目要求以南大嶼為例，而是以整個大嶼山作為例子。 |
| &nbsp;&nbsp;&nbsp;&nbsp;(b) | | 欠佳。超過一半考生混淆經濟合作及發展組織(OECD)評估旅遊業與環境壓力的架構、承載力及可持續發展旅遊業的十二個目標，未能準確歸納「引致壓力的相關活動」，僅籠統指出旅遊活動可能帶來的影響。 |
| 2 (a) | 24 | 尚可。約一半考生能指出並描述於規劃展覽階段確立目標的五個「SMART」條件，並準確解釋主辦機構於美食博覽中如何應用這些條件，顯示對相關概念具備一定理解。惟部分考生對「SMART」概念掌握不足，未能正確解釋各條件的含義。 |
| &nbsp;&nbsp;&nbsp;&nbsp;(b) | | 欠佳。超過一半考生僅能列舉一至兩項推廣本地食材對香港自然環境及生物多樣性的好處，且解釋較為簡略，未能充分解說。 |
| 3 (a) | 91 | 令人滿意。超過一半考生能指出客人以自攜裝置使用電子餐牌與使用印刷餐牌的差異，並作出適當比較；惟部分考生未能詳細說明電子餐牌如何更有利於餐廳營運。 |
| &nbsp;&nbsp;&nbsp;&nbsp;(b) | | 欠佳。超過一半考生僅能描述Parasuraman的五個顧客服務特點。此外，大部分考生建議的自助餐廳措施，未能完全符合五個顧客服務特點或題目要求，部分建議亦未考慮實際可行性。 |
| 4 (a) | 55 | 欠佳。超過一半考生未能指出並描述使酒店收取更高房價的因素，亦未能提出適當建議以提升高端消費客群的服務體驗。 |
| &nbsp;&nbsp;&nbsp;&nbsp;(b) | | 欠佳。超過一半考生未能指出建立提昇顧客滿意度文化所涉及的五個工序，部分考生誤將Parasuraman的五個顧客服務特點作為解釋。 |
| 5 (a) | 92 | 尚可。約一半考生能正確比較乘坐高鐵與飛機的差異；惟部分考生對飛行安全有既定負面印象，並誤以為鐵路班次必定較航班頻密，亦有部分考生未能明確指出內地家庭旅客的需要。 |
| &nbsp;&nbsp;&nbsp;&nbsp;(b) | | 欠佳。超過一半考生未能描述浦樂中庸型旅客的特徵，部分考生錯誤引用高恆「環境泡泡」概念解釋這類旅客，也未能按題目要求舉出合適例子。 |
