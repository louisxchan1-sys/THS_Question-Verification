# 2020 DSE THS 考生表現_論述題
<!-- formal_source: 2020\2020 CP.pdf -->

卷二**

卷二共設五題，考生須選答三題。在每題中，內容佔18分，傳意能力佔2分。下表是考生表現的總結：

| 題號 | 選題百分率 | 一般表現 |
| :--- | :---: | :--- |
| **1 (a)** | 55 | 令人滿意。約一半的考生能指出可持續發展旅遊業議程的五個目標，並以大館的情況作說明。但很多答案並不全面。 |
| **(b)** | | 良好。大部分的考生能指出全部四類承載力，並提供相關例子，但往往缺乏對相關概念的詳細描述。由答案可見他們對相關概念有一定的認識。 |
| **2 (a)** | 77 | 令人滿意。超過一半的考生能指出年長的旅客的關注事項，並為確保「環境泡泡」建議的不同安排。但很多答案，略嫌重複。 |
| **(b)** | | 尚可。約一半的考生能指出香港部分而非全部的四個競爭優勢和四個不利條件。當中很多考生只概括描述香港的強項及弱點，而未能就題目的特有情況加以討論。 |
| **3 (a)** | 67 | 令人滿意。大部分的考生能指出並解釋不能適用於此個案的旅遊動機。 |
| **(b)** | | 尚可。約一半的考生能寫出一個景點的五個特性，但對相關概念並未加以準確描述。當中大多數考生可就每個特性提出一個改善建議，但一些建議與相關特性不符。 |
| **4 (a)** | 59 | 尚可。約一半的考生能指出籌辦來港的獎勵旅遊時的五個考慮，而當中大多數考生能舉例子，加以說明。 |
| **(b)** | | 尚可。超過一半的考生能指出酒店部門，並為每個部門建議合宜的環保措施。一些稍遜的考生誤將「管家部」視作「前線」部門。 |
| **5 (a)** | 42 | 尚可。超過一半的考生能寫出政府在旅遊發展中的部分而非全部四個角色，當中大多數考生能建議應對健康危機的措施。 |
| **(b)** | | 尚可。約一半的考生提出飲食從業員衛生的良好做法，但當中大多數考生未能指出個人衛生的範疇。 |
