乙部（資料回應題）**

乙部共設三題，每題佔10分。考生須在本部選答兩題。下表是對考生表現的總結：

| 題號 | 選題百分率 | 一般表現 |
| :--- | :---: | :--- |
| **1 (a)** | 64 | 尚可。約一半的考生能正確指出該航空公司的三個服務差距，當中大多數考生能提供例證。能力稍遜的考生未能提供例證，加以準確說明。 |
| **(b)** | | 欠佳。超過一半的考生未能準確指出兩種食物污染的名稱，當中大多數考生未能解釋它們為何會在飛機上發生。 |
| **(c)** | | 令人滿意。超過一半的考生能提供例證，解釋機票平均價為何會於這些年間顯著下降。 |
| **(d)** | | 尚可。約一半的考生能從服務金三角涉及每一方的角度，各提出飛機延誤的一個理由，但很多答案略嫌重複。 |
| **2 (a)** | 83 | 尚可。約一半的考生能指出正確的旅遊形式，並輔以例證。一些能力稍遜的考生對題目所要求的旅遊形式缺乏認識，而用旅遊動機答題。 |
| **(b)** | | 尚可。約一半的考生能指出兩個目的地的階段，並輔以例證說明，但一些說明並不準確。 |
| **(c)** | | 令人滿意。超過一半的考生能寫出獨立營運度假村的兩個壞處。 |
| **(d)** | | 良好。大部分的考生能指出聘請當地人從事度假村大部分工作的兩個好處，反映他們對所考核的議題有充分的理解。 |
| **3 (a)** | 52 | 尚可。超過一半的考生能指出旅行社職員所持的一種牌照，但當中大多數考生未能準確指出發牌機構的名稱。 |
| **(b)** | | 欠佳。大部分考生未能指出全部三個不恰當的安排。他們對要在資料中總結出不恰當的安排，往往力有不逮。 |
| **(c)** | | 令人滿意。約一半的考生能正確指出餐飲場所的類別，當中大部分考生能正確描述餐單及服務方面的特色。 |
| **(d)** | | 尚可。大部分的考生未能指出人工景點的分類，考生只能簡單指出並說明行程中的景點。 |

一般評論及建議

1. 考生在資料回應題的表現尚可。他們在一些涉及旅遊與款待概念的題目上表現理想，例如題2(c)、題3(c)。大部分考生主對某些概念所涉及的分類表現欠佳，例如題1(b)、題3(d)。

2. 在題1(a)、題2(b)，大部分考生只能提出有限的正確答案，顯示出他們對差距模式、巴特勒的目的地生命週期的概念，缺乏全面認識。

3. 考生對某些要求他們詮釋及分析資料的題目表現力有不逮，例如題1(b)、題3(b)。

4. 整體而言，考生在多項選擇題的表現令人滿意。在考核旅遊的相關知識的題目上表現略為遜色，例如題9和題26。考生宜拓闊視野，增進旅遊與款待業的相關知識。
