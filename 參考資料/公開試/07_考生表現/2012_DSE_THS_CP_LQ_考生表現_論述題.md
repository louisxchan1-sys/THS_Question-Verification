# 2012 DSE THS 考生表現_論述題
<!-- formal_source: 2012\2012 CP.pdf -->

卷二**

卷二共設五題，考生須解答三題。每題內容佔18分，傳意能力佔2分。下表總結考生的表現：

| 題號 | 選題百分率 | 一般表現 |
| :--- | :---: | :--- |
| **1 (a)** | 32 | 尚可。大部分考生能說明給顧客提供優質服務對一家旅行社的重要性，惟部分考生只提出一些優質服務的例子，而缺乏詳細的闡述。 |
| **(b)** | | 尚可。約半數考生未能明辨顧客服務的特點，而且所舉例子與所述特點無關。 |
| **2 (a)** | 70 | 良好。大部分考生能從不同的層面解釋環保酒店增加的原因，惟只有少數考生能提出建立環保酒店是為了符合政府條例的重要性。 |
| **(b)** | | 尚可。大部分考生能建議在酒店日常運作中可用的一些綠色措施，惟部分答案與環境保護無關。 |
| **3 (a)** | 36 | 優良。大部分考生能寫出三種對消費者有害的食物污染類型。 |
| **(b)** | | 良好。大部分考生能根據食物安全中心制訂的「食物安全五要點-業界指南」，建議一些避免因廚房食物引致疾病的預防措施，惟少數考生未能以合適的食品處理例子與其要點互相配合。 |
| **4 (a)** | 83 | 優良。部分考生能分別從服務供應商和顧客的角度，詳盡說明使用資訊科技銷售及購買旅遊產品及服務的好處。 |
| **(b)** | | 良好。大部分考生能理解有些顧客對使用資訊科技購買旅遊產品及服務有所保留的原因，惟小部分考生誤以為網上銷售的旅遊產品和服務的質素比直接親身向供應商購買的差。 |
| **5 (a)** | 79 | 良好。大部分考生能寫出對入境遊客具吸引力的香港本土文化元素，並以合適的例子加以說明，惟少數考生未能以所舉例子與所提出的文化元素配合。 |
| **(b)** | | 良好。大部分考生能解釋旅遊發展對一個旅遊目的地社會及文化可能造成的影響，惟小部分考生混淆了社會文化影響與經濟影響。 |
