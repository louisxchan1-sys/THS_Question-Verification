# 2025 DSE THS 考生表現_選擇題
<!-- formal_source: 2025\2025 C.pdf -->

卷一**

**甲部（多項選擇題）**

甲部為多項選擇題，共三十題。一般來說，考生的表現尚可，平均答對十五題。

整體而言，考生普遍能展示對款待業和客務關係的一些主要概念之理解，例如酒店管家部主要崗位的職責、營造餐廳環境氣氛要素及客戶服務禮儀等。大部分考生在題13、題15及題23都能選出正確答案。然而，以下題目值得特別注意：

---

9. 以下哪些服務同屬旅遊業與款待業？

   (1) 香港半島酒店提供的住宿服務
   (2) 國泰航空公司提供的航空服務
   (3) 香港海洋公園提供的娛樂活動
   (4) 大型連鎖餐廳提供的餐飲服務

   | | | |
   | :--- | :--- | :--- |
   | A. | 只有 (1) 及 (2) | (51%) |
   | \*B. | 只有 (1) 及 (4) | (20%) |
   | C. | 只有 (2) 及 (3) | (22%) |
   | D. | 只有 (3) 及 (4) | (7%) |

   51% 的考生錯誤選擇 A 作為答案。許多考生誤以為航空服務同屬旅遊業與款待業。事實上，航空服務僅歸類於旅遊業，因其主要滿足旅客的交通需求。

---

10. 一位擁有高消費力的旅客想入住一間徒步可到西九文化區主要景點的酒店。以下哪間酒店最合適？

    | | | |
    | :--- | :--- | :--- |
    | A. | 香港四季酒店 | (17%) |
    | B. | 九龍香格里拉 | (40%) |
    | \*C. | 香港麗思卡爾頓酒店 | (26%) |
    | D. | 富豪九龍酒店 | (17%) |

    40% 的考生錯誤選擇 B 作為答案。許多考生未能意識到九龍香格里拉位於尖沙咀東，並不在西九文化區步行距離內，因此不符合旅客偏好入住於主要景點附近的要求。

25. 根據服務金三角的概念，以下哪些酒店採取的行動是互動行銷的例子？

| | | |
| :--- | :--- | :--- |
| A. | 在酒店網頁提供三維虛擬導覽，以吸引潛在顧客 | (48%) |
| B. | 為前線部門的員工提供網上培訓課程 | (13%) |
| *C. | 根據既定標準提供入住登記服務 | (27%) |
| D. | 為長期服務的員工提供額外福利 | (12%) |

48% 的考生錯誤選擇 A 作為答案。許多考生普遍誤解服務金三角各持分者的關係。在此架構內，酒店網頁提供三維虛擬導覽屬於外部行銷（公司對顧客的溝通）的例子，因此不屬於互動行銷。

26. 以下哪項／些有關全面優質服務策略與例子的描述是正確的？

(1) 酒店房務員致送手寫的感謝信以表達對顧客的珍惜。
(2) 餐廳率先回收廚餘並加工成牲畜飼料以展示競爭優勢。
(3) 航空公司在官方網站推出最後一刻優惠促銷機票以把握「關鍵時刻」。

| | | |
| :--- | :--- | :--- |
| A. | 只有 (1) | (63%) |
| B. | 只有 (3) | (15%) |
| *C. | 只有 (1) 及 (2) | (16%) |
| D. | 只有 (2) 及 (3) | (6%) |

63% 的考生錯誤選擇 A 作為答案。大部分考生未能意識到陳述(2)也屬於全面優質服務的策略與例子。餐廳率先回收廚餘並加工成牲畜飼料的做法，透過正面環保效益提升品牌差異化。

27. 以下哪項有關「負責任旅遊」的陳述是正確的？

| | | |
| :--- | :--- | :--- |
| A. | 確保護照仍有至少六個月的有效期，可被視為負責任旅客的行為。 | (20%) |
| B. | 負責任旅遊著重於環境方面，而可持續發展旅遊則充分考慮旅遊對各方面的影響。 | (47%) |
| C. | 負責任旅遊的概念不能應用於旅遊業整合模式之中。 | (11%) |
| *D. | 透過負責任旅遊，更能滿足可持續發展旅遊議程十二個目標中的文化獨特性。 | (22%) |

47% 的考生錯誤選擇 B 作為答案。許多考生誤解了「負責任旅遊」的概念。它不僅限於環境方面，還同時考慮旅遊對社會、經濟及文化的影響。
