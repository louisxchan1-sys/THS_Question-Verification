# 2015 DSE THS 考生表現_資料題
<!-- formal_source: 2015\2015 CP.pdf -->

乙部（資料回應題）**

乙部共設兩題，每題15分，考生須在本部選答一題。下表是考生表現的總結：

| 題號 | 選題百分率 | 一般表現 |
| :--- | :---: | :--- |
| 1 (a) (i) | 72 | 良好。大部分考生能將所有酒店套票與目標訪客正確地加以配對。 |
| (ii) | | 良好。很多考生能引用相關例證支持他們在題(a)(i)所作的配對。但一些考生卻未能就所有酒店套票的配對提供理據。 |
| (b) | | 欠佳。很多考生未能舉出正確的管理模式。 |
| (c) (i) | | 令人滿意。很多考生能提供恰當例證並說明自助退房服務的好處。 |
| (ii) | | 尚可。很多考生能指出不使用自助退房服務的原因，惟解釋略欠詳細。 |
| (d) | | 尚可。很多考生未能準確引用赫曼的理論，闡釋也略嫌不足。 |
| 2 (a) (i) | 28 | 欠佳。很多考生未能提供正確的客房狀況。 |
| (ii) | | 尚可。部分考生未能為相關組別編配合適的客房，以及提供準確解釋。 |
| (b) (i-iii) | | 尚可。大部分考生對第一及最後階段的回答較準確。他們常混淆了第二及第三階段，或提供了重複的答案。 |
| (c) (i) | | 良好。很多考生能正確地描述該團體。 |
| (ii) | | 尚可。部分考生能指出一些接待遊客基本禮儀的例子，但很多例子未能按題目要求針對該團體作答。 |
| (iii) | | 良好。大部分考生能舉出客人的一些需要，但答案並未能涵蓋全部三個範疇的需要。 |

<br>

**一般評論及建議**

1. 在乙部資料回應題，考生對那些答案已包含於題目資料中的題目，應付裕如；但他們對於需要詮釋資料以總結出其他論點的題目，則顯然力有不逮。而對學科專門知識的應用亦並非一貫地令人滿意。

2. 考生在一些需要闡釋或從多角度進行分析的題目，表現力有不逮，例如題1(b)及題2(c)(iii)。
