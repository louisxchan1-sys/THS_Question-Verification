# 地理景觀

歐洲東面連接亞洲大陸，北面是北冰洋，西面是大西洋，南面是地中海及黑海。全洲平原廣闊，佔總面積六成，是各大洲之冠。歐洲也是世界上地勢最低的洲，平均海拔僅三百米。因此，森林、牧場、園林遍布歐洲各處，成為風景優美的自然旅遊資源。

歐洲山地不高，植被茂密，其中巴爾幹半島的喀斯特地型最為典型，而阿爾卑斯山區就是著名的滑雪勝地。意大利境內的維蘇威、埃特納等火山仍在活動。

# 2 河川湖泊

歐洲冰川地貌分布廣，形成不少窪地、湖泊及沼澤。其中北歐的冰島、挪威等地，都是觀賞冰川的好地方。全歐洲湖泊眾多，廣泛分布在各個國家，而芬蘭就有「千湖之國」之稱，瑞典更被譽為「萬湖之國」。

歐洲最長的河流是位於俄羅斯境內的伏爾加河。第二大河多瑙河則流經德國、奧地利、斯洛伐克、匈牙利、塞爾維亞、保加利亞、羅馬尼亞等多國，是東南歐的大動脈。第三大河萊茵河流經瑞士、奧地利、德國、法國、荷蘭等國。其他較著名的還有法國的塞納河、英國的泰晤士河等。

# 3 氣候

歐洲大部分地區位於北温帶，而由於沒有高山阻隔，西風及大西洋暖流能順利深入，使歐洲大部分地區的海洋氣候特徵明顯。

當中西歐、北歐沿海、中歐平原及東歐西部平原，成為温帶海洋性氣候，冬天較温暖，夏天較涼快，多雨及多霧，而日照時間少。

阿爾卑斯山以南的地中海沿岸屬於地中海氣候，冬天温暖多雨，夏天乾燥炎熱。

北歐東部及東歐北部屬於亞寒帶氣候，冬天漫長而嚴寒，夏天短暫而温暖。

# 人文景觀

# 5.3 法國

# 1 國家簡介

法國位於歐洲大陸西部，包括地中海上最大的島嶼科西嘉島，國土面積 63 萬平方公里，是西歐面積最大的國家。法國西北隔英倫海峽與英國相望，東北與比利時、盧森堡交界，東部與德國、瑞士相鄰，東南毗連意大利，南部與摩納哥接壤，西南與西班牙、安道爾相接。

根據國家商務部《對外投資合作國別（地區）指南：法國（2023年版）》，法國2022年人口約6 800萬，其中白人約佔九成，其他有色人種約佔一成。法國有超過六成人口信奉天主教，其他主要宗教有伊斯蘭教、基督教、猶太教等；官方語言是法語，英語也在商界普遍使用。

# 2 歷史文化

法國曾是古羅馬帝國的一部分。古羅馬帝國覆滅後，法蘭西人統治當地。到了中世紀，法蘭西王國曾統一西歐，而法國自始一直是歐洲強國。近代，法國曾在全球多地擁有殖民地，影響力僅次於英國。1789 年，法國爆發大革命，之後前後五次成立共和國、兩次建立帝國。1958 年，戴高樂領導建立了法國第五共和國，並沿至今日。

# 法國習俗禮儀

法國人與客人相見時一般以握手為禮，親朋好友之間相見習慣行親面頰或貼面禮，與女士見面還可施吻手禮。法國人在餐桌上敬酒先敬女後敬男，走路、進出、入座等都要讓女性先行，拜訪告別時也是先向女主人致意道謝。

法國人偏愛公雞，認為它既有觀賞價值和經濟價值，還有司晨報早的功能，因而將牠作為「光明」的象徵。他們還非常喜愛鳶尾花，視為權力象徵和國家標誌，並敬為國花。

# 3 地理氣候

# A 地理

法國地勢東南高西北低，平原約佔全國總面積三分二，主要山脈有阿爾卑斯山脈、比利牛斯山脈等。其中位於法國與意大利交界的勃朗峰，高4 810米，是西歐最高的山峰。

法國三面臨海，南面是地中海，西面是大西洋，北面是英倫海峽，海岸線長達5 500公里。

# 提示箱

所有旅客都希望能健康地出遊、健康地返回原居地，因此衞生環境也是旅客選擇外遊目的地的考慮因素。經濟發達地區，衞生及醫療較佳，對旅客吸引力較大；反之，對一般旅客吸引力較小。

# B 旅遊資源

法國首都巴黎擁有豐富的文化資源，地中海、大西洋沿岸及阿爾卑斯山區風景優美，使當地成為熱門的旅遊目的地。

法國也有多個全球知名高級時裝、珠寶、皮革、化妝品、香水品牌，吸引大批旅客前往當地的專營店購物。

根據聯合國教科文組織資料，截至 2024 年，法國共有 53個世界遺產，文化遺產 44 個，自然遺產 7 個，文化與自然雙重遺產2個。

# C 旅遊競爭力

根據世界經濟論壇發表的《全球旅遊業競爭力報告2024》，法國在全球排名第 4位。

法國政治局勢相對穩定，社會治安狀況相對良好。但法國近年針對旅客的搶劫案件有上升趨勢，而恐怖襲擊個案偶有發生，對安全和保安排名有所影響。然而，這些無損法國對旅客的吸引力，使法國多年來成為全球第一大旅遊目的地。

# 5 衞生環境

法國的衞生環境良好。不過，根據世界衞生組織資料，法國南部在 2019 年曾出現寨卡病毒感染個案，在 2018 年曾出現登革熱感染個案。

# 6 簽證要求

法國是歐盟成員國，根據《神根公約》（Schengen Agree-ment），旅客只要持有其中一個國家的旅遊簽證，就可進入其他神根國家。根據歐洲對外事務部資料，截至 2024 年，有 62個國家或地區的公民可免簽證入境法國在內的歐盟國家，包括中國香港、中國澳門、新加坡、馬來西亞、阿聯酋，以及北美洲的美國、加拿大、墨西哥，南美洲的巴西、阿根廷、智利，大洋洲的澳洲、新西蘭等。

根據香港入境事務處資料，香港特別行政區護照持有人最長可免簽證逗留法國90日。

# 1. 艾菲爾鐵塔（Eiffel Tower）

艾菲爾鐵塔矗立於巴黎塞納河岸，於 1889 年為世界博覽會而建造，以鐵塔的建築工程師艾菲爾而命名。鐵塔的塔身是鋼架結構，高 324 米，是巴黎最高的建築物。旅客可從樓梯登上第一、二層，或乘電梯穿梭各層；第三層的觀景台高 276 米，旅客可遠眺巴黎全景。艾菲爾鐵塔不僅是巴黎最具代表性的建築及景點，還兼具電視廣播發射中心等功用。

# 2. 羅浮宮（Mus\~e du Louvre）

# 11. 伊夫堡（Chateau d'If）

伊夫堡位於馬賽海港的弗里烏群島，約 1529 年開始興建。建築結構呈方形的伊夫堡，共分四層，兩側有三個塔樓，初為軍事碉堡，後來用作國家監獄，現存石壁尚能看到囚犯刻名的痕跡。大仲馬的小說《基度山恩仇記》中，描寫主角被監禁於伊夫堡監獄，令伊夫堡聞名於世。

# 12. 古羅馬大劇院（Roman Theater）

古羅馬大劇院位於里昂的福爾維山丘上，是一大一小的兩個半圓形劇場。公元前 43 年，古羅馬人在這裏建成了這座當時世上最豪華的大劇院。公元 2 世紀，劇院擴建，增加了 11 000個座位。大劇院經修復後，至今保存完好，不僅可供旅客參觀，還不時舉辦演奏會、歌劇等文化活動。

# 5.4 意大利

# 國家簡介

意大利位於歐洲大陸南部，包括形狀像一隻靴子的亞平寧半島，以及西西里島、撒丁島，國土面積 30 萬平方公里。意大利北面與法國、瑞士、奧地利、斯洛文尼亞相鄰，東、西、南三方面都是地中海。

根據國家商務部《對外投資合作國別（地區）指南：意大利（2023年版）》，意大利2022年人口約5 885萬，其中白人佔九成以上，其他為有色人種。意大利有超過七成人口信奉天主教，其他主要宗教有基督教、東正教、猶太教、伊斯蘭教等；官方語言是意大利語，英語也在商界普遍使用。

# 歷史文化

公元前 509 年，羅馬共和國成立。到公元前 27 年至公元 476 年，意大利進入羅馬帝國時期。後來外族入侵，羅馬帝國覆亡，意大利分裂成許多小國。自 16 世紀起，意大利先後被法國、西班牙、奧地利佔領。到了 19世紀中葉，意大利統一運動興起，意大利在撒丁王國帶領下，於 1870 年完成統一。1946年，意大利廢除君主制，成為共和國家。

# 意大利習俗禮儀

意大利人在各種社交場合奉行女士優先。見面禮是握手或招手示意，親吻是比較親近的朋友間的禮節，一般兩人的臉要貼兩次，男性朋友之間見面會擁抱。

意大利人如請客人到家裏吃飯，表明視客人為上賓，客人可帶酒、甜點或鮮花作禮物。客人攜帶的食物、酒和甜點會當場一同食用。意大利人習慣當場打開禮物，以示對客人的尊重。

# 旅遊概況

# A 交通便捷度

根據國家商務部資料，意大利境內交通四通八達，有 96 個機場。羅馬國際機場是全國最繁忙的機場，有航線連繫全球主要城市。米蘭機場、威尼斯機場、都靈機場等也是較為重要的國際機場。

# B 旅遊資源

意大利是古羅馬文明和歐洲文藝復興的發源地，擁有大量文物古跡和藝術珍寶，加上氣候宜人，風景秀麗，對旅客甚具吸引力。

意大利也有多個全球知名高級時裝、珠寶、皮革、化妝品和香水品牌，吸引大批旅客前往當地的專營店購物。

根據聯合國教科文組織資料，截至2024年，意大利共有60個世界遺產，文化遺產 54 個，自然遺產 6 個，是其中一個世界歷史文化遺產最豐富的國家。

# C 旅遊競爭力

根據世界經濟論壇發表的《全球旅遊業競爭力報告2024》，意大利在全球排名第 9位。

意大利社會較為穩定，恐怖襲擊事件也較少發生。治安方面，針對外國旅客的財物盜竊案件時有發生，而北部地區的治安較南部為佳。

# 羅馬（Rome）

羅馬位於意大利半島中部，是意大利的首都、全國第一大城市，也是歐洲著名的歷史古城。

羅馬原是羅馬帝國時期的首都，後來成為基督教世界的首都，保留了許多古羅馬的建築，包括了古羅馬廣場、羅馬競技場、萬神殿、奧古斯都大帝陵墓、圖拉真圓柱、城牆等，以及羅馬教廷時期的宗教及公共建築等。羅馬歷史中心於 1980 年被列入《世界文化遺產》名錄。

# 1. 萬神殿（Pantheon）

萬神殿位於羅馬市中心，始建於公元前27年，是羅馬城內保存最完好的羅馬帝國建築。萬神殿由混凝土建成，入口門廊由巨型柱子支撐，主體大廳呈圓形，頂部有一個直徑達 43 米的穹頂，中間是一個直徑近 9米的圓形大洞，陽光可直接照射進來。萬神殿圓廳加柱廊的設計，對後世的建築物產生了重要影響。

# 2. 羅馬競技場 （Colosseum）

羅馬競技場又稱羅馬鬥獸場，是羅馬的地標性建築。這座於公元 80 年建成的橢圓形競技場，佔地約 2 萬平方米，由混凝土、泥炭和磚塊建造而成，可容納近八萬名觀眾。競技場的看台有三層，每層有 80 個拱門支撐。當時，競技場可用巨大的帆布覆蓋，讓觀眾可免在烈日或風雨下，觀賞角鬥士與角鬥士之間，或角鬥士與猛獸的搏鬥。

# 3. 古羅馬廣場 （Roman Forum）

古羅馬廣場位於羅馬競技場不遠處，在當年古羅馬市中心的位置，曾是羅馬帝國的政治、經濟中心。廣場後來被摧毀、破壞，直到 18 世紀才陸續發掘出來。現時，旅客仍可在被稱為「露天博物館」的廣場遺址，欣賞到大量古羅馬時期的歷史建築，包括宮殿、神殿、元老院、禮堂等。

# 4. 許願池（Trevi Fountain）

許願池又名特萊維噴泉，位於羅馬市中心，是一座建於 18世紀的巴洛克風格噴泉。噴泉建築左右對稱，以海神和女神雕塑為主題，各雕像栩栩如生，美輪美奐。傳說只要能背着許願池，把硬幣投入池中，將來就有機會再重遊此地。因此，向池裏投入硬幣許願，已是旅客的指定動作。

君士坦丁凱旋門位於羅馬競技場旁邊，始建於公元312年，是為了紀念君士坦丁大帝而興建。凱旋門有三個拱門，高 21 米，闊 25 米，上面保存有羅馬帝國各個重要時期的雕刻，堪稱一部生動的羅馬雕刻史。

# 6 . 梵蒂岡教廷建築（the Properties of the Holy See inthat City Enjoying Extraterritorial Rights）

# 7. 聖彼得大教堂（St. Peter's Basilica）

聖彼得大教堂又名聖伯多祿大教堂，位於梵蒂岡內，始建於 1450 年，由文藝復興時期著名建築師與藝術家參與設計，包括米高安哲羅、拉斐爾等。這座佔地 2 萬 3 千平方米的教堂，是全球最大的教堂，呈現十字型設計，內部金碧輝煌，以不同顏色的大理石做裝飾，並有大量令人驚嘆的雕像、壁畫。旅客可登上教堂的大穹頂，俯瞰整個梵蒂岡城。

# 9. 佛羅倫斯歷史中心（Historic Centre of Florence）

佛羅倫斯歷史中心保留了羅馬時期的基本布局，以及眾多中世紀文藝復興時期的建築，如聖母百花大教堂、聖十字大教堂、領主廣場、老橋等，並有藏品豐富的博物館，如烏菲茲美術館、學院美術館等。佛羅倫斯歷史中心於 1982 年被列入《世界文化遺產》名錄。

# 10. 聖母百花大教堂（Cathedral of Santa Maria del Fiore ）

聖母百花大教堂位於佛羅倫斯歷史中心，是天主教佛羅倫斯總教區的主教堂，也是佛羅倫斯的地標式建築。這座哥德式風格大教堂，由主教堂、鐘樓和洗禮堂組成，外部以白色、綠色和粉紅色的大理石塊鋪砌而成，色彩斑斕而和諧。其中主教堂的圓頂，更是有史以來最大的磚造穹頂。

# 11. 烏菲茲美術館（Uffizi Gallery）

烏菲茲美術館位於佛羅倫斯歷史中心內，收藏了大量文藝復興時期名家的作品，包括達文西、波提切利、米開朗基羅、卡拉瓦喬等大師的繪畫、雕塑和陶瓷等。這幢高三層，有 50 個展廳的美術館，也是與法國羅浮宮、俄羅斯冬宮博物館和西班牙普拉多美術館齊名的歐洲美術館。

# 12. 比薩大教堂廣場（Piazza del Duomo, Pisa）

比薩位於意大利中部，在佛羅倫斯西北約 30 公里。比薩大教堂廣場由一系列宗教建築組成，包括大教堂、洗禮堂、鐘樓（即比薩斜塔）和墓園，是意大利羅馬式教堂建築的典型代表。當中圓柱形的比薩斜塔，始建於 12 世紀，由於地基不穩而傾斜，並因而成為意大利其中一個重要地標。比薩大教堂廣場於 1987年被列入《世界文化遺產》名錄。

# 13. 威尼斯及其潟湖（Venice and its Lagoon）

威尼斯位於意大利東北部，建於 5 世紀，坐落在潟湖的淺灘上，由 118 個小島構成，曾是中世紀歐洲的航運樞紐。威尼斯內有近150條運河、400多座橋樑，使它有「水都」的美譽，更被譽為歐洲最浪漫的城市。當地建有宏偉的宮殿、教堂，旅客可乘坐貢多拉在運河中穿梭。威尼斯及其潟湖於 1987 年被列入《世界文化遺產》名錄。

# 15. 威尼斯嘉年華（Venice Carnival）

# 20. 五漁村（Cinque Terre）

五漁村位於意大利西北部沿海地區，距離佛羅倫斯約 180 公里。五漁村由五條在中世紀形成的小村落組成。各村落的房屋密密麻麻建於臨海山壁上，外牆都塗上色彩鮮艷的顏色，景色非常壯麗。旅客可乘坐臨海鐵路穿梭五條村落，並飽覽地中海景色。五漁村於1997年被列入《世界文化遺產》名錄。

# 21. 埃特納火山（Mount Etna）

埃特納火山位於意大利西西里島東岸，海拔約 3 300 米，是歐洲最高的一座火山，也是全球其中一座最活躍的活火山。埃特納火山的噴發歷史，可追溯至五十萬年前，有記錄的在公元前475年。不斷噴發的埃特納火山，曾摧毀附近的城鎮村落。

# 5.5 西班牙

# 國家簡介

西班牙位於歐洲大陸西南部的伊比利亞半島，國土面積 51萬平方公里，在西歐僅次於法國。西班牙西面與葡萄牙接壤，東北面與法國、安道爾交界，東面和東南面瀕臨地中海，西北面是大西洋，南面隔着直布羅陀海峽與非洲的摩洛哥相望。

根據國家商務部《對外投資合作國別（地區）指南：西班牙（2023年版）》，西班牙2022年人口約4 819萬，主要是西班牙裔人，小部分是來自非洲、南美洲等地的移民。西班牙有超過九成人口信奉天主教；官方語言是西班牙語，英語、法語也在商界普遍使用。

# 歷史文化

西班牙是歐洲其中一個文明古國，曾被古羅馬人、西哥德人、阿拉伯人統治。其中阿拉伯人曾在 710 至 1482 年統治西班牙南部地區長達七個世紀。1492 年，西班牙人建立統一的王朝，並逐漸成為海上強國，向海外擴張。16 世紀時，西班牙在美洲、亞洲、非洲等多地建立了殖民地。後來，西班牙的海上霸主地位被英國取代。1873 年，西班牙建立共和國。自 1978年起，西班牙實行君主立憲制。

# 資料室

# 西班牙習俗禮儀

西班牙人見面問候一般採取握手、貼面和擁抱 3 種方式。 初次相識一般是握手問候。在正式社交場合與客人相見時，行握手禮，女士之間親吻面頰。與熟人相見時，男性朋友之間常擁抱。

到西班牙人家中做客，一般應備禮品，如酒或鮮花等，贈送禮品很注重包裝，並有當面拆開包裝、讚賞禮品的習慣。西班牙人忌諱送大麗花和菊花，送朋友以玫瑰花為宜。

由於西班牙的勢力曾遍及全球多地，現時世界上有 5 億多人使用西班牙語，令西班牙語成為全球第三多人使用、第二多國家使用的語言。

# B 氣候

西班牙大致分為三種氣候，北部屬温帶海洋性氣候，冬暖夏涼；中部屬温帶大陸性氣候，冬冷夏熱；佔全國七成的南部和地中海沿岸地區，屬温帶地中海氣候，冬暖夏乾。全年四季分明，夏季氣温可高達 40℃以上，冬季北部及山區經常下雪，平均氣温 2℃至10℃。北部、西北部及東部沿海地區雨量充足，年降雨量達600至800毫米，其他大多數地區降雨量較少。

# 12. 塞哥維亞古城及其水道橋

# （Old Town of Segovia and its Aqueduct）

塞哥維亞位於馬德里西北約 100 公里，是一座歷史悠久的城市。古城內完好保存了約有二千年歷史的羅馬水道橋，成為當地最壯觀的景點。這座雙層拱洞結構的建築，至今仍發揮供水作用。古城還保存了很多中世紀的建築，如阿爾卡札哥德式大教堂等。塞哥維亞古城及其水道橋於1985年被列入《世界文化遺產》名錄。

# 13. 托萊多（Toledo）

托萊多位於馬德里西南約 70 公里。這座城市曾先後被羅馬帝國、西哥德王國統治，更曾是伊斯蘭王國與基督教國家戰鬥的前哨，因此是猶太教、基督教和伊斯蘭教文明並存和共同孕育的古城，完好保存了三大宗教的建築，並有王宮、城牆等多處古建築。托萊多歷史城區於 1986 年被列入《世界文化遺產》名錄。

# 14. 阿爾罕布拉宮（Alhambra）

阿爾罕布拉宮位於西班牙南部格拉納達市郊，由伊斯蘭統治者於 13 世紀在軍事要塞的基礎上興建。建築群建在山崗上，包括當時統治者的宮殿、清真寺、城堡和庭園，具有鮮明的阿拉伯文化色彩。阿爾罕布拉宮連同格拉納達的赫內拉利費花園、阿爾拜辛住宅區，於1984年被列入《世界文化遺產》名錄。

# 15.科爾多瓦歷史中心

# （Historic Centre of Cordoba）

科爾多瓦位於西班牙南部，是一座由羅馬人於公元前建立的城市。穆斯林人在中世紀佔領西班牙南部後，於科爾多瓦興建了多座清真寺、宮殿和公共建築。其中科爾多瓦清真寺擁有 800 根圓柱和近四百個雙色馬蹄拱門，是穆斯林在當地留下最美的建築物。

# 16. 昆卡歷史古城

# （Historic Walled Town of Cuenca）

昆卡位於西班牙中部，地處馬德里和華倫西亞之間。當地處於斷崖上，在中世紀是重要的防禦位置，至今成為一座保留了完好中世紀建築的歷史小城。古城最著名的地標，是大部分面積都伸到懸崖的懸屋，昆卡因而被稱為「中了魔法的城市」。古城內還有西班牙第一座哥德式大教堂。昆卡歷史古城於1996年被列入《世界文化遺產》名錄。

# 17. 奔牛節（Festival of San Ferm5n）
