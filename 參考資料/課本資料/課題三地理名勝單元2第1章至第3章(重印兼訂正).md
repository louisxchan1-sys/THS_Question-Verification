# 1 景點的作用與功能

景點在旅遊業中佔有重要位置。各旅遊目的地為了增加旅遊吸引力，都不斷發展及完善旅遊景點。

# 1.1 甚麼是「景點」？

# 1 「景點」的定義

# 思考點

你最近去過哪一個景點？它有哪些吸引你的特質？

綜合學者的觀點，「景點」（Attractions）有以下定義：

• 通常是某個地區的特色，可以是地方、場地或焦點活動；  
• 必須對遊客具吸引力；  
• 具開發潛力；  
• 為遊客提供有趣、愉悅的體驗，滿足他們的消閒需求；  
• 可作為一個景點進行管理，滿足遊客；  
• 提供合宜的設施和服務，其水平要迎合且滿足遊客的需要及利益；  
會收取或不會收取入場費。

![](images/7ba6f349c308a9c29280e82582cd0c1c3b240c60282421ef2a54369cb5607e10.jpg)

# 例子庫

地方：一個能吸引遊客的樹林、峽谷、山峰、河流、湖泊、瀑布、冰川、草原、沙灘、沙漠等，可以是一個景點。  
• 場地：一個能吸引遊客的古跡、建築物、主題公園、遊樂場、動物園、博物館、演出場地、球場等，可以是一個景點。  
• 焦點活動：一個能吸引遊客的節日慶典、文化表演、大型展覽、體育比賽、動物遷徙等，可以是一個景點。

# 2 「旅遊景點」與「旅遊目的地」的分別

根據學者的看法，「旅遊景點」與「旅遊目的地」之間存在分別：

. 「旅遊景點」一般屬單一具特色的個體，是可簡單劃分的地理區域。  
C 「旅遊目的地」包括多個景點，並為遊客提供所需基本設施和服務的較大區域。

# 發展「旅遊景點」與「旅遊目的地」的注意事項

景點對遊客有重要拉力，是吸引遊客到訪的主要資源。假如沒有旅遊景點，遊客亦不會前往旅遊目的地，更不需要提供其他旅遊設施和服務。因此，旅遊目的地的市場策略往往會傾注在景點的推廣上，這就會使遊客將景點視作目的地的象徵。

可是，旅遊目的地的吸引力因人而異，而且會隨遊客的興趣和時間等因素改變。根據「旅遊目的地生命週期」的理論，當一個目的地踏入「停滯」階段，則部分景點對遊客的吸引力下降，周邊的設施和支援服務亦會作出調整。整體而言，如果旅遊目的地能發展出多個不同類型的景點組合，當地對遊客的吸引力會較大，其生命週期也較長。

旅遊景點與旅遊目的地的可達度，在發展階段同樣值得留意。大多數遊客會選擇較容易前往、較節省運輸時間的旅遊目的地。因此，旅遊目的地能發展出方便遊客的交通運輸系統，對擴大遊客來源地和遊客流量十分重要。

# 1.2景點在旅遊業所起的作用

景點在旅遊業中是非常重要的，所起到的作用包括：吸引遊客到訪、為旅遊目的地樹立形象、完善目的地交通配套、促進目的地經濟發展、帶動目的地相關行業發展和推動旅遊業可持續發展。

# 吸引遊客到訪

景點是重要的拉動因素，能夠吸引遊客到訪目的地。沒有景點，目的地便沒有遊客，旅遊業亦無法發展起來。因此，各地為了增加對遊客的整體吸引力，都不斷發展多元化的景點。

![](images/343980a9742590fee890e574547c618befe0433326beba4305bb9e699c0aa458.jpg)

# 例子庫

香港政府一直推動旅遊業發展，如於 1999 年與迪士尼樂園達成協議，在竹篙灣興建主題樂園；於 2003 年與企業合作，在尖沙咀興建星光大道；批准建造昂坪 360 纜車等，以提高香港的整體旅遊吸引力。

# 為旅遊目的地樹立形象

獨特的旅遊景點，可替目的地樹立鮮明的旅遊形象，令遊客由景點而直接連繫到旅遊目的地。這種地標式景點，由於具有深入民心的形象，往往能吸引大量遊客選擇前往。

# 3 完善目的地交通配套

主要景點的存在，可促使目的地完善交通運輸系統，以及興建酒店住宿、餐飲服務、電訊網絡等配套，以便利遊客，增加當地的吸引力。與此同時，當地居民亦可從中得益，享用較過去便捷的設施和服務。

![](images/d1db80c10a4843a0d03edf556a9bf9bbfb9abcedbcbb546799474b55087d78e9.jpg)

# 例子庫

• 為了配合香港迪士尼樂園的開幕，香港政府批准港鐵興建迪士尼線，以方便遊客到樂園及附近的迪欣湖活動中心遊玩。  
• 位於湖南西部的張家界，隨着知名度越來越高，當局除了發展高速公路，更興建了張家界荷花國際機場，以方便國內外遊客到訪。

# 促進目的地經濟發展

景點可吸引遊客前往目的地，而遊客在酒店住宿、餐廳飲食、交通運輸、消閒娛樂、購物等方面的消費，除了為當地創造相關就業職位，還會帶來直接的經濟收益，並透過乘數效應，促進目的地的經濟發展。

# 5 帶動目的地相關行業發展

景點為目的地帶來的遊客，不但可刺激當地旅遊業的發展，而且會令零售業、手信業、建築業、金融保險業等行業受惠，帶動各相關行業的進一步發展。

# 1.3成功旅遊景點的特性

世界各地分布着不同的旅遊景點，而這些景點各有不同的魅力。不過，成功的旅遊景點普遍具有高品質、真實性、獨特性、吸引性、活動選擇和可達度等共通的元素。

# 1 高品質

外觀良好：具有良好外觀的旅遊景點，即具備美學特徵和觀賞性，可讓遊客在美感中獲得精神的滿足。

保護完好：開發、保護得當的旅遊景點，能夠保持景點的外觀，避免遊客對景點有破落、過氣的不良觀感。

營運暢順：旅遊景點營運暢順，能有效維持秩序，以及提供清晰的指示牌、解說、洗手間、停車場等設施，可讓遊客有舒適的體驗。

友善款待：旅遊景點向遊客提供友善的款待，員工態度誠懇有禮、具有良好的溝通技巧、主動而迅速協助遊客解決問題，均能提升遊客的滿意度。

# 真實性

遊客在觀賞景點時，可感受到景點的真實性，包括旅遊目的地營造的「地方感」，即能反映出社區獨有的社群面貌、地方特色、傳統文化等，從而讓遊客獲得真實的本地體驗。

![](images/7b60bb2dfdee7f3d62390b8f3102be8aa29da7a64a8d1fbac67a9986e9f66b7a.jpg)

# 例子庫

澳門巴黎人鐵塔按法國巴黎艾菲爾鐵塔一半比例設計，雖然能吸引不少遊客參觀，但有些遊客會認為始終不是在巴黎觀賞艾菲爾鐵塔，心裏仍會想親身到巴黎參觀真正的艾菲爾鐵塔，並一併感受當地的城市氛圍。

# 獨特性

景點的獨特性，主要表現在附近地區都沒有類似的景點，使其成為特有的景觀。這既可增強景點的吸引力，同時可避免與其他地區出現競爭。

![](images/9477b18fbdd24187728761160bd2be2418700a9da6efdb7d378463af504966b8.jpg)

# 例子庫

南非的好望角，是非洲大陸的最南端，也是大西洋和印度洋的交匯處，因其地理獨特性，成為著名的旅遊景點。

# 5 活動選擇

旅遊景點如能提供一系列多元化的活動給遊客選擇及參與，不但會增加遊客的新鮮感，也能一次性滿足遊客的各項需要，令當地對遊客的整體吸引力提高。

![](images/c8d12df92855c35325842ee0c0ac442c79715f4c6775c0fee6f2775b491088d9.jpg)

# 例子庫

迪士尼樂園、環球影城等主題樂園，設有多種遊戲，同時提供表演、餐飲、購物、住宿等活動，可讓遊客有不同的體驗，並滿足遊客各項需要，因而能成功吸引大量遊客。

旅遊景點如能不時推出新的活動項目，或定期更新展覽品，亦能維持景點對遊客的新鮮感，吸引更多遊客到訪，使整體訪客人數上升。

![](images/f8dc0adad721d8279388cec3c1fe0ff4902ae055f3f3f492e208415270afb3e7.jpg)

# 例子庫

香港海洋公園自 2008 年起，每年十月會舉辦「哈囉喂」萬聖節節慶活動，把部分場地改建成鬼屋和興建一些臨時鬼屋，以及安排鬼怪巡行，曾成功揭起入場熱潮，令入場人數大幅提升。

# 6 可達度

遊客出遊時，會傾向考慮可達度高的景點作為旅遊目的地。因此，具有四通八達的交通網絡和便捷交通系統的景點，對遊客的吸引力較大，遊客的到訪人次亦會較其他類近的景點為多。

# C 宗教神聖事物風貌

# 遊客被歷史或文化資源吸引的原因

歷史尋根： 部分遊客可能為了前往與其文化背景相同的地方，了解與個人家族有淵源的歷史，從而獲得歸屬感。例如一些港澳人士和海外華僑，會到內地旅遊，欣賞中華文化相關的古跡文物，體驗祖國的文化；一些祖籍歐洲的美國人或加拿大人，會到歐洲旅遊，參觀古城古鎮，認識其祖先曾生活過的地方等。

精神審美： 不少遊客希望在旅遊過程中欣賞美好的事物，獲得精神上對美感的滿足。中國萬里長城、希臘雅典神殿等宏偉的歷史建築物，或蒙羅麗莎油畫、大衞雕像等精美的藝術品，便能吸引和滿足這些遊客的需求。

體會歷史意義：歷史遺址、建築、文物等，背後都存在着某些歷史意義，部分熱愛歷史的遊客，便由於受到這些歷史意義的吸引，希望親臨歷史現場，感受歷史的氛圍。例如有遊客會前往中國武昌起義爆發的武漢；有遊客會前往美國珍珠港歷史陳列館等。

滿足好奇心：人們都充滿好奇心，他們到外地旅遊，除了吃喝玩樂，亦會希望認識其他國家或地區民眾的歷史文化、生活方式、社會風俗等。部分人更是因為被當地的傳統習俗、音樂舞蹈、手工藝等所吸引，而前往目的地。

# C 地貌

大自然中存在不同的地貌，當中奇特的地貌，可以形成景點，吸引大批遊客前往觀賞，以及進行各種活動。

# a地形

地形指地表分布的固定物體所呈現的各種高低起伏的狀態，包括山岳、岩石、沙漠、草原、峽谷、火山、島嶼等。

遊客除了可以欣賞地形的景觀外， 還可以因應環境，進行攝影、行山、 攀岩、騎駱駝、騎馬、滑雪等活動。

# b 水體系

水體系指自然界天然水體所構成的各種狀態，包括湖泊、河流、瀑布、海灣、冰川、珊瑚礁等。

遊客除了可以欣賞水體系的景觀外，還可以因應環境，進行攝影、游泳、獨木舟、風帆、釣魚、潛水等活動。

# D 自然植物

自然植物泛指在野生環境天然生長的植物。自然植物除了是重要的自然資源，對生態平衡十分重要外，也可以成為吸引遊客的景點。

野生動物泛指在野生環境繁殖成長的動物。在自然環境下觀察野生動物，受到喜愛動物生態的遊客歡迎。為了保護野生動物，以及保障遊客的安全，不少國家設立了陸上或海上野生動物保護區，遊客必須乘坐指定的遊覽車輛、船隻，在盡量不騷擾野生動物的安全環境下，觀賞動物在野外的生活形態。

# 遊客被自然野生資源吸引的原因

精神審美： 大自然的各種天然美景，吸引遊客前往或身處其中。遊客在欣賞這些美麗的景色時，會得到精神上的滿足。

滿足好奇心：大自然中存在各種奇觀，如火山爆發、噴泉、地下洞穴、奇岩怪石、動物大遷徙等，遊客為了滿足好奇心，於是親身前往觀賞，以增廣見聞。

參與運動： 自然界中不同的地形、水體系等，為熱衷運動的遊客提供了行山、攀岩、洞穴探險、森林探險、騎馬、游泳、潛水、獨木舟、滑浪、滑雪等活動所需的地理環境。

促進健康： 到大自然觀賞野生植物和動物，或到郊野地區欣賞各種地貌、季節景觀，以及參與野外運動等，可讓遊客遠離城市的煩囂，舒緩緊張的生活，促進身心的健康。

# B 有長短不一的時限

活動項目只會在一段指定的時間內舉辦，遊客在其他時間前往同一目的地，將無法參加或參與有關活動。各活動項目的舉辦時間長短不一，可以長至數星期，也可以短至數小時。

![](images/da3c292770ceac97a0049448945e9ebea9e557c61d51c1eaaac7bd758665c8cb.jpg)

# 例子庫

巴西的嘉年華會每年在復活節前 40 天登場，並一連舉辦五天，如遊客在這五天以外到訪巴西，就無法參與該嘉年華會。  
• 世界很多大城市每年都會舉辦除夕倒數活動，但各城市的活動舉辦時間不一，有的數小時，有的可能只有不足一小時。

# C 固定或不定期舉辦

不少活動項目是固定每年舉辦的，但亦有部分活動項目是不定期舉行的，這視乎目的地在資源分配、人員設施、社會環境等方面能否配合。

![](images/880f79267b5528f5f5e3ba22055ba9f16bdadd91bb51e095fb91792ca94c98f4.jpg)

# 例子庫

• 泰國水燈節是每年泰曆十二月十五日（公曆 11 月），泰國固定舉辦的傳統節日慶典，民眾會按傳統習俗慶祝節日。  
國際汽車聯會於 2016 年首次在香港中環海濱賽道舉辦電動方程式大獎賽，在連續舉辦三年後，不設香港站。

# 消閒康樂

消閒康樂景點指專為遊客提供各種度過閒暇時間，並在過程中得到快樂的活動。這類景點包括日光浴、體育活動、夜生活、賭博和購物等 。

# A 日光浴

陽光與海灘向來是讓遊客嚮往的天然景點。每到夏天，就有很多人到海邊享受日光浴。隨着社會越來越富足，不少居住在寒帶及温帶地區的人，會於冬天選擇到熱帶地區旅遊。他們在享受陽光與海灘的同時，還會進行各種水上活動。

# E 購物

# C 動物園

動物園會蓄養多種動物，並根據動物的棲息環境，為牠們設計居所。有關居所一方面方便遊客觀賞，作娛樂及教育用途，另一方面保護野生動物，同時作科學研究之用。很多動物園更會發展繁殖計劃，以增加瀕臨絕種動物的數量。

# 2.3 按等級劃分景點：首選與次選景點

遊客前往的旅遊目的地，通常有多個旅遊景點，它們的性質和種類都不一樣，但由於旅遊時間有限、費用預算不足、景點規模很大或遊客體力不足、個人喜好等原因，遊客要對景點作出選擇，只能遊覽部分景點。

按等級景點可分為「首選景點」和「次選景點」兩大類。

# 首選景點

「首選景點」是遊客在旅程中必然的遊覽選擇，其特徵如下：

• 是驅使遊客前往該旅遊目的地的首要動機；  
• 一般是旅遊目的地最具代表性、最受遊客歡迎的景點；  
• 通常具有較大的面積和規模，遊客願意花最多時間遊覽，以接觸景點的所有元素，獲得一種旅程物有所值的感覺。

# 次選景點

情況許可下，遊客在旅程中會選擇到一些「次選景點」遊覽，以豐富旅遊體驗。「次選景點」的特徵如下：

般鄰近首選景點，或在前往首選景點的交通要道上，遊客可在參觀完首選景點後，順道遊歷次選景點；  
• 通常面積和規模較小，遊客會用較短的時間遊覽；  
• 可當作旅程的中途站，如作休息或用餐等，使遊客回復精力及為旅程加添新意；  
• 行程中安排的首選景點，未必是所有家庭或團體成員的意願，在旅程中加插一些次選景點，可安撫個別成員和照顧他們的需要，是一種妥協的解決方法，盡量令所有人盡興而歸。

![](images/aca5783fe26742ccd2aeaa27d29c7f38d3f7d012cf25130b1f3d2c00049373a1.jpg)

# 例子庫

有家庭在旅程中的首選景點是柬埔寨的吳哥窟，會花三天時間遊覽各古跡文物。不過，部分家庭成員對吳哥窟的古跡文物興趣不大，午膳或晚餐後順道安排到購物中心購物，或到劇場欣賞民族歌舞等，作為次選景點，可照顧喜愛購物及欣賞表演的成員，令他們的旅遊需要得到滿足。

實際上，「首選景點」和「次選景點」會因應不同遊客的旅遊需要、個人喜好、意願態度等，而各有差異。

# B 幫助旅遊目的地宣傳推廣

為了吸引更多遊客到訪，旅遊目的地需要積極展開對外宣傳推廣工作。一個鮮明、獨特的旅遊形象，可讓目的地在宣傳推廣上更容易突出重點，對外地遊客產生深刻的印象，並將有關形象與目的地直接連繫起來。

# A 高度概括性和符號意義

旅遊目的地的形象往往具有高度概括性，甚至被賦予一種象徵意義符號的作用。這種形象是由目的地的各種旅遊產品和因素結合而成的總體印象，雖然不完全反映目的地的真實情況，但已代表了特定的旅遊體驗。
