# 1 與顧客的溝通

在旅遊與款待業中，有效的溝通非常重要。這不但能把旅遊產品和服務的訊息傳遞給顧客，還可以更好了解顧客的需要，幫助企業推出更適切的產品和服務，有利增加顧客的忠誠度。以下我們會深入探討與顧客的有效溝通。

# 1.1 溝通概述

溝通是指兩個或以上的人或組織互相傳遞訊息的過程，一方可以文字丶說話丶肢體動作或行為等發出訊息，並由另一方用五感去接收訊息。

不過，並非所有的溝通都能成功，雙方的溝通過程可能會受到各類「噪音」影響。至於成功接收到訊息的一方，會作出「回饋」，即向發出訊息的一方傳回訊息，讓對方知道已接收到訊息，以及回應有關訊息。

# 噪音的影響

影響溝通過程的各類「噪音」，包括嘈吵的環境丶發出訊息者口齒不清、表達的字跡潦草難明或文意不通、接收訊息的人思緒混亂或有很多煩惱等。這些都會阻礙訊息的發放或接收，導致雙方未能有效溝通。

因此，要確保服務過程能有效溝通，服務人員除了要具備清晰的表達能力外，亦須具備洞察環境因素和顧客情緒的能力。

# 回饋的重要性

回饋在溝通過程十分重要，它可以鼓勵雙方繼續溝通，令溝通更具建設性。試想像一下，假如你跟別人說話，對方一直毫無表情，亦沒有回應，你可能索性不再與對方說下去。相反，你跟別人說話，而對方在過程中不時微笑點頭，並會加上一兩句評語，分享他的看法，你會感到對方正在聆聽你的說話，希望與對方溝通下去。

作為顧客服務的員工，與顧客溝通時情況同上面一樣，一方面需要留意顧客的回饋，如對方沒有反應，可能是顧客對產品和員工說的內容不感興趣，員工便要改變服務策略；另一方面，員工要多給予顧客正面回饋，讓對方感覺你正專注於聆聽他的說話，感受到你的尊重。

# 溝通的途徑

簡單而言，服務人員與顧客的溝通，主要有以下三種途徑：

• 書面溝通  
• 口頭溝通  
• 非口頭溝通

以下我們會深入認識不同的溝通途徑。

# 1.2 書面溝通

書面溝通指把訊息以文字表述，然後傳遞給接收者。在通訊科技發達的今天，傳統的書面溝通仍是主要的溝通方式。在旅遊與款待業，企業與顧客丶員工與員工之間的書面溝通，包括所有重要的協議丶紀錄丶報告、告示和傳單等，都是以傳統實體印刷或電子媒介存檔及分發。

# 書面溝通的要求

企業與顧客的書面溝通一般以文字為主。雖然白紙黑字，但是要準確傳遞訊息，避免誤會，員工應多加注意。

書面溝通各式各樣，員工要因應目的調整表達方式。例如公函的格式和內容要正確；紀錄內容要詳盡和精準；海報內容要精簡而吸引等。不過，以上的書面溝通都有相同而重要的要求：準確。

準確的表達有賴於：

正確的語法：文法要正確，不可有錯字；  
• 扼要的內容：詞不達意容易引起誤會，過多而混亂的內容會令對方難以理解；  
• 標準的格式：個別形式有一定格式要求，如公函和官方電子郵件等，要謹慎跟從。

文字表達準確才會給予顧客一種專業的形象，有時表達錯誤或模糊更會導致企業蒙受損失。即使現時有很多電腦軟件可協助員工校對，但員工也不宜過於倚賴科技，人手核實才可減少內容上的失誤。很多企業都會有多於一位員工參與閱讀及校對，把書面溝通的錯誤減至最少。

# 書面溝通的常見方式

常見的書面溝通方式有公函、便條、名片、小冊子與產品目錄、海報和通告幾種。

# A 公函

• 公函即正式的或官方的公文，是企業或機構之間往來使用的一種文體。  
• 公函可以是單一式或標準式，前者給予指定顧客，後者可同時發給多位顧客；  
• 在各種書面溝通方式中，公函的格式和要求最為嚴謹，一般要印在印有企業名稱丶標誌丶電話、通訊地址和網址等的公司信紙上。  
• 根據香港旅遊業議會指引，旅遊業機構須於公函上列明其註冊編號。

# B 便條

• 便條是一種簡便的短信，用於把簡單的事項告訴他人，不會用作傳遞重要訊息。  
• 便條常用於提示對方處理文件丶請顧客簽收和寄回文件等，通常附夾於正式公函和文件上。  
便條有指定的格式和設計，與公函相似，但大多面積較信紙小，並印有預設信息，如「請予存案」、「請寄回收據」等。  
• 若是企業給予顧客的便條，如酒店提示顧客可享用桌上的歡迎朱古力，表達格式可能刻意輕鬆和非正式，以拉近與對方的距離。

# C 名片

• 名片會印有企業和員工的名字、電話、地址和網址等聯絡方式，用作自我介紹或方便顧客直接聯絡。  
• 名片還會印有企業的標誌，以及個別員工的職銜和聯絡電話等資料。  
• 部分企業更會在名片印上服務承諾丶公司業務或聯營公司名單，甚至員工照片，以建立專業形象和拓展業務。  
• 儘管隨着科技發達，部分企業開始使用電子名片，員工資料可直接儲存在智能電話簿內，但實體名片仍然流行。

# D 小冊子與產品目錄

• 旅遊與款待業的不少企業，如旅行社、餐飲機構等，經常會印製及派發小冊子與產品目錄，或將電子檔案放到互聯網，向顧客宣傳產品和服務。  
• 小冊子及產品目錄須分類清晰，便於閱讀，以免顧客失去閱覽興趣。  
• 由於印製小冊子與產品目錄的費用有限，加上能把宣傳訊息直接傳遞予潛在顧客，所以為企業常用。

# E 海報

• 海報屬於設計廣告，企業用來把精簡概括的產品和服務訊息，張貼於潛在顧客常出現的地方，以收宣傳效果。  
• 海報的文字內容通常較小冊子少，主要利用圖像和文字設計，吸引顧客注意。

# F 各類通告

• 通告是企業或機構向顧客公布或傳達事項、措施的文件，例如交待機構營運時間表、開放時間、設施位置圖丶門票銷售情況和入園安排等資料。  
通告的內容以重要資訊為主，表達清晰扼要，務求讓顧客看完就清楚明白。

# 書面溝通的五 C 要點

簡單而言，書面溝通要符合五點要求（5C）:

1. 簡潔度（Concise）: 簡潔句子
2. 正確度（Correct）: 內容真實
3. 清晰度（Clear）: 內容精要
4. 完整度（Complete）: 內容齊全
5. 禮貌度（Courteous）: 表達有禮

# 利用電子媒體的書面溝通

配合社會科技發展，現時企業與企業之間丶企業與顧客之間的書信往來，大多改以電子媒體進行。透過電子郵件丶短訊，以及WhatsApp等社交媒體的溝通已相當普遍。企業的宣傳品丶確認信甚至重要通告等，都會利用電子媒體發出。

儘管有電子校對軟件協助，但由於電子媒體十分方便，書信往來更為頻繁，大意導致出錯的機會亦增多。因此，企業和員工使用電子媒體作書面溝通反而要額外留心。

例如在寄出電子郵件時，要注意以下幾點：

# A 有禮得體

傳送給顧客的電子郵件是公函的一種，語句要清晰易明，行文也不能輕佻無禮，要展示對顧客的尊重。例如避免使用縮寫或網絡簡寫，以及不易理解的術語、俗話。

# B 格式專業

員工要用書信的標準格式去寫郵件內容，不可隨便。例如要有上下款和祝福語。

# C 檢查接收者資訊

寄出郵件前，應檢查輸入發送的電郵地址和收件人資料是否正確，否則無法傳遞給對方。

很多時候，員工會將重要郵件，如回覆顧客的投訴信等密件，以副本形式一同傳予上司作備案。員工應確保密件接收者的資料保密。

# D 檢查附件

寄出郵件前，員工宜再次檢查有否將附件夾附，亦須小心避免夾附其他非必要的附件。

• 加強企業即時輸出和即時回收訊息的能力，使書面訊息能像面對面或電話的口頭訊息一樣快捷地傳遞。  
可作遠距離和跨地域的書面溝通，方便跨國企業和員工作正式文字溝通。  
員工可以在家中或其他地方傳送電子訊息，使員工之間的溝通交流更隨時隨地，工作更為方便。

# 1.3 口頭溝通

口頭溝通指所有由發訊者透過說話的方式，傳達訊息予接收者的過程。口頭溝通的方式可包括面對面的推銷、一般口頭查詢、電話交談、不同語音通訊軟件和各種社交媒體的語音通訊等。

我們每天都在進行口頭溝通，但有時未必能有效將訊息傳遞給接收者。在旅遊與款待業中，口頭溝通的有效性十分重要。員工的表達丶提問和聆聽技巧會直接影響服務的質素。

# 1 口頭溝通要注意的地方

員工與顧客利用口頭溝通時，應注意以下地方：

• 語速：語速要適中，避免過快或過慢，影響顧客接收訊息；  
用字：用字要準確，避免使用行內術語丶太艱深的字詞或不適當的方言和俗語；  
• 聲線：注意聲線和音量，聲音太大或聲音太過尖銳，都會令對方感到壓迫和聽得不舒服；聲音太輕或說話過於低沉，均會使對方聽得不清楚和感到不耐煩。  
• 語氣：語氣要平靜丶有禮且肯定，讓對方感到舒服，並安心回應。  
• 態度：不可說謊丶誇大或隱瞞事實。  
• 精準：不應轉移話題，宜準確回答問題。  
觀察：留意顧客的身體語言，以感受其情緒變化，即時隨機應變，調整說話內容。

# 口頭溝通需要的聆聽技巧

與顧客溝通時，員工很多時間需要擔當聆聽者的角色，才可了解顧客的需要，所以專注聆聽對於旅遊與款待業員工非常重要。以下是一些常用的聆聽技巧：

留心對方說話的重點；  
• 專注聆聽，注意力不要被分散，更不可一邊聆聽一邊處理其他事務；  
• 防止分心，可在腦海中或回應時重覆對話中重要的字句，加深印象；  
• 雙眼望着對方，並通過點頭丶微笑和相應的面部表情，給予對方肯定；  
• 對方說話時，切勿無故打斷對方；  
• 可用紙筆記下內容和自己稍後需要回應的要點。

# 口頭溝通需要的提問技巧

口頭溝通過程中，不論顧客表達如何，發問總能進一步澄清你所理解的東西是否正確，以便更清楚掌握顧客的說話內容或要求。不過，提問亦有一定的技巧：

• 適當的時機：應選擇適當的時機提問，不應無故打斷對方說話，可等到對方停頓或說完時提問。  
恰當的問法：選擇提問開放式或封閉式問題，這取決於提問的目的和顧客的接收能力。  
• 相關的內容：所提問題內容要扣連談話主題，不要提問無關的事情或另開話題。  
• 清晰的用字：提問用字要清晰，避免使用顧客不懂的術語，以確保對方明白所問內容。  
• 注意語調：留意個人語調，避免讓對方覺得你語帶懷疑、嘲諷，或表達咄咄逼人；要表現出誠懇的態度，令對方感覺舒服。  
• 避免重覆：說話要簡潔，避免不斷重覆某些內容，以及重覆提問對方已解釋過的問題。

# 4 口頭溝通的的優點與缺點

與書面溝通比較，口頭溝通有以下的優缺點：

# 1.4 非口頭溝通

非口頭溝通指不以語言和文字來表達訊息的溝通方式，包括：使用身體語言、個人儀容及衣著。

# 使用身體語言

我們常會用面部表情丶眼神丶手勢、坐姿和站姿等身體語言表達自己，這些均屬於非口頭溝通。服務員工如懂得運用身體語言，可為顧客留下正面形象；仔細留意顧客的身體語言，則有助理解對方的心情，方便應對。

口頭溝通和使用身體語言很多時是互補的。不過，人會不自覺地將真實的思想感情透過身體語言表露出來。例如當說到興起時，人會很自然提高音量和有較大的肢體動作。因此，員工需注意自己的身體動作，避免顧客誤解或反感。

然而，有時候兩者可以呈現相反的含意。例如顧客口頭上說無礙，但他捲曲身體，可能反映他腸胃不舒服，情況未必適合繼續溝通下去。此時，如員工留意和理解顧客的身體語言，可為對方提供最佳的服務。

# E 空間距離

與別人溝通時，我們很少會和別人身貼身，一般會維持比較舒服的距離。親密的人通常會靠得較近，而陌生人如靠得太近會令我們不安和抗拒。站得太遠，接收訊息未必清晰，以致影響溝通。所以，員工和顧客溝通時，不應站得太靠近對方，宜保持約一米的距離。

# 個人儀容及衣著

個人儀容及衣著也屬於非口頭溝通。旅遊與款待從業員必須整理個人儀容，工作時衣著必須得體及保持潔淨。這能展示對顧客的尊重，並傳達專業的形象。例如：

• 頭髮乾淨、梳理整齊。  
• 面部毛髮修剪整齊，或剃刮乾淨。  
• 避免佩戴過多首飾，而且首飾應是可清潔及無孔的材料。  
• 不宜佩帶眉、鼻、舌、唇飾品。  
• 指甲應修好、乾淨、短且無拋光。  
• 每天開始工作時，制服應是乾淨、整齊的。  
• 鞋子應保持光亮潔淨。

要提供有效率的顧客服務，還可以透過建立顧客資料庫，以掌握顧客正確及最新的資料。越齊全的顧客紀錄，越能幫助公司提供貼心的顧客服務。

# 2.1 保存顧客紀錄

旅遊與款待業的企業都習慣保存各種顧客紀錄，以助改善服務，例如：

• 酒店：知道顧客的喜好，可方便為他們作更合適的安排。例如客人是否吸煙者，客人有否食物敏感，以及有何慣常入住習慣等，對維繫顧客忠誠度尤其重要。  
• 航空公司：記錄顧客的航班紀錄丶旅行證件資料和聯絡資訊等，可為常客提供更貼心的服務。  
• 旅行社：記錄顧客的姓名和通訊資料，掌握他們的出遊紀錄， 如出遊地點和消費金額等，有助針對顧客的旅遊模式，在日後推廣時向對方提供合適的旅遊資訊。

由此可見，企業會分析顧客的資料，作針對性的市場推廣，例如研究顧客的消費頻率和消費口味等，推算他們未來的消費喜好，以調整銷售策略。這不但有助企業留住現有顧客，同時確保自己比對手有更大的優勢。

# 2.2 顧客資料的保密

顧客資料的準確度對分析相當關鍵，所以企業應提供足夠訓練予員工，令他們懂得使用資料輸入的裝置和軟件，以及細心運用有關數據，確保不會出錯。

至於確保顧客資料的安全性亦十分重要。所有顧客紀錄都受法律保護，企業有責任防止資料外洩。因此，企業要做好顧客資料保密工作，確保只有特定員工才可取得相關資料，而員工不應私下收藏這些資料。這一方面保障顧客利益，另一方面防止員工將資料外洩給對手，造成公司利益受損。
