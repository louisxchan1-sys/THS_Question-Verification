# 地理景觀

非洲東面是印度洋，北面是地中海，西面是大西洋，南部與南極洲相望，中間被赤道橫過。500 米以上的高原佔全洲面積六成以上，非洲又被稱為「高原大陸」。其中著名的有埃塞俄比亞高原、東非高原及南非高原。

非洲東部的東非大裂谷長達 5 000 多公里，是地球陸地上最長的裂谷帶。非洲北部的撒哈拉沙漠面積約900萬平方公里，是世界最大的沙漠。騎駱駝欣賞沙漠風光，是撒哈拉沙漠周邊國家其中一項主要的旅遊項目。

位於肯尼亞及坦桑尼亞交界處的乞力馬紮羅山，海拔5 895米，是非洲的最高峰，也是世界其中一座最高的火山。峰頂終年積雪，形成赤道雪山的奇觀，常被稱為「非洲屋脊」。

# 4 氣候

非洲被赤道橫貫中部，全洲四分之三的土地位於熱帶地區，超過九成的地區全年平均氣温在 20 度以上，沒有明顯的冬季及夏季。全洲三分之一的地區全年平均降雨量不足 200 毫米，全年高温乾燥。

非洲氣候帶南北對應，以赤道為中軸，向南北兩方，分別由熱帶雨林氣候依次遞變為熱帶草原氣候、熱帶沙漠氣候及温帶地中海氣候。

# 5 人文景觀

非洲是人類起源地之一，不少遠古人類的考古遺址是旅客關注的旅遊點。尼羅河下游的埃及是古埃及文明的發祥地，留下很多古跡，如吉薩大金字塔就是世界古代七大奇跡之一。

北非是古代迦太基、希臘、羅馬等古代文明的重要地區。突尼斯的迦太基遺址、古羅馬劇場，亦是熱門的旅遊地點。

公元 7 世紀後，信仰伊斯蘭教的阿拉伯帝國開始向非洲擴張，使阿拉伯文化和伊斯蘭教對北非產生了巨大影響。現在北非許多城市都保存了古代的清真寺，成為旅客的觀光對象。

位於埃塞俄比亞的拉利貝拉岩石教堂，建於公元 12 世紀，有「非洲奇跡」之稱，是非洲著名的世界文化遺產。

# 4.3 摩洛哥

# 國家簡介

摩洛哥位於非洲西北端，國土面積 46 萬平方公里。摩洛哥東部和東南部與阿爾及利亞交界，南部是西撒哈拉，西臨大西洋，北面是地中海，隔着直布羅陀海峽與西班牙相望，處於地中海西端出入口，甚具戰略地位。

# 2 歷史文化

摩洛哥在歷史上曾被腓尼基人、羅馬帝國和拜占庭帝國等佔領。公元 7 世紀，阿拉伯人進入摩洛哥，並經歷了數次王朝更替。摩洛哥在 20 世紀初，曾先後被西班牙人和法國人統治。1956年，摩洛哥取得獨立，成為一個實行君主制的伊斯蘭國家。

# 資料室

# 摩洛哥習俗禮儀

摩洛哥人喜歡綠色和紅色，並以紅色作為國旗的主色，而穿著較為開放，年輕人受西方文化影響喜愛穿流行服飾，成年男女則多穿摩洛哥風格的長袍，女士穿著的摩式傳統長袍和頭巾色彩豔麗。

由於宗教信仰原因，摩洛哥人不吃豬肉，不飲酒，也很少抽煙。未經主人許可，不脫鞋不得進入其宅居。

# B 氣候

摩洛哥氣候多樣，受斜貫全境的阿特拉斯山脈影響，西北部和東南部的氣候截然不同。西北部沿海平原屬温帶地中海氣候，夏季炎熱乾燥，冬季温和濕潤，月均氣温為 13℃，7 月氣温介乎 22℃至 29℃，當地更享有「北非花園」和「烈日下的清涼國土」的美譽。東南部內陸山區夏季炎熱乾燥，冬季寒冷且多有降雪。撒哈拉沙漠邊緣則呈現乾燥的沙漠氣候。

摩洛哥整體降雨量呈由北向南、由沿海向內陸逐漸減少的趨勢。自北向南主要城市年平均降雨量，由 810 毫米一直降至289毫米。南部接近撒哈拉沙漠地區，降雨量更接近0毫米。

# 旅遊概況

# A 交通便捷度

根據國家商務部資料，摩洛哥是連接歐洲、非洲、中東的交通樞紐。全國擁有 16 個國際機場，重要的有卡薩布蘭卡穆罕默德五世機場和馬拉喀什梅納拉機場。其中卡薩布蘭卡機場旅客量佔四成以上，航班目的地遍布全球 105 個城市，主要是歐洲、非洲和中東城市。

摩洛哥的公路網絡在非洲國家中名列前茅，且道路狀況良好。截至 2023 年，公路總里程達 5.7 萬公里，高速公路總里程約 1 800 公里。

鐵路方面，截至 2019 年，摩洛哥鐵路總長 2 295 公里，超過六成是電氣化火車。其中高速鐵路有 200 公里，於 2018 年通車，連接丹吉爾和卡薩布蘭卡，是非洲大陸首條高鐵。

# B 旅遊資源

摩洛哥環境優美，西北部海灘綿長，陽光明媚；中部群山環繞，阿特拉斯山脈終年積雪；南部是撒哈拉沙漠。加上摩洛哥歷史悠久，留下不少千年古城和名勝古跡，近代又曾被西方殖民統治，使該國孕育出混合了阿拉伯、歐洲和非洲三種文化的特有風情，吸引了來自世界各地的旅客。

根據聯合國教科文組織資料，截至 2024 年，摩洛哥共有 9個世界遺產，全部是文化遺產。

# C 旅遊競爭力

根據世界經濟論壇發表的《全球旅遊業競爭力報告2024》，摩洛哥在全球排名82位。

旅遊業是摩洛哥重要的支柱產業，近年當地旅遊部門推出了多條特色旅遊線路，包括文化旅遊、以療養為主的海濱旅遊、以自然湖泊和體育旅遊為特色的旅遊，以山林、綠洲和地方人文特色為主的綠洲旅遊線路，覆蓋不同的旅遊城市和地區。

# 衞生環境

摩洛哥的衞生環境普通。根據世界衞生組織資料，摩洛哥屬血吸蟲病感染低風險國家。

# 簽證要求

根據摩洛哥外交部資料，截至 2024 年，有 70 個國家或地區的公民可免簽證入境摩洛哥，包括中東的沙特阿拉伯、阿聯酋、科威特、突尼斯，亞洲的中國內地、中國香港、中國澳門、新加坡、馬來西亞、日本，以及歐盟成員國和北美洲的美國、加拿大、墨西哥，南美洲的巴西、阿根廷、智利，大洋洲的澳洲、新西蘭等。

根據香港入境事務處資料，香港特別行政區護照持有人最長可免簽證逗留摩洛哥30日。

# 8. 德吉瑪廣場（Djemaa el-Fna）

德吉瑪廣場位於馬拉喀什舊城，是摩洛哥最古老、最熱鬧的廣場。德吉瑪廣場從早到晚都有各種小吃、商品攤販擺賣，並有耍蛇、耍猴和各種傳統演奏表演，而每當夜幕降臨更為熱鬧，所以又被稱為不眠廣場。德吉瑪廣場是唯一被聯合國同時評為「世界物質文化遺產」和「世界非物質文化遺產」的地方。

# 9. 非斯的伊斯蘭舊城（Medina of Fez）

非斯位於摩洛哥北部，是摩洛哥第四大城市。非斯舊城始建於公元 9 世紀，是摩洛哥最早建立的阿拉伯城市，被視為伊斯蘭教其中一個聖地，有「西方的麥加」之稱。舊城內街道狹窄，保存了眾多阿拉伯風格建築，包括世界上最古老的伊斯蘭大學，以及市集、宮殿、民居和清真寺等。

皮革浸染是非斯最重要的手工藝，旅客可觀看到浸染過程，以及五顏六色的染缸。非斯的伊斯蘭舊城於 1981 年被列入《世界文化遺產》名錄。

# 4.4 南非

# 國家簡介

南非位於南半球，地處非洲大陸最南端，國土面積 122 萬平方公里，西臨大西洋，南向印度洋，北部與納米比亞、博茨瓦納、辛巴威、莫桑比克交界，斯威士蘭、萊索托被南非國土包圍。

南非有三個首都：行政首都比勒陀利亞 ／普利托里亞、立法首都開普敦、司法首都布隆方丹，這在全球屬特有。

根據國家商務部《對外投資合作國別（地區）指南：南非（2023年版）》，南非2021年人口約6 014萬，其中非洲人種約佔 81%，白種人約佔 9%，其餘是雜色人和亞裔人。南非宗教信仰多元開放，其中近八成人口信奉基督教，其他主要宗教有印度教、伊斯蘭教、猶太教、佛教和原始宗教。根據世界銀行資料，南非是一個多種族國家，官方語言有 11 種，白人主要使用英語及南非荷蘭語，黑人主要語言有祖魯語、柯薩語、蘇圖語。

# 2 歷史文化

南非早期散布不同的土著部落。17 世紀以來，荷蘭人、英國人相繼入侵。1910 年，南非成為英國的自治領。1948 年，南非國民黨上台後，逐步實行種族隔離政策。1961年，南非獨立，成立由白人政府主導的南非共和國，仍然施行種族隔離政策。

經 過 多 年 的 爭取， 南 非 於 1991 年廢除種族隔離政策，並於 1994 年舉行首次多種族參與的全民大選，出現首任黑人總統，實現由少數白人政權向民族團結政府的過渡。

# C 旅遊競爭力

# 4.5 突尼斯

# 國家簡介

突尼斯位於非洲大陸的最北端，國土面積 16 萬平方公里，西面與阿爾及利亞交界，東南與利比亞接壤，北面隔地中海與歐洲的意大利相望。

根據國家商務部《對外投資合作國別（地區）指南：突尼斯（2021年版）》，突尼斯2021年人口約1 266萬，其中阿拉伯人佔九成以上，其餘為柏柏爾人。突尼斯以伊斯蘭教為國教，大多數人口信奉伊斯蘭教，並以遜尼派為主，少數人信奉天主教、猶太教等；阿拉伯語為官方語言，並通用法語。

# 歷史文化

突尼斯在古代是地中海迦太基文明的發源地，後來被羅馬帝國攻滅。此後，突尼斯先後遭汪達爾人、拜占庭帝國、阿拉伯帝國、鄂圖曼帝國吞併。到了 1881 年，突尼斯成為法國的保護國。1956年，突尼斯獨立，並於1957年成為共和國。

# 資料室

# 突尼斯習俗禮儀

突尼斯人大多信奉伊斯蘭教，禁食猪肉、不飲酒，並忌諱以左手傳遞東西或食物。

突尼斯人遇見初相識的朋友，多行握手禮。如遇見熟悉的朋友，不僅熱情握手，還會擁抱。多數突尼斯婦女有戴面紗的習俗，她們不會與男性握手，多以點頭微笑、彎腰鞠躬的方式向對方表示歡迎和敬意。

# 1. 迦太基古城遺址（Archaeological Site of Carthage）

迦太基古城遺址位於突尼斯市東郊，曾是地中海強大的迦太基帝國的首都，始建於公元前 9 世紀。迦太基後來被羅馬帝國打敗，古城亦遭摧毀。後來，羅馬人在原址附近另建新城，但之後遭阿拉伯帝國毀滅。現時，旅客可在古城參觀到城牆、宮殿、神廟、房屋、公共浴室、劇場、競技場、墓地等遺址。迦太基古城遺址於 1979 年被列入《世界文化遺產》名錄。

# 2. 突尼斯舊城（Medina of Tunis）

突尼斯舊城位於突尼斯市內，始建於公元12 世紀，曾是當時伊斯蘭世界其中一個最富庶、最強大的城市。舊城以宰圖納清真寺為中心向四面展開，保留了古老的阿拉伯色彩，包括宮殿、陵墓、伊斯蘭學校、噴泉、塗飾白色牆體的矮屋、曲折蜿蜒的小巷。突尼斯舊城於1979年被列入《世界文化遺產》名錄。

# 3. 巴爾杜國家博物館

# （Bardo National Museum）

巴爾杜國家博物館位於突尼斯城西北郊，是規模僅次於埃及開羅博物館的非洲第二大博物館。博物館是皇宮的組成部分，本身是一座具阿拉伯風格的歷史建築，收藏了近萬年不同時期的文物，包括古希臘藝術品，並以瑰麗多彩的鑲嵌畫而聞名。

# 4. 藍白小鎮（Sidi Bou Said）

藍白小鎮位於突尼斯城東北，全名西迪布賽，是具有地中海氣息的美麗小鎮。這個坐落在地中海邊峭壁上的小鎮，始建於公元 13 世紀，以全是白牆藍窗風格的小屋而聞名，曾被評為世界十大浪漫小鎮之 。

# 5. 蘇斯古城（Medina of Sousse）

蘇斯古城位於突尼斯東海岸，過去曾是伊斯蘭世界重要的

貿易樞紐和軍事港口，是一座典型的伊斯蘭城市。古城保存了土著人聚居區、防禦工事、建有大清真寺的伊斯蘭城區，以及兼具軍事和宗教功能的驛站建築。蘇斯古城於 1988 年被列入《世界文化遺產》名錄。

# 6. 傑姆的古羅馬劇場

# （Amphitheatre of El Jem）

傑姆的古羅馬劇場位於突尼斯中部，是北非現存最大的古羅馬帝國劇場遺址。這座建於公元3世紀的建築，呈橢圓形，可容納3萬5千名觀眾，曾用作觀賞角鬥士決鬥及戰車競賽。傑姆的古羅馬劇場於1979年被列入《世界文化遺產》名錄。

# 7. 開羅安（Kairouan）

開羅安位於突尼斯東北部，位處海岸和內陸山區之間，始建於公元7世紀。開羅安是一座歷史文化名城，有豐富的建築遺址，包括長3公里的城牆、塗上白灰牆的房屋，以及多間清真寺等。其中用大理石和斑岩製成柱子的大清真寺，是北非歷史最悠久、規模最大的清真寺。開羅安於1988年被列入《世界文化遺產》名錄。

# 8. 伊其果國家公園（Ichkeul National Park）

伊其果國家公園位於突尼斯北部，佔地約 1 萬2千公頃，由伊其果山、伊其果湖和沼澤濕地組成。公園是數百種候鳥遷徙的中途站，並擁有兩百多種野生動物和五百多種野生植物。伊其果國家公園於1980年被列入《世界自然遺產》名錄。

# 10. 瑪特瑪他（Matmata）

瑪特瑪他是位於突尼斯中部的一個小鎮，當地有壯觀的丘陵地貌，並保存了原住民柏柏爾人獨特的穴居屋，即仿似中國黃土高原的窯洞房屋。旅客除了可參觀穴居屋，亦能體驗到柏柏爾人的穴居生活方式。瑪特瑪他更曾是電影《星球大戰》的拍攝場景。

# 11. 撒哈拉沙漠（Sahara Desert）

突尼斯南部是遼闊無垠的撒哈拉沙漠，部分地區已開發為旅遊資源。旅客可參加旅行團，乘坐四驅車進入沙漠，然後體驗在沙漠中騎乘駱駝，又或入住沙漠綠洲帳篷旅館，觀賞沙漠的日落、星空和日出。
