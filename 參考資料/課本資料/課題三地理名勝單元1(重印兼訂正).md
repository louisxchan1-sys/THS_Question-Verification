# 1.2 半球與區位

# 1 半球

地球可分為北半球、南半球、東半球、西半球。

# A 北半球和南半球

赤道以北的半個地球稱為北半球，赤道以南的半個地球稱為南半球。北半球的陸地面積要比南半球為多。

# B 東半球和西半球

東西半球以西經 20° (大西洋中部)、東經 160° (太平洋中部)為分界線。東半球包括歐洲、亞洲、非洲和大洋洲的大部分陸地；西半球大約在大西洋以西，主要有北美洲、南美洲和格陵蘭。

# 2 區位

區位是一個地理概念，指地理座標上的確定位置，如經度和緯度所標示的位置。

# 1.3 經緯度

為了方便標明地球上的區位，需要利用經度和緯度。由經度和緯度所標示的位置，就是一地的定位了。

# 1 經度

- 地球由北向南行的假想線稱為經線。
- 國際上以英國倫敦格林威治天文台的經線為 0 度，它亦被稱為本初子午線。
- 本初子午線以東的經度稱為東經，以西的經度稱為西經，東經和西經各有 180 度。
- 國際上通常以英文字母 E、W 來表示東經、西經。

# 2 緯度

- 地球由東向西行的假想線稱為緯線。
- 赤道是緯度 0 度的緯線。
- 赤道以北的緯度稱為北緯，以南的緯度稱為南緯，北緯和南緯各有90度。
- 國際上通常以英文字母 N、S 來表示北緯、南緯。

# 1.4 時區

由於地球自轉的關係，各地日出、日落的時間有所不同，因而會出現時差的問題。於是，人們採用時區去設定一個區域的標準時間，稱為當地時間，以解決時差的問題。

# 1 時區的定義

全球以英國格林威治的本初子午線為標準，分為 24 個標準時區。在格林威治以東及以西，分別有 12 個時區。每個地區的當地時間，都是相對「世界協調時間」(Universal Time Coordinated, UTC) 格林威治時間而設定的。

本初子午線以東國家的時間會較格林威治時間快，以西國家的時間會比格林威治時間慢。每差一個時區，時間就相差一小時。在格林威治以東地區的時間，以 UTC+ 計算；以西地區的時間，以 UTC- 計算。

![](images/4498110defa500b0a4ff04e0bb7924b8792bb80dfd9e61ed7dea068e17aa8e26.jpg)

# 例子庫

- 香港及內地位於 UTC+8 時區，當格林威治時間為上午 8:00，香港及內地時間就是 8:00+8:00=16:00，即下午四時。
- 加拿大溫哥華位於 UTC-8 時區，當格林威治時間為上午 8:00，加拿大溫哥華時間就是 8:00-8:00=0:00，即凌晨 12 時，與香港相差 16 小時。

# 世界時區的特別情況

中國雖然橫跨五個標準時區，但為了方便國家的管理，以北京時間為標準，用行政方式將全國統一劃為一個時區。

馬來西亞分為東馬來西亞和西馬來西亞兩部分，東馬來西亞處於標準時區的 UTC+8 小時，西馬來西亞處於標準時區的 UTC+7 小時，後來為了全國時間上的統一，就劃一以東馬來西亞的 UTC+8 小時為標準。

新加坡與西馬來西亞相鄰，本來處於標準時區的 UTC+7 小時，但為了配合馬來西亞時區的改動，於是亦將國家的時間改為 UTC+8 小時，與內地、香港等地相同。

印度全境則採用 UTC+5.5 小時。

# 夏令時間

為了節約能源，讓人早起早睡，減少照明電量，全球有不少國家或地區會實行夏令時間，即在夏季人為地把時間調快一小時。不過，各個國家或地區的夏令時間安排有所不同。

以美國、加拿大為例，夏令時間是在每年3月的第二個星期日清晨02:00，把時間撥快一小時，變成03:00；夏令時間於11月的第一個星期日清晨02:00結束，恢復到當地原來的標準時間01:00。另外，美國實施夏令時間的地區不包括夏威夷。

![](images/2cf9624df8e88ff1fbc1c3353194171230e3ea7d56bd2add06f9e4266936fbf7.jpg)

# 提示箱

為了避免造成民眾生活上的不便，國際日期變更線故意弄得彎彎曲曲，令同一個國家的領土可處於同一個日期區內。

# 3 國際日期變更線

東半球的時區比西半球的時區時間早，為了避免日期上的混亂，國際上統一以國際日期變更線作為虛構的日期分界線。

國際日期變更線位於地球東經及西經180度，若跨越這條線，日期就會發生變化。例如旅客於2月9日由東半球向西半球跨越這條線，他會處於西半球的2月8日，變相多了一天時間；若旅客於2月8日由西半球向東半球跨越這條線，他會處於東半球的2月9日，變相少了一天時間。

# 4 時區對旅遊的影響：飛行時差

# A 飛行時差的形成

飛行時差是指旅客在短時間橫越多個時區時，由於身體的自然節奏和睡眠週期受到擾亂，所引發的身體和生理的病徵變化。根據香港衛生署港口衛生旅遊健康中心的資訊，由東飛向西所造成的飛行時差，較由西飛向東時嚴重，復原的時間亦較長。

# B 飛行時差的影響

飛行時差引發的身體和生理病徵，包括失眠、疲倦、情緒波動、腸胃不適及胃口不佳等。飛行時差所引發的病徵，嚴重者可持續三數天，並可能會影響工作和思維表現。

![](images/fed14bf75c7d1616736fa3aed283d26d7b8bcd7e7da18e4b9a13ecd658bbab03.jpg)

旅客如在東半球或西半球內旅遊，各國時差不會太大。但假如跨越東西半球的旅途，時差就會較明顯。

# C 飛行時差的預防方法

預防飛行時差的方法包括：

- 展開飛越時區的旅程時，應休息充足及避免睡眠不足。
- 在飛行途中不可飲用過多的酒精和咖啡，應喝大量的水。
- 若旅程少過三天，應按原居地的時間表作息。
- 若旅程超過三天，應立即按目的地的睡眠及用膳時間。如有需要，可在首數天作午睡，以幫助適應。
- 在目的地接受戶外陽光照射，能夠減少時差的徵狀。
- 應盡量避免服用安眠藥，如有需要應諮詢醫生的意見。

有炎熱的雨季和溫暖的旱季。雨季的氣候狀況與熱帶雨林相似，高温而多雨；冬季是旱季，氣候狀況非常乾燥。越接近熱帶雨林區，雨季越長，雨量越多；越接近熱帶沙漠區，雨季越短，雨量越少。

# c 熱帯沙漠氣候（Tropical desert climate）

日夜温差大，白天日照強，氣溫可高達 $50^{\circ}C$ ，蒸發大，濕度低；夜間則較涼，可降至 $0^{\circ}C$ 。全年降雨量少，降雨多為暴發性陣雨。

熱帶沙漠氣候主要位於北緯 $20^{\circ}$ 至 $30^{\circ}$ 和南緯 $20^{\circ}$ 至 $30^{\circ}$ 之間。

全年高溫，受季候風影響，乾濕季節分明。降雨主要來自夏季季風和颱風，冬季季風通常較乾燥，但也會有雨。

# e 温帶大陸性氣候（Temperate continental climate）

全年溫差較大。受強烈大陸高氣壓影響，冬季寒冷，時常有暴風雪發生；夏季天氣溫暖，雨量亦集中在夏季。

溫帶大陸性氣候位於溫帶海洋性氣候地區以東，同樣位處北緯 $40^{\circ}$ 至 $60^{\circ}$ 之間。

![](images/f7aecee059099a86a45a6d412469bba7c1d073a08f6535e0e872a1aae3d12aee.jpg)

# 例子庫

\- 温帶大陸性氣候主要分布區：中國北部、俄羅斯大部分及北美洲大部分地區。

# f 温帯乾燥性氣候（Temperate arid climate）

與熱帶沙漠氣候有不少共同點，如日夜溫差大，白天日照強，氣溫高，濕度低，夜間則較涼；全年降雨量少。但與熱帶沙漠氣候有不少差異，如冬季寒冷，有少量降雪。

溫帶乾燥性氣候主要位於內陸地區，距離海洋較遠，且有高山阻隔，導致水氣難以到達。

![](images/9d4be46150d22a52fdd717a892f358b10d2cf140075ac543103ea8449ec60b7c.jpg)

# 例子庫

\- 温帶乾燥性氣候主要分布區：亞洲蒙古高原的戈壁、中國新疆的塔克拉瑪干沙漠、中亞沙漠、美國西部內陸沙漠和南美洲南部的沙漠等。

# C 寒帶 / 極地氣候（Polar Climates）

寒帶／極地包括北極圈（北緯66.5°）內及南極圈（南緯66.5°）內。寒帶／極地地區的氣候特徵是全年低温，夏季短暫且涼冷，冬季漫長而嚴寒，年溫差大。

寒帶 / 極地氣候又分為寒帶 / 極地苔原氣候和寒帶 / 極地冰原氣候兩種。

# 1.6 季節性與旅遊業

不同的氣候環境會塑造出不一樣的自然景觀，部分獨特的景觀更會成為旅遊景點，吸引各地的旅客前來觀賞。不過，這些自然景觀與景點存在季節性的特質，並會對旅遊業及旅遊活動產生影響。

# 1 自然景觀的季節性

自然景觀與景點受到氣候環境等因素影響，在不同的季節會呈現不同的面貌，在不同季節到訪的旅客會產生不一樣的感觀。有些自然景觀與景點更只會在個別季節出現，或只在某個季節特別優美，旅客於是集中在這些季節前來觀賞，結果形成自然景觀與景點的旅遊旺季和淡季。

![](images/561042c39b53208cfb45c53edd19de50fce732c897ecb110f0b6f8195863c813.jpg)

# 例子庫

- 北極光是在北極圈或接近北極圈地區才能看到的自然景觀。雖然極光現象全年都有機會發生，但極光要在漆黑的夜晚才能看到，所以觀賞極光的最佳季節會是北半球的冬季。
- 樱花是日本著名的樹種，每年春季都會盛放，吸引不少日本民眾及海外旅客前往觀賞。當地旅遊部門甚至開發了櫻花開花日預測地圖，方便旅客安排觀賞櫻花的行程。

# A 居住地與目的地的氣候差異

生活在寒帶及高緯度溫帶地區的人士，冬季比較寒冷而漫長，甚至受到冰雪吹襲，氣候狀況較惡劣，他們會傾向離開當地，到陽光普照、氣候溫暖的舒適地方度假。

生活在熱帶及低緯度溫帶地區的人士，全年天氣炎熱，季節變化不明顯，他們會考慮到四季變化較大，天氣較涼快，甚至會下雪的地方度假，感受不一樣的氣候環境。

![](images/baa8e3769322456a8f8faf75f90a18fc6930214d4d4ebb2946a90ba247210fef.jpg)

# 例子庫

- 不少居住在北歐挪威、瑞典、芬蘭、冰島等高緯度地區的歐洲民眾，由於當地冬季長，沒有陽光的黑暗日子多，會選擇到地中海沿岸地區度假，或前往東南亞、加勒比海島嶼等熱帶地區，享受陽光與海灘。
- 一些居住在香港、澳門、新加坡等低緯度地區的民眾，冬天會選擇到內地東北、日本北海道、歐洲、加拿大等地，觀賞雪景及參與滑雪等活動。

# B 降水的影響

強降雨和強降雪等惡劣天氣，會阻礙甚至破壞各種交通運輸及旅遊服務設施的使用。在大雨、大雪、大霧等天氣環境下駕駛出行，也容易造成交通意外。因此，旅客大多會先了解目的地的天氣情況，再決定是否安心出行。

一些旅遊活動需要充足的降水量支持，才能順行進行。假如降雨量不足，河道乾涸，便有機會令遊船無法行駛；降雪量減少，滑雪場沒有足夠厚度的冰雪覆蓋，就無法讓旅客參與滑雪活動。

![](images/07b7ee067f7224fbfaff18d7e9e2e7cd8535067947f7f1fae48ffc605db68a12.jpg)

# 例子庫

- 意大利威尼斯在 2021 年 2 月底，城內的運河水位下降，不少河道乾涸，許多貢朵拉遊船被迫停駛。
- 日本北海道在 2019 年的冬季，由於降雪量不足，有三分之一的滑雪場無法開放。

# C 温度的影響

嚴寒及酷熱天氣除了影響旅遊活動的進行，更會誘發一些與低溫和高溫有關的疾病，危害旅客健康。

嚴寒天氣往往伴隨暴風雪，令天氣變得相當惡劣，不適合旅遊活動的進行。旅客如缺乏足夠保暖衣物，容易誘發低溫症，甚至凍死。

酷熱天氣下，民眾會想方設法消暑降溫，也難以長時間在戶外逗留。因此，很多旅客會選擇避開酷熱天氣，轉往其他溫度相宜的旅遊目的地。

![](images/dd181c03856be56564d931efb904b7813acb73aab465e40aff254d6871305828.jpg)

# 例子庫

- 北美洲在 2019 年初受到嚴重寒潮侵襲，寒潮除了帶來暴風雪和厚積雪，更造成數十人因低温而死亡，多地交通受影響，旅遊活動停止。
- 歐洲的法國、西班牙等地，在 2019 年夏天受到熱浪侵襲，其中法國有超過 1500 人因酷熱死亡，不少旅客轉往其他地區旅遊。

# D 風力的影響

衝浪、滑浪風帆等體育活動，除了需要在海上進行外，同時需要有足夠的風力提供適當的環境。

![](images/33287d750ad3bbf717ff71858a13451d707e531da1c415b61419703ec0103606.jpg)

# 例子庫

\- 美國夏威夷群島和加州海岸、巴西里約熱內盧海岸、澳洲黃金海岸等，都是著名的衝浪聖地。

郵輪旅遊的航線，需要考慮季候風等氣候因素的影響，並在規劃行程時避開颱風和颶風，以免對旅客的安全構成危害。

![](images/a8a9949984f37fdcc3e8ff9b443583fabd59988a9129cb55631615f6c35e89b6.jpg)

# 提示箱

![](images/9f9b87165ad9661636e84decb53c124c67c56ab18df8e20af9d959f7afb31b3c.jpg)

# 例子庫

\- 2015 年，曾有原定從香港出發前往日本的郵輪，因日本受颱風侵襲，需改往泰國和越南。部分旅客不滿郵輪公司因颱風更改行程，一度拒絕下船。

# 1.7 氣候變化對旅遊業的影響
