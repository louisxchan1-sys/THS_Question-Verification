# 1 顧客服務的性質

旅遊與款待業是服務性行業，顧客在購買旅遊產品時，員工的服務水準足以影響顧客對企業的印象。因此，顧客服務是旅遊與款待企業營運時重視的一環。

# 1.1 客務關係及服務

# 1 甚麼是顧客服務？

顧客服務是指向消費者提供的服務，包括產品出售前、出售期間及出售後整個過程中的所有服務。

根據杜賓（Turban et.al.）等學者指出，顧客服務是一連串活動，以提升顧客在交易前後和過程中的滿足感，讓顧客感到所購買的產品和服務物有所值，甚至物超所值。市場學者菲力·哥特勒（Philip Kotler）表示，當商品的實際消費效果達到消費者的預期時，就會使顧客感到滿意，否則會令顧客不滿。

# 2 實物商品與服務的主要分別

在實物商品買賣時，商品的品質較容易量度和比較。然而，實物商品和服務之間有性質上的分別，會影響顧客對服務質素的認知，因此我們可先了解兩者的分別。

<table><tr><td>實物商品</td><td>服務</td><td>提供顧客服務時要注意的事項</td></tr><tr><td>有形</td><td>無形</td><td>比起實物商品,顧客購買服務前難以依靠五觀感知去判斷質素。</td></tr><tr><td>生產與使用分開進行</td><td>生產與使用同時進行</td><td>顧客享用服務時,服務提供者與顧客須同時存在,而服務提供者及其他在場的顧客,也是顧客體驗的一部分。</td></tr><tr><td>標準化</td><td>多變性</td><td>提供服務的過程比實物商品交易的過程,更易受提供者、地點及時間等影響而出現變化,導致質素較難保持一致。</td></tr><tr><td>可保存</td><td>不可保存</td><td>服務的提供存在時限,通常只維持一段時間,不可永久保存,更不能留作日後銷售或使用。</td></tr></table>

# 3 有形及無形的服務

雖然實物商品和服務兩者有清晰的分野，但是顧客在交易時所消費的可以是商品本身，也可以是一種服務，或是商品連同服務。

由於服務是互動的過程，我們在旅遊或款待設施獲得的服務，都是由服務員或機械所提供的，所以難以描述或衡量，因此服務有無形的一面。同時，在顧客體驗服務時，又會牽涉到物品、設施和建築，它們都是可見、可觸摸、可感覺、可聽到、可品嚐的有形事物，於是旅遊及款待業兼具有形及無形的服務。

作為服務業中的重要組成部分，旅遊與款待業在顧客服務方面，有獨特的地方，並可歸納出以下五個特性：

# 1 綜合性

旅遊與款待業提供的是綜合性顧客服務，而這是其他行業未必具有的。以外遊旅行團為例，旅行社在旅客出發前、旅途中，甚至旅程結束後，都會提供一連串服務。

![](images/123bbb8f9dbeea40526cea1230ffb1dde78aa3eb251a122acbcce40c8bd629f6.jpg)

# 例子庫

\- 外遊旅行團出發前，旅行社會舉辦茶會，向團友簡介行程和注意事項；出發前又會提示團友集合時間、地點等。旅途中，旅行社職員會為團友安排交通、餐飲、住宿和觀光等服務。行程結束後，很多旅行社會有後續服務，如收集團友意見、向舊有顧客推廣最新優惠等。

# 2 直接性

旅遊與款待業的顧客服務，須向顧客提供直接、及時和即時的服務，以盡快回應顧客的需要。這不同於產品可先生產、再銷售，或生產後轉由分銷商售予顧客。

![](images/30ba28f75c4552745ab2f321c08377851ed9b1af2014d9fc94362aff772b01be.jpg)

# 例子庫

- 旅行社或旅遊諮詢中心的職員，會為顧客提供面對面、即時的旅遊資訊和預訂服務。
- 顧客選定餐飲後，餐廳廚師需立即烹製，再由侍應直接送上。

# 3 情緒性

旅遊與款待業的顧客服務，同時要顧及顧客在情緒上的需要。我們在課題一學習過「旅遊動機」，明白旅客外遊除了追求物質享受外，還有精神上的需求，如安全感和別人的尊重等。過程中，旅遊與款待業從業員的服務態度和服務質素，都會左右旅客的滿意度。

# 4 時間性

旅遊與款待業從業員提供服務的時刻，其服務質素的高低，會直接令顧客對企業留下良好或負面的印象。顧客對服務產生印象的瞬間稱為「關鍵時刻」，有關概念會在後面的章節再加討論。

# 5 應變性

顧客服務需針對不同顧客的不同需要，提供合適的服務。旅遊與款待業從業員面對的顧客眾多，需因應顧客背景、性格和旅遊目的等，隨時作出應變，以滿足他們的需要。

# 1.3 顧客服務的重要性

顧客服務是旅遊及款待業運作中相當重要的一環，雖然企業需要持續投入資源去提供優質顧客服務，但優質顧客服務為企業和員工帶來的好處，絕對值得企業投入資源。

# A 增加吸引力

旅遊與款待業是一個產品差異不大的行業，顧客服務因而成為釐定市場競爭力高下的重要因素。加上顧客在外遊時重視體驗，所以提供優質服務的企業，能贏得更多口碑，較受顧客歡迎。

# 例子庫

\- 不同旅行社舉辦的日本賞櫻團，各團的行程、食宿、交通等安排都不相伯仲，但一直提供優質服務的旅行社，對顧客較有吸引力，有較多顧客報團。

# B 累積忠誠客戶

優質的顧客服務有助增加顧客對企業的好感，並對企業產生信心。當顧客需要再次購買相同的產品或服務，相對光顧新公司，會較願意光顧有信心保證的公司。久而久之，優質的顧客服務能為企業建立忠誠客戶群。

# C 提高收入

優質的顧客服務質素能為企業建立口碑，吸引更多顧客，從而增加營業額。同時，優質的顧客服務能為企業建立忠誠客戶群，而累積忠誠客戶的成本比尋找新顧客的成本低，可為企業節省部分宣傳推廣的費用。因此，優質的顧客服務有助企業減少開支，亦能增加收入，為企業帶來更大利潤。

# D 樹立品牌和商譽

現有顧客的體驗分享，具有很大影響力，足以影響品牌的口碑。當顧客能從企業的優質顧客服務獲得滿足度，他們會願意與別人分享經驗，以及推介親友光顧。這些體驗分享，會為潛在顧客帶來更大的信心。社交媒體的普及，更使顧客的意見有機會在網絡廣泛傳播，對企業商譽的影響力亦隨之大增。

# 2 顧客服務對員工的重要性

企業提供優質顧客服務，連員工也能獲得好處：

# A 增加滿足感

當員工提供優質顧客服務，顧客往往會作出正面的回饋，如滿意的笑容、寫感謝信，甚至給予小費。這令員工得到滿足感和實際的回報，並因而更加投入工作，更有自信地提供顧客服務。

# B 增強歸屬感

員工要先經過專業培訓，才可提供優質顧客服務。當他們提供的服務獲得顧客和公司的肯定，他們對公司的歸屬感會提高，想繼續服務公司。當大部分員工都具有一定經驗，並為共同目標而努力，更可提高公司士氣。當工作團隊擁有良好的精神面貌，又進一步加強員工歸屬感。

# C 減少投訴

優質的顧客服務可避免顧客對員工服務產生不滿，令顧客投訴減少，進而為公司減省人力、物力。因為一宗顧客投訴可能需要不同部門的員工處理，而員工需花費心力、時間去查找原因，並要與顧客溝通賠償問題，亦增加他們的工作壓力。

# 1.4 Parasuraman 的五個顧客服務特點 -RATER

# 2.1 旅遊與款待服務員工的儀容

雖然人不可以貌相，但是旅遊與款待業的員工提供服務時代表着企業，必須保持良好的儀容，以展現專業的形象。由顧客的角度出發，他們會期望接待自己的員工儀容端正、具有良好態度，而這直接影響他們的整個服務體驗和對企業的印象。

# 1 制服與衣著標準

員工的制服和衣著標準，對企業建立優質服務形象有直接影響。因此，不少旅遊與款待企業會為前線員工提供制服，並有清晰指引教導員工如何正確穿著制服。員工穿著整齊制服上班，實際上會為企業帶來多個好處，包括：

- 穿著整齊和潔淨制服的員工，可給予顧客專業形象，將企業的優質服務形象化。
- 不同職級和部門的員工，制服通常有所不同，可方便顧客辨別不同職員，有助溝通和提高效率。
- 企業不用津貼員工購置上班衣物，可減省整體開支。
- 員工穿着相同制服更易對企業產生歸屬感，有助提升「團隊士氣」和服務質素。

# 思考點

一名已入住酒店的顧客，因不滿房間整潔度而要求換房。他在登記入住時，已要求晚上將餐飲送到房門口。有哪些部門的職員需合作處理有關個案？

# B 有良好組織能力

員工一天要處理多項工作，所以他們要有良好的組織能力，有效地安排工作次序或同時進行不同工作，仔細地完成顧客的要求，務求沒有錯漏。否則會令顧客失望，甚至無法完成整個服務，並帶來更多的後續工作。

# D 適應團體工作模式

旅遊與款待業屬勞工密集的行業，團隊工作和溝通的機會很多。顧客的要求亦常涉及不同部門，他們會期望企業的員工能有完善的溝通，迅速及有效地解決他們的問題。因此，員工必須能展示團體合作，不抗拒與不同部門的員工協調工作，才可為顧客提供優質的服務。

# E 能獨立完成工作

旅遊與款待業的服務除了需要不同員工合作完成，也需要員工能夠單獨接待顧客，了解顧客的需求，並想辦法為他們提供解決方案。所以，優秀的員工應具有獨立完成工作的能力，懂得如何作出合理的判斷，提升顧客的整體滿意度。
