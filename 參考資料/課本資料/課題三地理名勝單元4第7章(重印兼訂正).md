# 地理景觀

南美洲東面瀕臨大西洋，西面為太平洋，北部與北美洲相接，南部與南極洲相望。

南美洲的地形，西面有世界最狹長的安第斯山脈，綿延9 000多公里；東部是大片低緩的山地及高原，其中巴西高原是世界最大的高原；中部是廣闊平坦的平原區，而亞馬遜河平原是世界最大的沖積平原。

智利、厄瓜多爾、哥倫比亞、阿根廷等國擁有不少火山，可開展觀賞火山的旅遊活動。

距離厄瓜多爾本土 1 000 公里、位於太平洋東部的加拉巴哥群島（或稱加拉帕戈斯群島），因達爾文在此參觀稀有野生動物後，發展出進化論而廣為人知，並已被列為世界自然遺產。

# 7.3 巴西

# 國家簡介

巴西大部分國土位於南半球，地處南美洲東北部，國土面積 851 萬平方公里，是南美洲第一大國，世界第五大國。巴西北面與委內瑞拉、哥倫比亞、蘇利南、圭亞那、法屬圭亞那相鄰，西面與秘魯、玻利維亞接壤，南面與阿根廷、烏拉圭、巴拉圭交界，東臨大西洋。

根據國家商務部《對外投資合作國別（地區）指南：巴西（2023年版）》，巴西2022年人口約2.03億，種族具多樣性，白人約佔 54%，黑白混血人種佔 38%，黑人佔 6%，其餘是印第安人和黃種人。巴西約五成人口信奉天主教，三成人口信奉基督教；官方語言是葡萄牙語，西班牙語、英語是主要外語。

# 2 歷史文化

巴西在古代是印第安人的居住地。16 世紀初，葡萄牙在巴西建立殖民地，開啟了在當地長達300年的殖民統治。1822年，巴西取得獨立。1889年，巴西成為聯邦共和國。

由於巴西在葡萄牙殖民時代起，有大批非洲人移入，到近代又有大量歐洲、亞洲移民，形成了巴西多元的種族與文化，更被稱為「文化大熔爐」，當地種族歧視情況也較少。

# 巴西習俗禮儀

巴西人的習俗和葡萄牙、南歐的習俗非常相似。英美表示OK 的手勢在巴西是非常不禮貌的。與巴西人打交道時，不宜贈送手帕或刀子。

# 地理氣候

# A 地理

巴西地域廣闊，北部和西北部是亞馬遜盆地，也是全球面積最大的熱帶雨林；中部及南部是巴西高原，約佔全國面積六成，也是世界面積最大的高原。巴西海岸線超過7 400公里。

# B 氣候

巴西北部及西北部的亞馬遜盆地屬熱帶雨林氣候，年平均氣温約 27℃至 29℃，雨量充沛；中部高原屬熱帶草原氣候，分旱季、雨季，年平均氣温約 18℃至 28℃；南部地區屬亞熱帶氣候，全年涼爽，年平均氣温約16℃至19℃。

# 旅遊概況

# A 交通便捷度

根據國家商務部資料，巴西航空交通發展在南美洲國家中不俗，有國際機場 18 個，重要的有聖保羅、里約熱內盧、巴西利亞國際機場。當地有航班直飛歐洲、北美洲主要城市，以及南非約翰內斯堡和阿聯酋迪拜等，目前香港旅客前往當地需在以上城市轉機。

巴西公路運輸發達，全國公路總里程達 172 萬公里，高速公路則有約 1 萬公里，並以東南部、南部及東北部的公路網較為密集。

# B 旅遊資源

巴西旅遊資源豐富，主要旅遊城市有里約熱內盧、聖保羅、巴西利亞。旅客可參觀城市風光，享受陽光與海灘，參加嘉年華，觀賞伊瓜蘇大瀑布等自然景觀，到亞馬遜森林探險等。

# 5 衞生環境

巴西的衞生環境一般。根據世界衞生組織資料，巴西屬登革熱、瘧疾、黃熱病、血吸蟲病、狂犬病感染風險國家。旅客到訪當地更需要出示黃熱病疫苗接種證明。另外，巴西在2019年曾出現寨卡病毒感染個案。

# 1. 三權廣場 （Three Powers Plaza）

三權廣場位於巴西利亞的中心。在廣場周圍，建有總統府、國會大廈和聯邦最高法院這三幢代表政府三權的建築物。其中總統府的設計具未來感，有白色曲線柱子和直達入口的大型斜坡；國會大廈採用雙塔設計；聯邦最高法院有多條曲線柱子，令建築看起來像懸浮於地面。廣場上方還飄揚着一面全球最大的國旗。

# 2. 巴西利亞主教座堂（Cathedral of Brasilia）

巴西利亞主教座堂的正式名稱為阿帕雷西達聖母總主教座堂，位於三權廣場不遠處，是天主教巴西利亞總教區座堂，於 1970 年完工。教堂外型像一個傘形，寓意眾人手捧起一個十字架；主體建築在地下，外部是由16根混凝土柱子構成的屋頂，狀似耶穌受難時所戴的荊棘冠。

# 7.4 阿根廷

# 國家簡介

阿根廷位於南半球，地處南美洲南部，國土面積 278 萬平方公里，是南美洲第二大國。阿根廷北面與玻利維亞、巴拉圭接壤，西面與智利以安第斯山脈為界，東面與巴西、烏拉圭相鄰，東臨大西洋，南面與南極洲隔海相望。

根據國家商務部《對外投資合作國別（地區）指南：阿根廷（2023年版）》，阿根廷2022年人口約4 733萬，白人和印第安人、歐洲人的混血人種約佔 95%，其餘有阿拉伯人和猶太人等。阿根廷近八成人口信奉天主教，一成人口信奉基督教；官方語言是西班牙語，其他語言包括英語、意大利語、德語、法語。

# 歷史文化

阿根廷原是印第安人的居住地。16 世紀中期，西班牙在阿根廷建立殖民地，自此殖民統治當地長達 300年。1810 年，阿根廷爆發反抗西班牙統治的「五月革命」，並於 1816年宣布獨立。1853 年，阿根廷成為聯邦共和國。

# 資料室

# 阿根廷習俗禮儀

阿根廷人飲食習慣以西餐為主，尤其喜歡各式各樣的烤肉，但不喜歡吃辣。

# C 旅遊競爭力

根據世界經濟論壇發表的《全球旅遊業競爭力報告 2024》，阿根廷在全球排名第49位。

近年，阿根廷政府投入大量資源於改善機場、公路、鐵路等基礎設施，以提升當地接待旅客的能力。

雖然阿根廷社會治安在南美國家中比較好，但近年城市犯罪率呈上升趨勢，偷盜、搶劫等案件時有發生，對當地的旅遊形象造成負面影響。

# 5 衞生環境

阿根廷的衞生環境一般。根據世界衞生組織資料，阿根廷屬登革熱、漢坦病毒感染風險國家。另外，當地在 2019 年曾出現寨卡病毒感染個案。

# 6 簽證要求

根據阿根廷外交部資料，截至 2024 年，有 120 多個國家或地區的公民可免簽證入境阿根廷，包括歐盟成員國，北美洲的美國、加拿大、墨西哥，南美洲的巴西、智利、巴拉圭、烏拉圭，亞洲的中國香港、中國澳門、新加坡、馬來西亞、泰國、日本、南韓，大洋洲的澳洲、新西蘭，非洲的南非，以及中東的阿聯酋等。

根據香港入境事務處資料，香港特別行政區護照持有人最長可免簽證逗留阿根廷90日。

# 7.5 智利

# 國家簡介

智利位於南半球，地處南美洲西南部，國土面積 76 萬平方公里。智利北面與秘魯接壤，東面與玻利維亞、阿根廷相鄰，西臨太平洋，南面與南極洲隔海相望。

# 地理氣候

# A 地理

智利位於安第斯山脈西麓，國土狹長，南北長4 329 公里，是世界最狹長的國家，有「絲帶國」的稱號。全國東西最寬處有434公里，最窄處只有90公里。智利北部是沙漠，中部是盆地，南部是森林區，靠近南極圈的地區有冰川地形，多湖泊及峽灣。智利海岸線長約1萬公里，沿海有多個島嶼。

# B 氣候

智利國土跨越 38 個緯度，氣候複雜多樣，但大部分地區四季分明。其中北部屬熱帶沙漠氣候，乾燥温和，年降雨量少；中部盆地屬温帶地中海氣候，氣候温和；南部屬温帶海洋性氣候，較為寒冷多雨。

# C 旅遊競爭力

根據世界經濟論壇發表的《全球旅遊業競爭力報告2024》，智利在全球排名第31位。

# 5 衞生環境

智利的衞生環境在南美洲國家中相對較佳。不過，根據世界衞生組織資料，智利屬登革熱、漢坦病毒感染風險國家。另外，智利復活節島在2019年曾出現寨卡病毒感染個案。

# 6 簽證要求

根據智利外務省資料，截至 2024 年，有 88 個國家或地區的公民可免簽證入境智利，包括歐盟成員國，北美洲的美國、加拿大、墨西哥，南美洲的巴西、阿根廷、巴拉圭、烏拉圭，亞洲的中國香港、中國澳門、新加坡、馬來西亞、泰國、日本、南韓，大洋洲的新西蘭，非洲的南非，以及中東的阿聯酋等。

# 8. 百內國家公園

# （Torres del Paine National Park ）

百內國家公園位於智利南部，面積約 2 400 平方公里。整個公園被湛藍的冰川峽灣和湖泊山谷景觀所環繞，並有不少高聳的山峰。其中三座如尖塔般的花崗岩山峰，最為高拔，是公園的地標。公園壯麗的大自然景觀，每年吸引成千上萬的旅客前往觀賞，成為其中一個最受旅客喜愛的智利國家公園。

# 9. 阿塔卡馬沙漠（Atacama Desert）

阿塔卡馬沙漠大部分位於智利的北部，小部分位於秘魯、玻利維亞和阿根廷，是一個南北長約 1 100 公里、總面積達 18 萬平方公里的沙漠。該沙漠是世界上其中一個最乾燥的地區，以浩瀚的沙漠風光而聞名，包括有酩似月球地貌的月亮谷、荒涼的死亡谷等。每年 9 至 11 月，當地春天雨水來臨，沙漠會遍地野花綻放，形成獨特的自然奇觀。
