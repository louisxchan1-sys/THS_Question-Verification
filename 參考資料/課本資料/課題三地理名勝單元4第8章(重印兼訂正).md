# 8.1大洋洲概況

大洋洲面積約897萬平方公里，是世界上面積最細的大洲。

大洋洲主要由澳洲、新西蘭、巴布亞新幾內亞，以及南太平洋的一眾島國組成（帛琉、斐濟、湯加、庫克群島、大溪地、基里巴斯、薩摩亞、所羅門群島、圖瓦盧、瓦努阿圖、紐埃、諾魯等）。

# 地理景觀

大洋洲位於太平洋中南部和西南部的赤道南北廣大海域。

大洋洲地形分為大陸和島嶼兩部分：澳洲大陸西部為高原，大部分是沙漠和半沙漠；大陸中部為平原；大陸東部是山地。新幾內亞島、新西蘭的北島和南島是大陸島，島上多高山，平原狹小。

澳洲東部和北部的太平洋島嶼，多為火山島及珊瑚島，也是太平洋西岸活躍的火山帶。

火山島海拔較高，地勢險峻，有壯觀的火山口，秀麗的火山湖，有地熱、温泉等，多為度假勝地。河流短，多急流、瀑布。

珊瑚島面積不大，地勢低平，多呈環狀，中間是風平浪靜的潟湖，適宜開展多種水上、水底體育及遊樂活動。

# 2 河川湖泊

大洋洲的大河及湖泊較少，最大的湖泊是位於澳洲中部的北艾爾湖；最深的湖泊是新西蘭南島的蒂阿瑙湖。

此外，新西蘭的冰川及地熱温泉，也是新西蘭的特色旅遊資源。

# 3 氣候

大洋洲大部分島嶼位於熱帶和亞熱帶地區，以熱帶氣候和亞熱帶氣候為主。

不過，澳洲大陸面積大，加上受緯度、地形、距海距離等不同影響，氣候較多樣，各地降雨量也不均等。

至於新西蘭，屬亞熱帶和温帶海洋性氣候，全年降雨豐沛，其南島更是大洋洲唯一冬季降雪的地區。

# 人文景觀

澳洲及新西蘭都是歐洲殖民者開發的國家，早期的城市具有濃厚的西歐色彩。現時，澳洲及新西蘭都是大洋洲經濟發達的國家，有不少新式的現代化建築。

另外，大洋洲不同島嶼上居住着不同的土著民族，如新西蘭的毛利人，以及湯加人、斐濟人等，仍保存着原有的生活方式及文化習俗。

# 8.3 澳洲

# 國家簡介

澳洲位於南半球，地處南太平洋和印度洋之間，國土面積769萬平方公里，是大洋洲最大的國家，面積在全球排名第六。

澳洲是一個多民族國家。根據國家商務部《對外投資合作國別（地區）指南：澳大利亞（2023年版）》，澳洲2022年人口約2 627萬，近五成是英國人後裔，其餘包括意大利人後裔、德國人後裔、華人後裔、印度人後裔、菲律賓人後裔、越南人後裔和土著等。澳洲超過四成人口信奉基督教，其他人口信奉天主教、伊斯蘭教、佛教等；官方語言是英語。

# 歷史文化

澳洲的原住民是土著。1770 年英國庫克船長登陸澳洲，宣布英國擁有澳洲主權。1788 年，首批英國移民定居澳洲。到了1901 年，澳洲聯邦組成，成為英國的自治領地。澳洲在 1931年取得內政外交的自主權，成為獨立的國家，仍奉英皇為國家元首。

# 3 地理氣候

# A 地理

澳洲大陸南北長約 3 700 公里，東西寬約 4 000 公里，四面環海，海岸線長約 3.6 萬公里，沿海有塔斯曼尼亞等島嶼。澳洲大陸西部主要是高原、沙漠和半沙漠，中部是平原，東部是高地。

# B 氣候

澳洲北部屬熱帶地區，年均氣温為25℃至 33℃。其餘三分二的大陸位於温帶地區，由於地處南半球，12 月至 2 月是夏季，3 月至 5 月為秋季，6 月至 8 月是冬季，9 月至 11 月為春季。澳洲僅沿海地區雨量充沛，越內陸地區雨量越少。

# 旅遊概況

# A 交通便捷度

根據國家商務部資料，澳洲是全球第八大航空市場，航空交通發達，全國有國際機場12個，重要的分布在悉尼、墨爾本、布里斯班、珀斯等城市。目前，澳洲有航班直飛亞洲、歐洲、北美洲、南美洲、非洲和大洋洲主要城市，香港旅客可直航到當地。

# B 旅遊資源

澳洲是一個移民社會，融合了歐亞多個種族的文化，形成各種文化兼具的特色。

澳洲自然旅遊資源豐富，擁有世界最大的熱帶珊瑚礁群、世界最大的岩山。旅客還可探索古老的雨林、壯闊的海岸和乾旱的沙漠；亦可進行滑浪、潛水、觀賞鯨魚和企鵝等活動。

文化旅遊資源方面，當地有不少現代化的地標建築、博物館等，吸引各地旅客。

根據聯合國教科文組織資料，截至 2024 年，澳洲共有 20個世界遺產，文化遺產 4 個，自然遺產 12 個，文化與自然雙重遺產4個。

# C 旅遊競爭力

根據世界經濟論壇發表的《全球旅遊業競爭力報告2024》，澳洲在全球排名第5位。

澳洲的優勢包括經濟發達，政治和社會環境穩定，治安良好，以及擁有現代化的基礎設施和交通網絡。

# 5 衞生環境

澳洲的衞生環境優良。不過，根據世界衞生組織資料，澳洲北部屬登革熱感染風險地區。另外，澳洲在 2017 至 2019 年曾出現麻疹感染個案。

# 1. 國會大樓（Parliament House）

國會大樓位於坎培拉市區，於 1988 年啟用，是澳洲國會議政和辦公的地方，採用現代化複合式建築風格。旅客可在此了解澳洲的民主程序。國會大樓有免費導覽服務提供，還設有許多展覽及公共藝廊，供遊人參觀。

# 3. 悉尼海港大橋（Sydney Harbour Bridge）

悉尼海港大橋橫跨悉尼港，是悉尼重要的橋樑，於1932年落成啟用。這座高134米，長502米，寬49米的大橋，是世界最大的鋼鐵拱橋，也是世界上少數可供攀爬的鐵橋。旅客可在專業導覽員陪同下，攀登大橋，360度飽覽悉尼港灣的美景。

# 5. 黃金海岸（Gold Coast）

黃金海岸是澳洲昆士蘭州的太平洋沿岸城市，也是澳洲著名的旅遊城市。沿海岸有多個美麗的海灘，是衝浪者的天堂。該處海域也是浮潛和潛水勝地，旅客可探索繽紛的水底世界。旅客亦可進入國家公園，參與森林探索，觀賞雨林、瀑布等自然風景。

# 8.4 新西蘭

# 國家簡介

新西蘭位於南半球，地處南太平洋，在澳洲東南方約 1 500公里，國土面積27萬平方公里，是大洋洲第三大的國家。

根據國家商務部《對外投資合作國別（地區）指南：新西蘭（2023 年版）》， 新西蘭 2023 年人口約 522 萬，近七成是英國等歐洲白人後裔，原住民毛利人佔 15%，其餘包括近年移入當地的亞裔人士、南太平洋島民等。新西蘭近五成人口信奉基督教和天主教，其中以基督教為多；官方語言是英語和毛利語。

# 2 歷史文化

新西蘭的原住民是毛利人。到了18世紀，英國開始向新西蘭移民。1840年，新西蘭成為英國殖民地。1907年，新西蘭擺脫殖民地位，成為英聯邦的自治領。1947年，新西蘭成為獨立的主權國家，仍奉英皇為國家元首。

# 資料室

# 新西蘭習俗禮儀

新西蘭民風純樸，富於探險精神，熱愛自然和田野生活，有較強的環境保護意識。

新西蘭人見面和告別均行握手禮，習慣的握手方式是緊緊握手，一般情況下，男士應等候婦女先伸出手來。

毛利人迎接尊貴的客人時有行碰鼻禮的習俗。碰鼻子的時間越長，就說明禮遇越高，越受歡迎。給別人拍照，特別是給毛利人，一定要事先徵得對方同意。

毛利人仍保留着濃郁的傳統習俗。他們大都信奉原始的多神教，相信「靈魂不滅」，尊奉祖先的神靈。

# 地理氣候

# A 地理

新西蘭由南島和北島兩個大島，以及附近一些小島組成。南島略大於北島，而兩島之間是庫克海峽，全國海岸線長約 1.5 萬公里。新西蘭的地形主要是高山和丘陵，其中南島有南阿爾卑斯山脈縱貫全島，海拔3 754米的庫克山是全國最高峰；北島的山峰較南島少，中央有全國最大的湖泊陶波湖。

# B 氣候

新西蘭北島北部屬亞熱帶氣候，北島南部及南島地區屬温帶氣候。由於地處南半球，季節與北半球相反。新西蘭夏季平均氣温約25℃，冬季氣温約 10℃，全年温差一般不超過 15℃。北島年均降雨量達 1 000 至 1 500毫米，南島600至1 000毫米。

# C 旅遊競爭力

根據世界經濟論壇發表的《全球旅遊業競爭力報告 2024》 ，新西蘭在全球排名第25位。

新西蘭的優勢包括社會發達，政治穩定，社會治安良好，且具有現代化的基礎設施和交通網絡。

旅遊業是新西蘭的重要產業，當地政府推出「2025 旅遊計劃」，致力提高新西蘭旅遊業的競爭力，提高旅客人次。當地近年亦興建了不少酒店、度假村等項目，並完善旅遊配套設施。

# 5 衞生環境

新西蘭的衞生環境優良。不過，根據世界衞生組織資料，新西蘭在2019年曾出現麻疹感染個案。

# 6 簽證要求

根據新西蘭外交貿易部資料，截至 2024 年，有 60 個國家或地區的公民可免簽證入境新西蘭，包括歐盟成員國，亞洲的中國香港、中國澳門、新加坡、馬來西亞、日本、南韓，大洋洲的澳洲，中東的沙特阿拉伯、阿聯酋，北美洲的美國、加拿大、墨西哥，南美洲的巴西、阿根廷、智利等。

根據香港入境事務處資料，香港特別行政區護照持有人最長可免簽證逗留新西蘭3個月。

# 8.5巴布亞新幾內亞

# 國家簡介

巴布亞新幾內亞位於南太平洋西南部，國土面積 46 萬平方公里，是大洋洲第二大的國家。巴布亞新幾內亞西面與印尼的巴布亞省接壤，南面和東面分別與澳洲、所羅門群島隔海相望。

根據國家商務部《對外投資合作國別（地區）指南：巴布亞新幾內亞（2023 年版）》，巴布亞新幾內亞 2021 年人口約995 萬，近 98% 是美拉尼西亞人，其餘包括波利尼西亞人、白人和華人等。巴布亞新幾內亞超過九成人口信奉基督教和天主教；官方語言是英語，地方語言達820多種。

# 2 歷史文化

巴布亞新幾內亞很早就有土著居住。到了 1884 年，當地被英國、德國瓜分，成為殖民地。第一次世界大戰後，當地由澳洲託管。第二次世界大戰期間，巴布亞新幾內亞曾被日本佔領。1949 年，巴布亞新幾內亞成為澳洲的領地。到1975年，巴布亞新幾內亞成為獨立的主權國家，仍以英皇為國家元首。

# 地理氣候

# A 地理

巴布亞新幾內亞位處亞洲和澳洲海路交通要道，具戰略地位。巴布亞新幾內亞大部分地區是山地，並以熱帶雨林為主。

# B 氣候

巴布亞新幾內亞位處赤道以南，屬熱帶雨林氣候，全年高温多雨，年均降雨量達2 500毫米。

# 旅遊概況

# A 交通便捷度

航空運輸是旅客前往巴布亞新幾內亞的主要途徑。不過，根據國家商務部資料，當地國際航空交通不算發達，只有首都莫爾斯比港飛往澳洲布里斯班、凱恩斯，以及菲律賓馬尼拉、新加坡、日本東京、中國香港等數條國際航線。至於巴布亞新幾內亞國內，重要城市之間的交通主要依靠飛機。

# 網絡台

巴布亞新幾內亞官方旅遊網站

巴布亞新幾內亞的公路交通落後，全國公路總里程約 3 萬公里，國家級公路只有約 9 000 公里，且路況較差。加上全國以山地為主，至今仍沒有連接全國的公路網絡。

巴布亞新幾內亞全國範圍尚未有鐵路。

# C 旅遊競爭力

巴布亞新幾內亞在世界經濟論壇發表的《全球旅遊業競爭力報告2024》中未有排名。

巴布亞新幾內亞整體發展落後，基礎設施建設嚴重不足，城市間欠缺道路聯通，電力和通訊缺乏。當地城市更經常性出現停水、停電及斷網現象。

另外，巴布亞新幾內亞軍隊和警員力量薄弱，加上居民可合法擁有槍支，治安惡劣全球聞名。治安問題在城市尤為明顯，持槍搶劫等案件經常發生。

# 5 衞生環境

巴布亞新幾內亞的衞生環境欠佳。根據世界衞生組織資料，巴布亞新幾內亞屬登革熱、瘧疾感染風險國家，同時存在日本腦炎病毒傳播風險，當地在 2019 年更曾出現寨卡病毒感染個案。當地主要傳染病還有結核、腸道傳染病和肝炎等，旅客如要前往當地，應先接種預防疫苗。

# 6 簽證要求

根據巴布亞新幾內亞外交部資料，截至 2024 年，有 50 個國家或地區的公民可免簽證入境巴布亞新幾內亞，包括亞洲的中國香港、新加坡、馬來西亞、菲律賓，大洋洲的所羅門群島、斐濟等島國，歐洲的英國，非洲的肯尼亞、坦桑尼亞，北美洲的加拿大、巴哈馬，南美洲的厄瓜多爾等。

根據香港入境事務處資料，巴布亞新幾內亞有關機構會在香港特別行政區護照持有人抵達當地時，就最長可免簽證逗留期作出決定。

# 6. 塞皮克河（Sepik River）

塞皮克河全長1 126公里，是巴布亞新幾內亞最長的河流。蜿蜒的河流形成湖泊、沼澤等，是珍貴的淡水濕地生態系統。沿岸有不少與世隔絕的村莊，建在河岸的高架房屋，住着原始部落。這些部落仍以獨木舟作為交通工具，保留着狩獵、採集的傳統生活方式。

# 7. 潛水（Diving in Papua New Guinea）

巴布亞新幾內亞是著名的潛水勝地，沿岸有很多適合潛水的地點。除了豐富多彩的珊瑚礁、熱帶魚群，第二次世界大戰的戰爭殘跡，如戰船、戰機殘骸等，也是這裏的潛水景致。
