# 1.1 本地旅遊業的表現

旅遊業是香港的支柱行業，多年來是本港經濟增長的一個主要動力。根據香港旅遊發展局的數字，2019 年訪港旅客有5 590 萬人，總消費金額超過 2 560 億港元。旅遊業佔本地生產總值約3.6%，旅遊業就業人數達23萬2千多人。

從統計數字，可以了解訪港旅客的特點，這有助旅遊業界分析他們的顧客——旅客，從而更好地制定市場策略。

# 提示箱

自改革開放以來，訪港的內地旅客一直穩步上升。到 2003 年《港澳個人遊計劃》推出以來，內地旅客更大幅上升，成為本港入境旅客的最主要來源地，以及成為香港旅遊業的支柱。

# 地理環境

旅客來源地集中：和大部分旅遊目的地相同，香港的入境旅客主要來自鄰近地區。根據統計數據，內地持續是香港最大的入境旅客來源地。2019年內地訪港旅客總數達4377萬人次，佔整體訪港旅客的78.3%。展望未來，內地仍然是本港旅遊業最大的客源市場。

# 2 人口特徵

# A 旅客性別

從 2014 至 2019 年的整體數字反映，訪港旅客中的女性約佔55%，男性佔45%，女性旅客多於男性旅客。

內地旅客性別：內地訪港旅客中，女性人數比例高於男性。

其他地區旅客性別：內地以外的其他國家或地區，除南亞及東南亞外，訪港旅客都是男性較女性多。

# B 旅客年齡

由統計數據可見，訪港旅客在各大市場的平均年齡，介乎35 至 42 歲之間。所有市場的平均年齡約為 37 歲，而內地、南亞及東南亞等地區市場的旅客整體較年輕，美洲、大洋洲、台灣等地區市場的旅客整體較年長。

# 香港旅遊業爭取過境旅客延長留港時間

過夜旅客訪港時間較不過夜旅客長，整體消費也比不過夜旅客高，並有利本地酒店、餐飲等行業的發展。因此，香港旅遊業一直致力爭取更多過夜旅客來港。

香港國際機場是亞太地區的重要航空樞紐，每年經香港機場轉機或過境的旅客超過二千萬人次。香港旅遊發展局為了吸引這批過境旅客延長留港時間，於 2017 年推出了「過境旅客留港優惠計劃」，向乘搭指定航空公司客機及在港停留六小時以上的旅客，提供多項優惠措施，以增加他們入境香港觀光的意欲。

計劃下的優惠措施包括：

• 免費送贈機場快線即日來回票；  
• 以優惠價享用機場來回迪士尼樂園接送及午餐或下午茶；  
• 以優惠價享用遊覽迪士尼樂園連機場來回接送；  
以優惠價享用機場來回昂坪360纜車接送，參觀360舞台、動感影院及與佛同行。

# 1.3 訪港旅客的目的及消費模式

訪港旅客的目的，包括度假、探訪親友、商務/會議及途經香港等；消費模式則要分析旅客在食住行遊購娛各方面的開支。

# A 過夜旅客

根據統計數據，各大市場的過夜旅客，以度假為訪港第一主要目的佔多數，而第二及第三主要目的則有所不同。

內地旅客：有六成的內地過夜旅客，訪港的目的是度假；兩成訪港的目的是探訪親友，比例高於其他國家或地區；一成訪港目的是商務工作/出席會議。

短途地區旅客：不包括內地在內的短途地區市場，過夜旅客以度假為訪港目的約有七成；第二主要目的是商務工作 / 出席會議，比例約一成五；第三主要目的是探訪親友，比例不足一成。

長途地區旅客：長途地區市場方面，過夜旅客以度假為訪港目的約有五成；第二主要目的是商務工作 / 出席會議，比例約兩成；第三主要目的是探訪親友，比例約一成五。

# 消費模式

訪港旅客的主要消費用於：購物、住宿、觀光、膳食、娛樂及其他。根據統計數據，整體而言，購物消費在過夜旅客和不過夜旅客中，所佔消費總額的比例均最高。

# A 過夜旅客

在 2019 年，過夜旅客的購物消費，整體佔消費總額接近五成，酒店住宿約佔兩成，酒店外膳食約佔一成五，娛樂、觀光及其他合共約佔一成五。不過，內地旅客與短途地區旅客、長途地區旅客的消費模式略有不同。

內地旅客：內地過夜旅客的最主要開支是購物，佔消費近六成，比例遠高於其他短途地區和長途地區旅客；其次是酒店住宿和酒店外膳食，均約佔一成五；娛樂、觀光及其他合共約佔一成。

短途地區旅客：不包括內地在內的短途地區市場，過夜旅客的最主要開支是酒店住宿，略高於消費總額三成；其次是購物，約佔三成；酒店外膳食佔近兩成；娛樂、觀光及其他合共約佔不足兩成。

長途地區旅客：長途地區市場方面，過夜旅客的最主要開支是酒店住宿，佔消費總額約四成五；其次是酒店外膳食和購物，各約佔兩成；娛樂、觀光及其他合共佔不足兩成。

與入境旅遊相關的總消費：2019 年與入境旅遊相關的總消費達 2 562 億港元，較 2018 年歷史高位的近 3 300 億港元下跌逾兩成。其中「境內總消費」為 2 066 億港元，「國際客運服務消費」為496億港元。

不過夜旅客消費：2019年不過夜旅客的總消費有642億港元，佔總消費約兩成五。內地不過夜旅客的消費有 604 億港元，佔不過夜旅客總消費的94.1%。

# 本港旅遊景點的發展概況

為了增加香港對旅客的吸引力，政府及旅遊相關機構持續重新包裝現有的旅遊景點，以及開發新的旅遊景點。以下是本港一些主要景點的發展概況：

# A 香港海洋公園

香港海洋公園於 2004 年推出《全新發展計劃》，興建大型水族館「夢幻水都」、熱帶雨林天地、冰極天地、香港老大街等景點，以及有多款機動遊戲的「高峰樂園」。

2012 年起，公園推出第二輪擴建工程，興建兩間酒店（首間於2019年開幕，第二間於2022年開幕）、全天候水上樂園（於2021年開幕）。

香港海洋公園在 2020 年公布未來發展藍圖，定位為以保育為本、充滿刺激歷險、融合自然的主題公園度假勝地，將會重新發展成為七個以歷險為主軸概念的體驗區，並加入一系列嶄新景點和高科技刺激遊樂設施，屆時海洋公園的景點數目會增加約四分一至超過一百個。

# 「盛事基金」停止運作

香港特別行政區政府於 2009 年撥款成立「盛事基金」，用作支持本地的非牟利團體，如藝術協會、體育組織等，在本港籌辦大型文化、藝術、體育及娛樂盛事，以協助香港發展為「亞洲盛事之都」，確立品牌盛事，提升香港的國際形象，以及吸引旅客來港。

「盛事基金」資助的項目包括香港許願節、香港龍獅節、香港龍舟嘉年華、香港高爾夫球公開賽、香港網球精英賽等。

至 2017 年，「盛事基金」停止運作，政府改以新策略，支持各類型的盛事和活動在本港舉行，例如為極具旅遊價值的大型商業盛事提供一站式支援、提升本地盛事地位，為已樹立國際品牌效應的盛事提供資助，以及推出先導計劃，資助具香港特色和旅遊價值的活動，以保持香港的旅遊競爭力。

# 1.5 香港各類旅遊概況

根據《香港旅遊業發展藍圖（2017 年）》，香港會大力發展會獎旅遊、郵輪旅遊、綠色旅遊及文化旅遊，以下將介紹這幾項旅遊項目的概況。

# 會獎旅遊

會獎旅遊即會展及獎勵旅游，包括會議 (Meeting)、獎勵(Incentive)、大型會議 (Convention)、展覽 (Exhibition) 四類活動，簡稱 MICE。

# A 香港會獎旅遊的發展概況

根據統計數字，2018年有約200萬過夜會獎旅遊旅客訪港，平均留港 4 日 3 夜，人均消費達 8 200 港元，較一般旅客多花約兩成。

會獎旅遊除了為香港帶來高消費客群，同時能鞏固本港國際商業和貿易中心的地位。在 2018 年，便有 138 個「商貿」和「商貿及消費」展覽在香港舉行，共吸引 69 000 多家參展商。根據香港展覽會議業協會估計，展覽活動已為本港創造 77 000個全職職位。可見會獎旅遊有助促進本港經濟發展。

# B 香港會獎旅遊的主要公營機構

為強化香港作為亞太區舉行企業會議、獎勵旅遊、會議及展覽首選地的領先地位，政府及相關公營機構成立了專責部門負責有關事項。

香港貿易發展局轄下的展覽部：該展覽部會與政府經濟貿易辦事處及投資推廣署等合作，向海外推廣本港會獎旅遊及產品，競標大型 MICE 活動，參加國際會展展覽，為會展旅遊者建立在線業務匹配平台， 以及加強現有的接待服務等。

香港旅遊發展局轄下的香港會議及展覽拓展部：該部門會為在本港舉行的會展獎勵旅遊活動提供一站式的專業支援服務，協助活動順利舉行。服務範圍包括場地協調、宣傳推廣、提供酒店住宿資料、安排市內活動和業界優惠、在機場設立特快專用入境櫃檯，以及籌備文娛休閒節目等。

# C 香港會獎旅遊的主要設施

香港目前的大型會議展覽場地，有香港會議展覽中心、亞洲國際博覽館、九龍灣國際展貿中心。

香港會議展覽中心：位於香港島的灣仔北，交通便利，於1988 年開幕，提供 91 500平方米的可租用面積。

亞洲國際博覽館：位於大嶼山香港國際機場，較遠離市中心，於2005年啟用，提供超過70 000平方米的可租用面積。

九龍灣國際展貿中心：位於九龍的九龍灣，於1995年啟用，大型展覽場館可租用面積達75 000平方呎。

# D 香港發展會獎旅遊的優勢

地理位置優越：香港位處亞太地區的中心地帶，五小時內可飛抵全球逾半數人口居住的地方，同時是進入內地市場的重要門戶。

設施齊備進出方便：香港國際機場是航空樞紐，航線連繫世界各地主要城市，交通及會展基建齊備，而且人員、資金及展品的進出均十分方便。

旅客免簽證來港：香港實行寬鬆的入境政策，目前有超過170 個國家或地區的人士可免簽證訪港，逗留七天至六個月不等，可方便商務旅客來港參與會獎旅遊。

良好的商業環境：香港具有高質素的專業服務支援、良好的英語營商環境、獨立運作的司法體系，加上與內地毗鄰，是中西營商者的交匯點，深得不同行業參展商及買家歡迎。

多元化的活動：香港旅遊發展局等機構，致力推動本港會獎旅遊發展，推出各種計劃和活動，有助吸引不同行業參展商及買家在香港舉辦國際會議和展覽。

# 郵輪旅遊

全球郵輪業旅客在過去二十年有穩定增長，其中亞洲地區的郵輪業發展尤為迅速。

# A 香港郵輪旅遊的發展概況

根據統計數字，在 2019 年，有 12 萬多人次旅客乘坐同一郵輪進出香港。另外，還有數以萬計經郵輪抵港而以其他途徑離港，或經其他途徑抵港而以郵輪離港的旅客。

# B 香港郵輪旅遊的發展策略方向及措施

政府致力發展香港成為區內的郵輪樞紐，以把握全球郵輪市場增長帶來的機遇，促進本港郵輪旅遊業的發展。為此，政府制定了四個主要策略方向：

• 帶動更多郵輪調配到香港；  
• 建立香港作為郵輪旅遊目的地；  
• 發展多元化的郵輪旅遊客源市場；  
• 提升香港在國際郵輪業的地位。

為策導本港郵輪旅遊業朝上述的策略方向發展，政府推行多項配合措施，包括作出便利業界的安排，以及向旅遊發展局撥款以實施支援業界的計劃。

![](images/69161f3f449d1b915f459bce17dbc4688fdb49137fff1cf816b7b1892f2f9008.jpg)

# 例子庫

政府優化過境郵輪旅客辦理出入境手續的安排；向香港旅遊發展局撥款，與業界合作推廣「飛航郵輪」旅遊，推出計劃吸引各地旅客乘航機來港再轉乘郵輪；又與業界合作發展和推廣「鐵路郵輪」旅遊，在高鐵沿線主要城市加強推廣「鐵路郵輪」產品；並鼓勵郵輪公司與香港的旅遊景點合作，推出結合「郵輪與景點」的優惠套票。  
香港政府致力拓展「亞洲郵輪聯盟」，邀請更多區內港口參與，以吸引更多旅客選擇聯盟港口，尤其是香港的郵輪旅遊產品。

# C 香港發展郵輪樞紐的優勢

地理環境：香港的維多利亞港，航道水深寬闊，而且沒有淨空高度限制，可供大型郵輪泊岸。香港氣候和暖，海港終年不結冰，郵輪可一年四季進出。

可達度：香港位處亞太地區的中心地帶，擁有完善的航空運輸網絡，能方便各地旅客乘航機來港再轉乘郵輪；同時可提供多元化郵輪航程選擇，包括鄰近沿海城市，以及遠東航程、環球航程。

郵輪設施：香港目前擁有啟德郵輪碼頭和尖沙咀海運碼頭兩個郵輪客運碼頭，可供巨型郵輪停泊，以及處理大量旅客上落和過境通關。另外，香港海港內設有多個拋錨地點，可供郵輪臨時停留和進行維修。

區域位置局限：新加坡和上海相繼宣佈要發展成為區域性郵輪樞紐，兩地已分別成為東南亞及東北亞多條郵輪航線的母港。由於香港位處來往東南亞和東北亞地區遠程郵輪航線的中間，只能作為這些郵輪旅客的停靠港。以香港作為母港的區域航線，只能較多前往台灣、越南、泰國、新加坡等地。

欠缺新景點：香港欠缺具吸引力的新旅遊景點，對開拓旅遊客源構成局限。至於啟德郵輪碼頭的交通配套不足，旅客曾需要等候多時才能乘搭其他交通工具前往各景點，降低了旅客的旅遊體驗，也對本港的郵輪旅遊形象造成負面影響。

本地市場有限：香港居民雖然熱衷旅遊，但本地人口不足八百萬人，相對內地珠江三角洲、長江三角洲地區的人口，對郵輪公司的吸引力相對較小。假如香港未能有效宣傳推廣、簡化出入境手續，吸引更多珠江三角洲等周邊地區居民前來參加郵輪旅遊，郵輪公司將缺乏足夠動力進一步拓展香港市場。

# 綠色旅遊

綠色旅遊，又稱生態旅遊或自然環境旅遊，泛指觀光遊覽自然景區。綠色旅遊是全球其中一項旅遊業增長新動力，根據香港立法會 2019 年的文件，全球自然環境旅遊業務每年總值達1 000 億美元。

根據香港旅遊發展局資料，2018 年有超過一成的長途市場過夜旅客，曾遊覽香港的郊野公園、遠足徑和海灘等「綠野風光」景點。

# A 香港綠色旅遊的公共政策與措施

培育及支持發展綠色旅遊，是香港政府的其中一個旅遊發展目標。為此，政府撥款香港旅遊發展局，推出先導計劃為業界提供資助，探討開發不同的綠色旅遊產品和景點，與地區攜手推動可持續的綠色旅遊發展。

另外，為了推動綠色旅遊發展，當局落實改善郊區碼頭設施計劃，探討改善前往地質公園的陸上交通連接安排，以及改善往返離島綠色景點的街渡服務。

政府又透過「香港郊野全接觸」為推廣平台，向旅客推介香港的地質公園、離島風光、行山徑和其他綠色景點。

# 「一國兩制」與香港航空發展

香港國際機場是全球其中一個最繁忙的機場，有超過200個航點連繫世界各地城市。事實上，香港特別行政區政府一直積極與外國訂立民航協議，以增加來往香港的航線，鞏固香港作為國際航空樞紐的地位。

香港《基本法》第五章第一百二十八條列明：「香港特別行政區政府應提供條件和採取措施，以保持香港的國際和區域航空中心的地位。」至於第一百三十三條列明：「香港特別行政區政府經中央人民政府具體授權可：

（一） 續簽或修改原有的民用航空運輸協定和協議；  
（二） 談判簽訂新的民用航空運輸協定，為在香港特別行政區註冊並以香港為主要營業地的航空公司提供航線，以及過境和技術停降權利；  
（三） 同沒有簽訂民用航空運輸協定的外國或地區談判簽訂臨時協議。

不涉及往返、經停中國內地而只往返、經停香港的定期航班，均由本條所指的民用航空運輸協定或臨時協議予以規定。」

因此，在「一國兩制」下，香港特別行政區政府擁有航空方面的高度自治權，這既促進了香港航空等不同範疇的發展，同時便利了香港居民到世界各地旅遊。

# E 陸路出入境管制站

香港回歸前，陸路出入境管制站只有羅湖、文錦渡、落馬洲、沙頭角和紅磡。香港回歸後，與內地的交往日益頻繁。為了應對兩地不斷上升的旅客出入境需求，香港與內地協議，先後開通了落馬洲支線、深圳灣、西九龍、港珠澳大橋、香園圍等陸路出入境管制站。
