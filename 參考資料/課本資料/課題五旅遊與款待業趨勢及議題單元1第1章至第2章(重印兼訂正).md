# 1.1可持續發展概念及其於旅遊業的應用

# 可持續發展的概念

根據聯合國環境與發展世界委員會的報告，可持續發展是一個追求經濟丶社會和環境三方面平衡的發展模式。在滿足當代人需求的同時，後代人的需求不會因此而受到損害。這一定義被稱為「我們共同的未來」

可持續發展的實踐主要集中在以下三個方面：

經濟可持續性：關注資源的高效利用與管理，以實現持續的經濟發展和穩定增長。這包括創造更多就業機會、提升經濟生產力，以及收窄貧富差距等。

社會可持續性：致力於通過促進社會包容性、機會平等和加強社區凝聚力，來提高全體成員的生活品質。這涵蓋人權保障、勞工權益、社會公正、文化多樣性，以及政治參與等。

環境可持續性：注重保護和維護自然環境，為後代創造可持續的生態條件。這涉及減少污染、推廣可再生能源、保護自然資源，以及維護生物多樣性等。

# 可持續發展概念對旅遊業的重要性

旅遊業正處於快速變化之中，並與交通、景點、娛樂、政治、宗教、經濟、金融、農業、環境、衞生、社會、教育和移民等多個相關範疇緊密交織發展。任何一個範疇的變動都無可避免會影響其他範疇，旅遊業也不例外。

旅遊業可為東道國帶來可觀的經濟收益，但亦會造成各種污染和資源過度耗費，例如加重當地水電等基礎設施的負擔。同時，過量旅客到訪，一方面會破壞動植物的棲息處，另一方面會打擾當地人的生活等。隨着環境和社會問題變得嚴重，景點對旅客的吸引力大減，變相不利當地旅遊業發展。

由於只着眼旅遊業帶來的經濟收益，長遠會阻礙當地旅遊業發展，所以可持續發展的概念慢慢被應用於旅遊業中。可持續發展旅遊業的目標，是確保各地在著重旅遊業經濟效益的同時，也要考慮社會和環境的需要，務求達致旅遊業長期而平衡的發展。

以2019 冠狀病毒病疫情為例，這場全球性大流行波及世界各地。由於多國實施旅行限制，以遏制病毒傳播，全球旅遊業遭受重創。

在許多城市，計劃旅行的人數大減。不僅出境旅遊受限，就連本地的博物館、主題公園和體育場館等旅遊景點，也需要關閉。

這一連串急劇的變化，迫使旅遊企業提高警覺，快速辨識變化、趨勢和潛在問題，並對業務進行必要的調整，以適應難以預測的情況和急劇變化的營運環境。

為了實現可持續發展目標，旅遊企業採取的方法包括密切關注媒體，尋找可能影響業務可持續的方式，同時儲備資金，以應對各項突發事件和不確定性挑戰。

# 生態旅遊不等同可持續發展旅遊

有些人對可持續發展旅遊產生誤解，以為生態旅遊等同可持續發展旅遊。事實上，生態旅遊不等同可持續發展旅遊，兩者的概念應予以清晰區分。生態旅遊是一種專注於欣賞和保護生態環境的旅遊形式；可持續發展旅遊則更為廣泛，關注環境、經濟和社會文化三方面的可持續性，適用於所有類型的旅遊活動和項目，包括傳統旅遊及各種另類旅遊形式。

# 1.2 可持續發展旅遊業的十二個目標

可持續發展旅遊的指導方針和管理實踐，適用於所有類型的旅遊目的地及旅遊形式，包括大眾旅遊和各種類型的利基旅遊。就可持續發展旅遊的理念，可持續發展旅遊之議程訂立了十二個目標，列出了需要考慮的所有關鍵要素，並提供了在經濟、社會和環境三大層面實現可持續發展旅遊的明確指引。

# 2.1全球化及其推動力

# 全球化的定義與特點

全球化指世界各地的交流和聯繫越趨緊密，彼此互相影響及依存的程度越來越高，形成全球一體化的現象。

時空距離縮小、全球網絡形成、各地交流緊密、世界連成一體、國際協作增加、普世價值傳播、本地文化商品化、同質化與標準化等，均是全球化的特點。

# 全球化的推動力

# A 技術發展

隨着交通運輸及通訊科技的進步，人口、貨物、資訊往來各地的時間大為縮短，成本大幅下降。各地交通及道路設施的建成，更提高了全球交通網的覆蓋率，有利各地的連繫和溝通，同時促進了旅遊業的發展。

互聯網的普及和發展，使通訊大為方便。旅遊企業可透過全球網上預訂系統，讓人們輕鬆預訂機票、酒店住宿。人們亦可利用電腦、智能電話搜尋旅遊資訊，與不同地域和文化背景的人即時溝通、分享資訊及交換意見。各地的連繫交流日趨緊密。

# B 經濟驅動因素

世界不少國家和國際經濟組織提倡自由貿易，消除各國之間的貿易障礙，放寬對資金、商品流動的限制，促進了各地的經濟交流和合作。

跨國企業把原料採購點、產品生產線及銷售點設於不同國家和地區，增加了資金、勞動人口、貨品在各地流動。

隨着全球經濟持續增長，民眾收入不斷上升，越來越多人能負擔出外旅遊的費用，推動了全球旅遊業的發展。

與此同時，低成本航空公司湧現，提供較低廉的機票，吸引更多旅客出行。

# C 對自己國家認識提高

由於教育和知識水平提高，以及社會經濟富裕，現今不少民眾閱歷豐富，見多識廣，並已遊遍自己國家和周邊地區的主要熱門景點。他們嚮往到新奇和遙遠的地方旅遊，例如一些人會前往北極及冰島等地。

# 2.2 全球化對旅遊業的影響

全球化促進了世界旅遊業的發展，並對旅遊業界、旅客行為、文化丶生態丶政治和科技等方面產生了不同的影響。

# C 造就網上旅遊代理平台出現

# A 依賴資訊科技

互聯網的普及和應用，令世界各地旅客可輕易搜尋到各類旅遊資訊，亦可自由透過應用程式預訂機票、酒店等旅遊產品，減少使用傳統的旅遊中介服務。不少旅客更會參考網絡紅或社交媒體上親友分享的遊記，作出旅遊決定。因此，今時今日，旅客在各方面均已十分依賴資訊科技。

# B 重視比較旅遊產品

由於資訊科技帶來的便捷，現時旅遊應用程式或旅遊平台可將各種旅遊產品及其價錢、內容、服務等，向人們清楚展示和排列。因此，旅客可輕易比較不同的旅遊產品，也較過去更樂意去作出比較。同時，匯率會直接影響人們外遊的成本，旅客在決定目的地和在目的地購物時，亦會仔細考慮匯率的變動，對價格份外敏感。

# C 重視消費品質

全球化下，人們接收到更多資訊，視野擴闊，會認識到不同國家和地區的文化產品及品牌。當他們到外地旅遊時，往往會想購買有關商品，很多旅行團更會安排購物環節。旅客一般認為，在品牌來源地購買的產品，質素較高、價錢較便宜。

# D 追求特別體驗

# 3 文化丶生態丶政治和科技對旅遊的影響

全球化下，社會各方面的變化都影響到旅遊業的發展。

# A 文化

• 全球化下，各地文化交流頻繁，並逐漸擁有普遍接受的文化和價值觀。這使來自不同國家和地區的旅客，在行為和價值觀上趨向相似，文化變得共融。  
• 然而，體驗不同國家和地區的文化獨特性，是很多旅客出遊的動機之一。當各地文化和生活方式變得相似，會令目的地的吸引力減少。  
• 另一方面，已發展國家及跨國企業積極向發展中國家推廣其文化和產品，使其他國家的傳統文化和價值觀受到衝擊，部分甚至最終消失，造成全球文化趨向單一。

# B 生態

• 生態價值會增加一個國家和地區作為旅遊目的地的吸引力。然而，在全球化下，不少發展中國家為了吸引外來投資，發展經濟，容許跨國企業開採其資源，進行生產活動，結果造成當地環境污染問題惡化，生態環境受到破壞，變相不利當地旅遊業的可持續發展。

# C 政治

隨着全球日趨一體化，各國在國際政治、外交事務上的合作更為緊密。這有助推動國際及區域性的旅遊業合作，為旅遊業創建更佳的政策和環境。  
全球化下，國際性旅遊組織會透過國際合作，消除阻礙各地旅遊業發展的因素。如設立旅遊行業守則，規管旅遊企業的不良營商行為；推廣旅客應有的出遊行為，減少旅客與東道國居民之間的文化衝突。

# D 科技

• 全球化促進資訊科技的普及，既方便旅遊企業向旅客宣傳及推廣，也便利企業之間的業務往來、企業與旅客之間的交易，以及能夠協助企業收集和分析旅客的消費數據。  
• 交通科技的發達，則降低各地旅客往來的成本，以及縮短他們往返的時間，有利旅遊業的進一步發展。

# B 文化同質化

文化方面，受到全球化的影響，各地民眾的生活方式和價值觀逐漸同化，這現象可被稱為文化同質化。當旅遊目的地與旅客所處國家和地區變得相似，同質化也隨之出現。

普遍來說，旅遊業中的文化同質化與以下三個因素有關：

• 示範效應：即東道國或旅遊目的地，尤其是發展中國家的民眾，模仿旅客的生活方式。當他們與來自已發展國家的旅客接觸增多，看到他們使用較先進的產品、穿着較華美的衣服等，便會希望能擁有同類的東西，並想方法去追求。  
西方產品的引入：為了照顧國際旅客的需要，各地旅遊目的地都引入西方產品，如西式的糕點等食物，或雪櫃、梳化等傢俱設施，以便旅客在觀光旅遊過程中可享用到平日的物品和設施。當地人在提供這些食物或設施的過程中，自己的生活方式久而久之也會改變。  
• 跨國企業的擴張：跨國企業如服裝品牌丶飲品公司和連鎖酒店等，會積極把其服務和產品擴展至全球各地，尤其是熱門的旅遊目的地。這些企業擁有豐厚的資本，當它們把西方的生活文化帶到各地，便會改變當地的文化。  
總括而言，文化同質化在發展中國家比較明顯。

# C 文化同質化對旅遊業發展的負面影響

# 標準化下的旅遊與款待業

# A 全球化下的標準化

生產方式的同質化就是標準化的過程。簡單而言，這裏的標準化是指同一跨國企業，在各地出售的產品質量統一，或是各地企業都向跨國企業學習同一套營運模式，經調整後再運用到商品生產和服務上。

# B 標準化的特色

般來說，標準化的營運模式有以下特色：

講求效率：以最短的時間、最低的成本，去達到業務目標。例如各地麥當勞的食物都有既定的製作程序，亦會以套餐形式出售。  
• 量化計算：由生產目標丶資本投入丶生產過程、產出數量和質量等，都經精密計算及客觀的量度和記錄。  
• 具可預計性：提供的產品和服務質素都力求均一無異，務求讓各地的顧客都能購買到相同的產品和服務。因此，生產工作的設計多為重複性和可預計性。不過，當中或會扼殺創意或少了通融的空間。  
• 具可監控性：為方便量化計算和更易控制，生產時員工的行為會被簡化為一系列重複的動作，每個人的獨特性會被隱藏。

# 3 本地文化商品化與文化在地化

# A 本地文化商品化

全球化下，外來文化在不同程度上改變了本地文化。其中本地企業為了與跨國企業爭奪文化商品市場，或為了迎合外地旅客，賺取更多利潤，會把當地文化產品商品化，以大量生產和銷售。

本地文化商品化有助吸引旅客購買本地產品，進而認識當地文化。旅客將旅遊目的地的商品化產品帶回自己國家和地區，亦能幫助推廣目的地的文化。

不過，當本地文化商品化，企業為了大量生產商品，便可能需要放棄傳統工序，或採用標準化的生產方式，只讓員工處理某一工序。另外，企業只會生產具商品性和具市場價值的產品。這就會妨礙到傳統藝術文化的傳承，造成全球文化趨向單一化。

# B 文化在地化

跨國企業會因應不同地方的文化背景及差異，為旗下產品注入各式本地文化元素，又會調整營運和宣傳策略，以迎合旅客及當地消費者的喜好和習慣。這形成了「文化在地化」現象。

# 公平貿易為何出現？

# A 國際債務龐大

發展中國家為了推動當地發展，會大力興建交通基建和景點，又會在各地進行宣傳推廣。可是不少國家缺乏資金，往往借下龐大的國際債務，造成財政負擔日大。

![](images/8f5479f90959df1602171b65ba2d2f542b26524b9d5c7d351bc50414b1ba8d9b.jpg)

# 例子庫

• 以撒哈拉地區為例，至 2018 年為止，當地約四成國家有嚴重債務危機，合共拖欠4 170億美元外債。

# B 對跨國企業提供稅項寬減

部分發展中國家無法提供國際旅客需要的設施和服務，政府為了吸引跨國企業前來投資興建酒店和渡假村等旅遊基建，便向跨國企業提供稅務寬減、土地優惠等。結果，跨國企業在投資初期完全不用向當地政府繳交稅項。到稅項寬減期過後，一些跨國企業會運用各種財技，在合法情況下，下調其向發展中國家繳納的稅款，以及其他經營費用。這造成發展中國家的整體稅收減少。

# 什麼是公平貿易？

# A 公平貿易的定義

根據世界公平貿易組織（WFTO）定義，公平貿易是一種貿易合作夥伴關係，在以對話、透明及尊重的基礎上，令國際貿易變得更公平；通過提供更好的交易條件，促進各國的可持續發展，尤其是確保發展中國家被邊緣化的生產者和工人的權利。

# B 公平貿易的主要原則

• 建立平等合作關係：跨國企業與發展中國家應是互助互利的夥伴關係，營運時應遵守當地政府的法例，亦應僱用當地人以提供發展機會  
• 確保交易支付公平：公平的支付是以雙方持續對話和共同參與為基礎，支付公平包括產品在市場上的價格要公平，以及企業支付勞工的報酬要公平。  
• 生產中有合理人權保障：投資者保障當地勞工享有良好工作條件，同時嚴守《聯合國兒童權利公約》，禁止聘用童工，亦承諾不作種族和性別歧視。  
珍惜當地環境資源：企業盡最大可能利用可永續管理的原材料，盡可能購買當地產品。企業亦應透過生產技術，設法減少能源消耗和對環境造成的破壞。

# 旅遊業中公平貿易的意義

現時，不少發展中國家對旅遊業收入有較高的依賴。透過在旅遊業實踐公平貿易，可以確保當地居民將土地、自然資源、勞動力、知識及文化應用於能為他們帶來合理回報的旅遊業活動中。通過本地與國際旅遊營運者之間的平等合作與互惠互利，公平貿易能為旅遊目的地的持份者爭取合理利益，並令雙方成為值得信賴的合作伙伴。維護當地社區權益，並在持份者與受益者之間實現平衡，始終是旅遊業發展過程中不可忽視的重要目標。

# 5 公平貿易對旅遊與款待業的好處

# A 對發展中國家而言

經濟發展穩定：在公平貿易原則下，東道國更有議價能力去保障自身在與跨國企業合作時的利益，減少資金外流；同時跨國企業採購更多當地產品或原材料，為當地社群帶來更多就業職位，可促進當地經濟發展。  
• 紓緩貧窮問題：公平貿易可使已發展國家的旅遊業發展更具持續性，保障當地民眾就業的同時，亦提供向上流動的機會，令更多當地人能夠脫貧。  
• 社會政治穩定：長遠而言，當地民眾因旅遊業的發展而得益，人人安居樂業，當地犯罪率亦會下降，社會更和諧，政局也相對穩定。

# B 對跨國企業而言

• 建立良好商譽：參與公平貿易的企業，可藉着承擔更多社會責任而建立起良好的信譽，從而吸引更多消費者和旅客支持。  
• 吸納人才：跨國企業為當地人提供就業和晉身機會，可吸納和培育熟悉當地文化的人才，長遠有助提高服務質素，以及增加員工的忠誠度，減少人才流失。  
• 獲取市場資訊：公平貿易下，企業與當地政府和社群緊密合作，可更容易得到相關市場資訊，從而加以應變，令產品和服務更具本地特色和具競爭力。

# C 對旅客而言

• 滿足感增加：旅客可透過參與公平貿易，幫助到他們到訪的地方及居民，從而增加旅遊滿足感。  
• 獲得優質產品：公平貿易產品會有標籤，代表產品通過檢測和驗證，符合國際公平貿易的標準，確保旅客購買的是優質產品。  
• 目的地選擇增多：長遠而言，公平貿易有助各地可持續發展，旅客亦有更多更完善的旅遊目的地供他們選擇。
