# 27.1 基本廚房的設計及布局

- 廚房的設計及布局必須非常審慎
- 因為廚房有很多各類電線、水、煤氣和排氣管道，完成後如果需要改動會非常困難，會耗費大量人力、物力、費用和時間

## A 廚房的工作流程和工作區

### 1 廚房的工作流程
- **驗收：** 點收食材和各類物資，單據存檔、貨物分別貯存
- **貯存：** 按冷藏食品、乾貨、飲料及一般用品等分別存放，位置視廚房設計而定，最少包括冷藏櫃和貯物格
- **準備：** 烹調前所需的工作，包括洗、切、預備烹調材料等多個步驟
- **烹調：** 包括預備冷盤和熱食
- **送餐：** 食物上碟後由傳菜員送出樓面
- **清潔：** 收回樓面和廚房用完的餐具和工具，清洗、消毒後放回各部門再使用

### 2 廚房的工作區
- **收貨準備區：** 進行驗收工作，一般位於廚房的入口，廚房員工上下班也經此地進出，不會從餐廳樓面進入廚房
- **儲物區：** 儲物區是貯存的地方，可以分為冷藏庫、飲料貯存、乾貨貯存及一般貯存等獨立空間，但香港租金昂貴，大多食肆只用大型雪櫃和儲物間存放
- **準備區：** 在準備區進行烹調前的各項食材準備工作，例如清洗蔬菜、肉類解凍及切割等。準備區內會有水喉、鋅盆、砧板等設備
- **烹調區：** 分冷盤區和熱食區，冷盤區處理沙律、生食菜式和甜品等，熱食區處理各種蒸、炒、炸、烤、烘焙等烹調工作
- **備餐服務區：** 
    - 備餐服務區在餐廳樓面及烹調區之間
    - 員工在上菜前作最後預備，例如裝飾、抹淨碟邊等
    - 之後傳菜員負責把食物送出樓面給客人
- **洗滌區：** 
    - 大部分廚房用具及樓面用完的餐具都會集中在洗滌區清潔
    - 完成後再放回各工作區及樓面器具存放架
    - 洗滌區、準備區、烹調區

## B 布局與設計

廚房的設計最重要的考慮因素有兩個：
1. **安全**
    - 食物安全
    - 員工職業安全
    - 處所安全
2. **運作效率**

### 1 廚房生產流程要暢通
- 順工作流程安排，不要出現交錯路線或逆向路線（交錯路線、逆向路線）
- **順暢流程的好處：**
    - 減少意外
    - 部門間易溝通，有助提升效率及發揮團隊精神
    - 工作省時省力，可減輕員工疲勞，增加生產力
    - 整個過程所用時間和步驟減少，減少食物污染的機會
    - 加快上菜時間，提高菜式質素
    - 增加餐桌回轉率，有助增加營業額

### 2 洗滌區與準備區分隔
- 洗滌區和準備區均需要大量用水
- 為免清潔工作的污水污染食物，洗滌區適宜儘量遠離準備區、烹調區和備餐服務區

### 3 更好的廚房環境
- 廚房是多油煙、高溫及潮濕的地方，改善工作環境可提高工作效率和保障員工安全
- 天花板須平整而無裂縫或飾紋，以防蟲鼠躲藏其中，亦方便清潔
- 牆壁應採用不吸水物料鋪成 (如瓷磚)，方便清潔油煙和污物
- 排煙通風要完善，因廚房生產大量油煙、蒸氣和各種氣味，需要使用抽氣扇、排煙罩、抽油煙機、送風管等
- 地面設排水口，防止廢水積聚，排水口設隔渣網方便處理垃圾
- 地面須用防滑、不吸油或水的物料 (如瓷磚)，最好有突紋以便沖刷和防滑
- 使用不銹鋼工作台和用硬質塑膠切菜板，容易清洗又耐用
- 設置充足照明裝置，減少工傷事故，亦有助監察食物素質

### 廚房通道
- 必須足夠讓食物、物資傳送等工作暢通無阻
- 為確保食物衞生，運送食物、廚餘和垃圾的手推車不應使用相同通道

### 4 充足的烹調用具
- 各區使用的器具要在本區使用，可減少食物污染的機會
- 例如使用準備區內切生肉的砧板和刀處理已烹調的熟肉，會引起食物污染
- 每區應配備本區用具，員工工作時用具齊全，工作效率更高

# C 影響廚房設計的因素

## 1 餐廳經營目標 (續)

- **餐廳的定位：** 例如快餐店、家庭式餐館、高級餐廳與宴會餐廳的廚房設計便大有不同
- **運作模式：** 例如如何配合每天早、午、晚餐的不同運作
- **服務方式：** 例如餐廳提供餐桌服務或自助式服務，會影響餐單與員工的安排
- **廚房類型：** 半公開式廚房、自助餐廳、中餐

## 2 餐單

- **菜式：** 菜式種類越多、製作技術越複雜，需要的設備及作業流程也更多，設計時必須考慮在內
- **烹調方法：** 例如較多煎炸食品為主的快餐店可能毋須太多蒸食物用的器具

## 3 投入資金

- 負責人應先有成本預算再決定廚房設計和設備

## 4 廚房員工

- **人數：** 員工越多，所需工作空間越大
- **技能水平：** 例如會有大量低技能員工或以專業廚師為主力

## 5 食材

- **外購或全部自製：**
    - 因技術、設備等問題，個別食肆會使用部分外購食品而並非全部自製
    - 例如不少快餐連鎖店的食材便先由中央廚房洗淨和處理，再送至分店烹調
    - 即使高級餐廳也會有部分食材購自其他食物供應商，不一定會全部自己製作

## 6 設備

- 由於租金昂貴，餐廳一般傾向選用較小型、容易擺放的設備
- 選用易用、易清潔和易維修的設備
- 考慮設備能否局部使用，這樣在清閒時段只需啟動部分設備，可節約能源
- 考慮多功能的設備，有助節省空間、成本和能源消耗

## 7 能源配合

- 有關水、電、煤等喉管分布要配合設計

## 8 合符營業規格

- 廚房設計要符合多項建築物及設備的法例要求
- 包括在食物安全、員工職業安全和消防方面

### 廚房設計發牌要求
香港特區政府對於食物業廚房的設計及建造都有嚴格的要求，可詳見於《食物衞生守則》。此外，食物業經營者必須遵從政府的衞生及消防等有關條例才獲發食肆牌照。

## 27.3 消防安全

### A 燃燒要素與滅火原理

#### 1 燃燒要素
物質燃燒有四個條件，包括可燃物、熱力及氧氣，還有三者互相作用而產生的連鎖反應：
- **可燃物：** 包括三種物質狀態的燃料，如炭和煤 (固體)、汽油 (液體) 和石油氣 (氣體)，及任何可燃燒的東西，例如紙張和布料。
- **熱力：** 必須有熱力才使可燃物釋出物質，與空氣中的氧氣產生化學作用和燃燒。
- **氧氣：** 熱力令可燃物釋出物質，與氧氣產生化學作用和燃燒。
- **連鎖反應：** 燃燒又產生更多熱力，令可燃物釋出更多物質，令燃燒可以持續而且不斷循環。

#### 2 滅火原理
- 只要把可燃物、溫度或氧氣任何一個條件移除，便可滅火。

#### 3 火災的分類
用水滅火不一定奏效，許多情況下可能令情況更壞。根據中國《火災分類》國家標準，火災可以分為六類，撲滅時要選擇相應的滅火方法：
- **A 類火災：** 由含有有機物質的固體，例如木材、紙張、布和塑膠引起的火災，一般在燃燒時能產生灼熱的餘燼。
- **B 類火災：** 由液體或可熔化的固體物質，例如液化石油氣或固體油脂引起的火災。
- **C 類火災：** 由易燃性氣體如煤氣引起的火災。
- **D 類火災：** 由鈉、鉀等易燃金屬引起的火災。
- **E 類火災：** 物體帶電燃燒的火災，例如使用中的變壓器和發動機等引起的火災。
- **F 類火災：** 烹飪器具內的烹飪物 (如動植物油脂) 引起的火災。

### B 餐廳常用消防設施與用具

- 香港餐廳要遵從消防安全 (商業處所) 有關條例。
- 增設基本的消防裝置及設備。
- 確保飲食處所的建造規格等符合屋宇署的有關規定。

#### 設施包括：
1. 認可的人手操作手提滅火器具，如滅火筒
2. 緊急照明系統
3. 機械通風系統的自動停止設施
4. 手控火警警報系統
5. 消防栓及喉轆系統
6. 自動噴灑系統

#### 1 滅火筒
- 於火警剛發生時員工可用滅火筒迅速應付，避免火勢進一步蔓延。
- 根據不同類別火源，要使用不同類型的滅火筒。
- 圖示設備：水式滅火筒、二氧化碳氣體式滅火筒、泡沫式滅火筒、乾粉式滅火筒。

**滅火筒類型使用對照表 (✓= 可以使用 🗶 = 不可使用)**

| 火源類別 | 水式滅火筒 | 二氧化碳氣體式滅火筒 | 泡沫式滅火筒 | 乾粉式滅火筒 | 淨劑滅火筒 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **A 類火災** (例如紙、布、木、膠料) | ✓ | 🗶 | ✓ | ✓ | 🗶 |
| **B 類火災** (例如液化石油氣、固體油) | 🗶 | ✓ | ✓ | ✓ | ✓ |
| **C 類火災** (例如煤氣) | 🗶 | ✓ | ✓ | ✓ | ✓ |
| **D 類火災** (例如鈉、鉀等易燃金屬) | 🗶 | ✓ | 🗶 | ✓ | ✓ |
| **E 類火災** (例如使用中的變壓器和發動機) | 🗶 | ✓ | 🗶 | ✓ | ✓ |
| **F 類火災** (例如煮食鑊內的植物油) | 🗶 | ✓ | ✓ | ✓ | ✓ |

#### 2 滅火氈
- 適用於燃燒中之易燃液體，例如在廚房發生的小火。
- 可用滅火氈覆蓋在火焰上以隔絕空氣，關掉煤氣等熱源，待燃燒停止物體冷卻後移開滅火氈。

#### 3 沙桶
- 簡單易用，適用於小火或清理濺落在地面上的易燃液體。
- 減少引發火災機會。
- 沙要保持乾爽，因為引起 D 類火災的易燃金屬可與沙粒中的水份產生作用令火勢更猛烈。

#### 4 消防喉轆系統與消防龍頭
- 必須每年最少檢查一次並不時作測試以確保能有效運作，有關設施不可以有任何阻塞。

#### 5 消防花灑系統
- 設在餐廳及廚房頂部，在 50 厘米範圍內不可以有任何阻隔。
- 當花灑上的感應器感到熱力達至限度，便會自動灑水滅火。
- 由於每一個花灑裝置覆蓋範圍有限，必需在指定位置安裝才有效。

#### 6 應急照明系統
- 用防火物料製造，安裝在固定位置，緊急時自行啟動，確保走火通道及相連之公眾地方有足夠照明。
- 若電力中斷，系統內電池會在數秒內啟動。

# C 增強員工消防安全意識

以下是餐廳員工應有的防火知識：

## 1 使用電器方面
- 正確地使用各類電器用品，經常檢查電器的線路
- 如發現電器有任何隱患應及早通知工程人員

## 2 使用爐具方面
- 爐具四周不應放置任何雜物 (如：廢紙、抹布等)
- 確保爐具四周沒有積聚油脂

## 3 烹調方面
- 烹調食物時應有工作人員看守爐火
- 烘烤或油炸食物時需注意烹製程序
- 不可在非煮食區生火烹製食物

## 4 通道與設備方面
- 任何時候樓梯及防煙廊的防煙門都要保持關閉
- 確保走火通道及樓梯暢通無阻
- 確保處所內的防火設備運作正常

## 5 其他注意事項
- 離開工作處所前，應關掉所有火源、電源或燃料供應掣
- 易燃物品 (如：酒精、食油、火水、氣罐、用聚苯乙烯泡沬塑料製成的食物容器等) 應遠離爐火或任何熱源
- 清理煙灰缸時必需確保煙蒂完全熄滅才倒進垃圾箱

# 提升處所負責人的防火意識

除餐廳員工外，負責人亦對其處所的消防安全工作負有責任，因此他們需認識及遵循以下消防安全的措施，例如﹕

- 食肆座位間容納的人數不得超出建築事務監督所批准的限額；
- 在食肆出口安裝以中英文字書寫「EXIT」或「出口」的燈牌(顏色對比為：綠字白底或白字綠底)；
- 嚴禁雜物阻塞樓梯及走火通道；
- 確保防煙門在任何時候都必須緊閉但不上鎖；
- 確保處所內的消防裝置不會被雜物阻擋；
- 定期檢查及維修消防設備。
