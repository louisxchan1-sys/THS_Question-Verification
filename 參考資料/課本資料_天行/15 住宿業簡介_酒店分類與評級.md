## 15.1 住宿的分類

### A. 非牟利住宿

一些不以盈利為目的，所得收入主要用於補貼營運成本或發展更多社會服務：

- 租住的公共房屋
- 大學宿舍
- 政府及慈善機構開辦的老人院
- 臨時收容中心

### B. 牟利住宿

#### 按時間分
- **長期的**：例如住屋
- **短期的**：例如酒店

#### 按設施分
- **家庭式**：有各類烹調和洗濯設施
- **度假式**：沒有太多家庭設施，卻有更多康樂休閒設施

#### 按服務分
- **全套管家式服務**：例如酒店住宿
- **很少甚至沒有服務**：例如青年旅舍

## 15.2 酒店的分類和特色

### 酒店的定義

根據香港法例第158章《酒店東主條例》，酒店 (Hotel) 的定義：

> 酒店指任何場所，其東主顯示該場所是一處向到臨該場所的任何人提供住宿的地方，而該人看似是有能力並願意為所提供的服務及設施繳付合理款項，而且是在宜於予以接待的狀況的。

### 酒店分類方式

- 地理位置
- 功能設施
- 服務水平
- 規模
- 房價
- 評級
- 產權

---

### A. 以地理位置分類

#### 1. 市中心酒店
- 位於交通便捷、各類設施集中的巿中心
- 房價一般較高
- 規模及類型分別很大，有頂級酒店，也有規模較小但房價較便宜的住宅式酒店

#### 2. 近郊酒店
- 位處郊區
- 較低密度環境和較大空間
- 提供完善酒店設施
- 交通較為不便

#### 3. 機場酒店
- 鄰近機場
- 接待較多使用機場的旅客，如商務旅客、機師及空中服務員；或因各類原因滯留的旅客
- 提供往返機場的接載服務
- 商務設施和完善服務
- 餐廳等設施的開放時間較長

#### 4. 公路酒店或汽車旅館
- 通常位於市郊公路附近，經營規模較小，提供最基本的住宿設施及服務
- 主要服務駕車作長途旅行的旅客，車子可直接停在客房門前

---

### B. 以功能設施分類

#### 1. 會議酒店
- 設在政治經濟要地，不少更毗鄰國際級的會議展覽中心
- 一般規模龐大
- 目標顧客為參加和舉辦大型會議的團體或商務旅客
- 擁有大量客房
- 有多個會議廳及宴會廳等活動空間，以滿足會議團體的需求
- 配有各類高科技會議設備，並具有接待大批客人、處理大型會議等服務能力

#### 2. 商務酒店
- 多位於市區工商業地帶
- 服務商務旅客為主
- 完善的商務中心提供全面支援服務
- 有各類餐飲服務和娛樂消閑設施如泳池、健身中心等
- 較缺少會議酒店所擁有的大型活動空間

#### 3. 賭場酒店
- 並非單以賭客為主，也包括商務旅客及一家大小的度假旅客
- 有豪華的設施及各類娛樂購物場所，例如表演場地、購物中心和各種類型的食肆酒吧

#### 4. 度假酒店
- 度假酒店多位於海濱、森林、山區等風景優美地區
- 一般遠離市區，客人逗留較長時間
- 有各式各樣的休閒康樂設施，如游泳池、溜冰場、高爾夫球場、保齡球和戲院等
- 有多樣化的餐飲設施供選擇
- 酒店還有完善的會議設備，也可招待會議團體，或商業及政府機構行政人員舉辦的退修聚會等

#### 5. 溫泉酒店及水療酒店
- 規模大小不一
- 最主要特色是設有各類溫泉泡池和浴池
- 日本與台灣的溫泉旅遊發展相當蓬勃
- 水療酒店性質類似，專為客人提供各類以保健養身為主的服務和設施

---

### C. 以服務水平分類

|  | 全套服務式酒店 | 有限度服務式酒店 | 長期住宅式酒店（又稱酒店式服務住宅） |
|---|---|---|---|
| **目標客源** | 需要有關設施服務 | 價錢實惠，對服務設施要求不高 | 逗留時間較長 |
| **客房設施和服務** | 完善又優質的住宿服務和各類設施 | 客房空間不大，傢俱較少；服務以清潔客房為主 | 住宅式設計包括睡房、起居間和廚房等；提供管家服務，包括客房清潔及替客人洗熨衣物等 |
| **餐飲設施和服務** | 有各種餐廳酒吧等設施 | 很少甚至沒有，客人要在街外用膳 | 較少甚至沒有 |
| **宴會和會議場地或設施** | 有 | 較少甚至沒有 | 較少甚至沒有 |
| **其他服務** | 有多項增值服務，包括禮賓服務等 | 較少甚至沒有 | 針對家庭客的相關服務為主；整體上較有限度服務式酒店多 |
| **香港例子** | 會議酒店、商務酒店及度假酒店均屬此類 | 紅茶館酒店 | 灣仔麗悅酒店 |

---

### D. 以酒店評級分類

- 「五星級大酒店」、「四星級大酒店」
- 公共或私人評級機構對酒店的評級，例如香港旅遊發展局、美國福布斯旅遊指南、中國國家旅遊局

---

### E. 以規模分類

- 酒店的規模與其營運方式關係密切
- 房間數目是反映酒店規模一個重要指標
- **小型酒店**：少於 100 間客房
- **特大型酒店**：超過 3000 間客房

---

### F. 以房價分類

- 大致可分為**豪華型**和**經濟型**
- 根據旅遊發展局資料，2019 年全港酒店平均房價為每晚 HK$1,206
- 甲級高價酒店房價可以接近 HK$2,000，但中價酒店大小相同的客房價可以低於 HK$650
- 有更廉價住宿，包括賓館、旅舍及民宿旅館等

## 15.3 其他住宿類型

### A. 舊式建築改建酒店

- 發展商會把一些古舊建築改建成酒店
- 這類酒店都保留原建築的特色，客人入住可感受到不一樣的歷史氛圍

**例子：**
- 位於尖沙咀的1881公館原是香港水警總部
- 大澳文物酒店前身為大澳警署

### B. 賓館

- 規模比經濟型的酒店小
- 只有基本的設施如空調、獨立洗手間、電視、電話等
- 多建於市中心，旅客要同時利用賓館附近的設施

### C. 旅舍

- 多位於市郊，價格便宜、設備簡樸的住宿服務
- 服務對象主要是自由行的年青旅客
- 通常是多人共住客房
- 只設有簡單的睡床、衣櫥，房內沒有通訊或娛樂設施，旅客亦需共用浴室及洗手間

### D. 民宿旅館

- 民宿旅館多位於市郊或鄉間的度假及觀光熱點附近，或由民居改建而成
- 業主負責接待和清潔
- 旅館規模小，客房數量有限，沒有酒店專業的服務及完備設施，只為旅客提供基本的住宿設備及早餐

## 15.4 酒店評級系統

### A. 香港酒店分類系統

世界各地的酒店並無統一的評級標準。

#### 1. 香港酒店分類系統的四個級別

香港旅遊發展局的酒店評級：

| 級別 | 綜合分數 |
|------|----------|
| 甲級高價酒店 | ≥ 3.00 |
| 乙級高價酒店 | 3.00 > 分數 ≥ 2.00 |
| 中價酒店 | 2.00 > 分數 ≥ 1.00 |
| 旅客賓館 | 評分不適用 |

> 酒店名單不公開，但會通知個別酒店

#### 2. 香港酒店分類系統的五個計算指標

##### (a) 酒店設施（25%）

| 設施分類 | 說明 | 分數 | 分數佔比重 |
|----------|------|------|------------|
| 飲食設施 | 酒店內餐飲場地數目 | 0-8 | 0.09 |
| 電訊設施 | 酒店提供的電訊設施：包括可租借手提電腦、寬頻上網、無綫上網及室內資料輸入插口 | 0-4 | 0.05 |
| 商務設施 | 酒店提供的商務設施：如商務中心、宴會設施、會議設施以及行政樓層 | 0-4 | 0.06 |
| 康樂及其他設施 | 酒店提供的康樂及相關設施：包括健身室、游泳池、運動設施、按摩服務、桑拿室／水療設施以及為殘疾旅客而設的房間 | 0-6 | 0.05 |
| **總比重** | | | **0.25** |

##### (b) 酒店地點（20%）

| 地區 | 分數 |
|------|------|
| 尖沙咀、中環、金鐘、銅鑼灣及國際主題公園 | 5 |
| 佐敦、旺角、油麻地、灣仔及大樓設有或鄰近出入境管制站或國際會議及展覽場地 | 4 |
| 北角、上環、西區、紅磡、沙田及荃灣 | 3 |
| 其他九龍及香港地區 | 2 |
| 其他新界地區及離島 | 1 |

##### (c) 職員與客房數目比例（20%）

| 職員與客房數目比例 (SRR) | 分數 |
|--------------------------|------|
| SRR ≥ 1.00 | 3 |
| SRR ≥ 0.50 | 2 |
| SRR < 0.50 | 1 |

##### (d) 酒店實際平均房租（20%）

| 酒店實際房租 (AARR) | 分數 |
|---------------------|------|
| 實際房租 ≥ HK$1,350 | 3 |
| HK$1,350 > 實際房租 ≥ HK$750 | 2 |
| 實際房租 < HK$750 | 1 |

> 備註：根據2024年數據。平均房租的分數根據每月酒店入住率的調查結果計算，實際房租數字會根據酒店問卷調查之結果作出修訂。

##### (e) 商務組合（15%）

| 商務組合 (BM) | 分數 |
|---------------|------|
| 商務旅客比率 ≥ 20% | 2 |
| 商務旅客比率 < 20% | 1 |

> 備註：數字會根據旅遊發展局之離境旅客問卷調查之結果作出修訂

#### 3. 分類計算方法

按照酒店在每項的評分乘以該項比重，把所有指標比重加起來便成為該酒店的綜合分數：

| 評分指標 | 評分 | 分數佔比重 | 指標比重 |
|----------|------|------------|----------|
| **(A) 酒店設施** | | | |
| 飲食設施 | | 0.09 | |
| 電訊設施 | | 0.05 | |
| 商務設施 | | 0.06 | |
| 康樂及其他設施 | | 0.05 | |
| **(B) 酒店地點** | | 0.20 | |
| **(C) 職員與客房數目比例 (SRR)** | | 0.20 | |
| **(D) 酒店實際平均房租 (AARR)** | | 0.20 | |
| **(E) 商務組合 (BM)** | | 0.15 | |
| **總指標比重分數** | | | = 酒店所得綜合分數 |

---

### 案例分析：計算酒店評級

**A酒店資料：**
- 位於中環商業中心區
- 有各類客房 120 間
- 各部門員工 360 人
- 提供各項頂級酒店服務及設施
- 目前酒店有 8 間頂級餐廳和酒吧，數量為全港之冠，其中包括三家米芝蓮星級餐廳
- 有不同類型的商務及康樂設施，包括提供 24 小時服務的商務中心、可供 1200 人使用的大宴會廳及多個不同大小的會議室等
- 酒店有一樓層專用作康樂用途，包括泳池、健身室、水療及桑拿、美容中心等
- 酒店已將全部客房翻新為智能客房，配有目前全港最完備的客房電訊設施
- 酒店亦設有兩個行政樓層及一個偌大的行政酒廊
- 酒店的實際平均房租超過 HK$2,500
- 平均入住率仍超過 90%
- 當中大部分入住的都是商務旅客

**A酒店的酒店評分：**

| 評分指標 | (1) 評分 | (2) 分數佔比重 | (3)=(1)×(2) 指標比重 |
|----------|----------|----------------|----------------------|
| **(A) 酒店設施** | | | |
| 飲食設備 | 8 | 0.09 | 0.72 |
| 電訊設備 | 4 | 0.05 | 0.20 |
| 商務設備 | 4 | 0.06 | 0.24 |
| 康樂及其他設施 | 6 | 0.05 | 0.30 |
| **(B) 酒店地點** | 5 | 0.20 | 1.00 |
| **(C) 職員與客房數目比例 (SRR)** | 3 | 0.20 | 0.60 |
| **(D) 酒店實際平均房租 (AARR)** | 3 | 0.20 | 0.60 |
| **(E) 商務組合 (BM)** | 2 | 0.15 | 0.30 |
| **總指標比重分數 = 酒店所得綜合分數** | | | **3.96** |

**結論：** A酒店綜合分數為 **3.96**，在香港的酒店評級制度中屬 **甲級高價酒店**。

### B. 中國國家旅遊局的五星評級制

- 中國國家旅遊局於 1993 年發佈
- 五星級評級制，星級越高，飯店檔次越高

**星級的劃分標準：**
- 飯店的建築裝潢
- 設備管理水平
- 管理水平

**評級權限：**
- 國家旅遊局專責評定全國的四、五星級飯店
- 各巿、自治區、直轄巿旅遊局則專責評定區內一、二、三星級飯店

---

### C. 美國福布斯旅遊指南

- 全球最悠久的評級制度
- 派出匿名調查員先為酒店環境、設施、服務作出評估
- 再按客觀準則例如設施、規模、職員與客房數目比例等對酒店作出評級
- 目的是要讓消費者在旅程中能根據評級，作出更好的選擇
- 評級每年更新兩次，列出包括五星級、四星級及列入推薦評級的酒店

## 15.5 特色酒店

### A. 精品酒店

- 主要針對高消費、注重住宿體驗和獨特風格的顧客群
- 以客房數目計精品酒店屬於小型酒店
- 房價一般都與高級酒店相若，甚至更高

**特色：**
- **規模**：精品酒店規模小，客房數目少
- **形象**：講求獨一無二
- **設計**：在裝飾布局、間隔、室內設計等都講求獨特、有品味及高檔
- **位置**：多坐落市中心或在走在潮流前端的城區
- **服務**：提供較高級酒店更細緻的個人化的服務
- **餐飲**：着重高質、時尚及提供本地特色的食品

---

#### 案例研究：查網站看酒店特色

石板街酒店是福布斯旅遊指南2020年版的推薦評級酒店。

**問題1：石板街酒店以甚麼特色作為推銷重點?**

**參考答案：**
- 歷史地標與時尚熱點的交滙，中西文化匯萃，加上懷舊色彩，展現香港的歷史與活力（A boutique beauty with Chinese charm）
- 經驗證的健康保障（Health security certified）

**問題2：從網頁資料所見，石板街酒店如何印證課文述及精品酒店的特色?**

**參考答案：**
- **規模**：客房數目少，只有68間
- **形象**：非常地道的香港形象，突顯中西文化交流、傳統與潮流並存的風味，又同時保留高檔酒店的格局
- **設計**：在裝飾布局、間隔、室內設計等非常切合形象
- **位置**：坐落在中環市中心新舊交替的地段
- **服務**：強調個人化的服務
- **餐飲**：有多間高級餐廳和咖啡店

---

#### 跨課題討論

**問題1：高恆的旅客分類模式共包括哪四類旅客?**

**參考答案：** 旅行團群體旅客／個別的群體旅客／探險式旅客／漫遊式遊客

**問題2：哪類旅客不會是精品酒店的主要目標客群? 為甚麼?**

**參考答案：** 漫遊式遊客：這類旅客着意體驗當地的生活，行程不定，不會花費較高的住宿成本體驗酒店的獨特風格

---

### B. 主題酒店

- 建築風格、室內裝飾和設施、員工的制服等採用一個連貫統一的概念
- 常見於主題公園和遊樂場的配套酒店
- 現時也有酒店專按特定的主題建造，給顧客一個獨特的文化氛圍

---

### C. 配合環境創造難忘特色

#### 1. 融入當地傳統生活的住宿

**例：日本白川鄉**
- 現為聯合國世界文化遺產，有「冬日的童話村」美譽
- 合掌房屋有近 300 年歷史

**例：教堂酒店（荷蘭）**
- 歐洲有不少古建築現在改建為高級酒店
- 前身是建於15世紀哥德式教堂，現在是擁有 60 間客房、配置現代化設施的高級酒店

**例：洞穴酒店（土耳其）**
- 在土耳其卡帕多奇亞地區
- 洞內冬暖夏涼

#### 2. 融入大自然的住宿

**例：冰酒店**
- 酒店每年要重建一次
- 每次的設計和布局都有不同

**例：樹酒店**
- 建在大樹上
- 可能只有三兩間客房，但有充足設施

**例：地底酒店**
- 上海佘山世茂洲際酒店由礦場修建而成
- 頂層在地面，最底兩層在地下湖位置

---

#### 討論：功夫酒店

有人提議在香港興建一間以中國功夫為主題的「功夫酒店」，你認為可行嗎? 為甚麼?

**思考角度：**
- 功夫酒店的主要顧客群應是甚麼?
- 可以讓客人有一獨特的旅遊體驗嗎?
- 如果你是設計師，你會如何令建築風格、室內裝飾和設施、員工的制服各方面均有一個連貫統一的概念?

**參考答案：**

**功夫酒店的主要顧客群（言之成理即可）：**
- 功夫電影愛好者
- 希望有獨特文化體驗的旅客
- 主要旅遊目的為消閒、度假、體育活動或探訪親友的旅客

**可以提供的獨特旅遊體驗（言之成理即可）：**
- 親歷香港經典功夫電影的片段或場景
- 功夫背後的文化意義
- 民初或古人生活的情懷
- 透過多媒體及高科技展現的功夫元素

**統一的酒店設計概念（言之成理即可）：**
- **建築風格**：武術門派或一代宗師的習武和起居地方
- **室內裝飾**：具功夫的意象，例如兵器、習武用品、以 LED 投射的深山靈雨蒼茫景色
- **員工制服**：習武服飾、武林高手的特別服飾

**可行性（言之成理即可）：**

| 可行 | 不可行 |
|------|--------|
| 有特色即能吸引旅客住宿，特別對消費力較高及響往東方文化的西方遊客 | 設計困難，投資龐大 |
| 香港沒有類似的酒店，容易建立形象 | 功夫熱潮不能長久，熱潮減退後即難以吸引旅客 |
| | 訪港旅客以內地客為主，沒有文化吸引力 |
