# 11 會議、獎勵、商務及展覽旅遊概況

- 現今旅遊與款待業增長最快範疇之一
- 全球旅遊目的地重點爭取業務
- 包括簡稱 MICE 的四類活動：
    - **M 會議 (Meeting)**
    - **I 獎勵 (Incentive)**
    - **C 大型會議 (Convention)**
    - **E 展覽 (Exhibition)**

2. 指出上述活動對香港旅遊業的三項好處。

    - 提高香港在國際企業中的知名度

## 商務旅遊
- 與工作相關的旅遊，包括工商業、學術等眾多領域
- 與以度假為主的各類閒暇旅遊有別

## 11.1 會議旅遊

### A 甚麼是會議?
- UNWTO/ICCA：會議 (meetings) 泛指十位或以上的參與者，聚集在一個指定的場地，共同進行一個最少四小時的活動
- MICE 活動範疇中的「會議」：企業會議，即由企業召開的各類會議

### B 會議的例子
1. **股東周年大會**
    - 上市公司必須每年定期召開股東會議
    - 跨國企業股東來自世界各地，加上需要接待傳媒，股東大會多會高級酒店或會議中心舉行
2. **員工大會**
    - 多由大企業主辦
    - 討論集團營運及策略、提昇士氣、凝聚向心力
3. **培訓研討會**
    - 管理人員及僱員培訓活動
    - 傳銷機構常會在酒店或會議中心主辦這類活動，讓新入職員工能認識企業文化、產品內容和傳銷方法
4. **產品發布會**
    - 企業推出新產品時，會舉辦發布會，廣邀分銷商、零售商、傳媒等出席
    - 例如：美國蘋果電腦公司每年數次的產品發布會，便是全球科技界焦點
5. **行政人員集思會**
    - 領導層暫時放下工作，在酒店或度假村共商發展大計
    - 加強管理層的聯繫

## 11.2 獎勵旅遊

### A 甚麼是獎勵旅遊?

#### 1 作用和特點
- 企業出資，獎賞出色員工作消閒旅遊的安排
- 行程安排跟消閒旅遊分別不大
- 屬商業管理手法，動機和旅程要求跟消閒旅遊不同
- 《中國旅遊百科全書》：獎勵旅遊是企業為提高員工的積極性、增強公司凝聚力而舉辦的免費旅遊
- 最重要的作用是激勵士氣，鼓勵員工為公司打拼好業績

#### MICE: 有別於 “MCE” 的 “I”
在四類 MICE 活動中，獎勵旅遊與會議、大型會議和展覽三類活動有一個重要的分別：
獎勵旅遊基本上以度假為主，工作成份低。相反，其餘三類活動主辦者或會加插各類消閒娛樂節目，但整體上都以商務活動或進修學習為主。

#### 特點：
- **群體獎賞**：多是群體獎賞，較少只給予個別員工
- **事前宣傳**：必須有成功的宣傳配合，讓有關員工知道「得獎」條件，各自努力爭取佳績
- **相關活動**：通常會有公司晚宴或聚會，公開表揚得獎的員工，向與會者發表鼓勵、振奮人心的講話
- **重視特色**：由於旅遊活動非常普及，除非行程安排很有特色，否則難以吸引員工
- **狂喜因素**：成功計劃會有最少一個與別不同、令員工非常重視的狂喜因素

#### 給顧客或商業夥伴的獎勵旅遊
- 用於公司員工，也用於顧客或商業夥伴
- **顧客**：提供給忠誠客戶及主要客戶，以酬答支持
- **商業夥伴**：提供給重要的供應商、批發商和分銷商等，因為公司需要跟供應商在生產上緊密協調和配合，也需要分銷商和批發商促銷產品

#### 2 跟員工旅遊的分別
- 獎勵旅遊不可跟員工旅遊混淆

| 比較項目 | 獎勵旅遊 | 員工旅遊 |
| :--- | :--- | :--- |
| **獎賞與聯誼** | 只有達至目標才能實現的獎勵計劃；並非任何同事都可享有 | 公司福利；所有同事都可以參加 |
| **費用來源** | 從增加的營業額或盈利撥出 | 屬於營運開支；與營業額關係不大 |
| **海外與本地** | 出境旅遊為主 | 本地消閒活動為主；出境旅遊較少 |

### 分辨「獎勵旅遊」和「員工旅遊」
試分辨以下的旅遊安排是「獎勵旅遊」或「員工旅遊」。為甚麼?

(a) MMM 食品公司每年都有一次大旅行，今年的節目是濕地公園一天遊，遊畢還有屏山盆菜宴，預計全部四百位員工大部分都會參加。
- **(a) 員工旅遊**：這是每年舉辦的員工活動，沒附帶獎勵計劃

(b) XYZ 科技公司的人事部接到指示，今年因業務不景，人事部各項支出都要減少，包括把員工福利項目下的旅遊開支減少三成。所以今年辦的旅遊，員工都不可以携眷，同時明年會停辦一年。
- **(b) 員工旅遊**：這是人事部所辦的員工活動，是一項員工福利

(c) ABC 餐飲集團根據營業額及客戶滿意度調查等多項指標，每年選出最佳大廚，得獎者可到法國參加一個為期七天的「美芝蓮美食團」，品嚐多位法國美芝蓮星級大廚的巧手菜式，全部費用由集團支付。

## A 甚麼是獎勵旅遊?

### 3 ㇐般獎勵旅遊與高端獎勵旅遊
- 獎勵旅遊可分為㇐般獎勵旅遊與高端獎勵旅遊兩類
- 後者是給予少數高級行政人員或大客戶
- 他們的旅遊經驗與閱歷豐富、影響力重大，有關的獎勵必須極昂貴或特別

### ㇐般獎勵旅遊
1. ㇐個令人興奮的旅遊目的地
2. 四至五星級的服務
3. 對於出資的企業而言，花費要物有所值
4. 旅遊目的地要安全、語言溝通便利
5. 旅程包括豐富的室內和室外的活動

### 高端獎勵旅遊
1. 要有富創意的活動安排；不㇐定是最奢華
2. 六星級的服務
3. 配合企業文化
4. 但要最為難忘，其他員工不可能有的特別經歷(例如與行業名人會面，參觀禁地等)

## 獎勵旅遊較現金獎賞優勝地方
- 宣傳效力：獎勵旅遊較易成為公司熱話，但現金獎賞多被視為佣金，議題不多
- 鼓勵作用：員工收取現金獎勵後多不會張揚，但對獎勵旅程卻會津津樂道，有助刺激其他員工發奮努力，有助提高生產力和士氣
- 人際網絡：結伴同遊能建立更佳人際網絡，對公司與員工均有好處
- 公司文化：高層可灌輸公司價值觀，勉勵員工

## 獎勵旅遊的宣傳效用
- 對企業本身有公關宣傳效果
- 經傳媒報導後，企業的國際知名度提高

## 為甚麼獎勵旅遊消費較㇐般消閒旅遊消費高?
- 獎勵旅遊利用物質與精神滿足激勵士氣，因此食宿和行程安排都要較好的，整體消費較高
- 企業付費，旅客不用自掏腰包，個人消費或較濶綽
- 並非全是消閒性質，旅程中會加插工作會議、晚宴等，為旅遊目的地帶來更多消費
- 常需要旅行團經營商代為安排，增加了供應商的營業額

## B 獎勵旅遊選擇旅遊目的地

### 1 有關企業與參加者的考慮
- 員工安全：
    - 安全的旅遊目的地
    - 安全的食宿和行程
- 整體費用：旅遊目的地的物價水平、匯率波動等均會影響活動的成本
- 當地經濟狀況：在經濟暢旺時，眾多企業對人才需求殷切，商機處處，企業為配合發展，會較樂意提供獎勵旅遊。

### 2 有關旅遊目的地方面的考慮
- 旅遊目的地的購買力：到貨幣匯率較低的旅遊目的地，因物價相對本地低，獎勵旅遊費用較低
- 政治考慮：避免選擇政局動盪或社會氣氛不友善的國家地區
- 公共設施及服務品質：機場、道路狀況、交通運輸設施、餐廳、當地環境衛生、旅館設備及服務水準
- 氣候：當地氣候會否影響行程安排

### 2 有關旅遊目的地方面的考慮 (續)
- 口碑：過去同類旅遊活動所給予的評價
- 當地形象及宣傳
- 當地的旅遊供應商﹕服務和數量
- 獨特旅遊體驗：目的地必須具備吸引力，或帶來獨特經歷，才能令獎勵旅遊更有意義
- 節慶和活動﹕行程能否配合當地的節慶、盛事

# 11.3 大型會議

## A 大型會議的特色
- ㇐般由專業組織、社團、慈善、宗教或政治團體等主辦
- ICCA：
    - 每年全球舉辦的各種國際會議超過四十萬
    - 總開銷近三千億美元
- 會議市場的巨大潛力和高回報
    - 吸引很多旅遊目的地用作發展重心
- 日程：㇐連數天。與會者會順道觀光或作其他商務活動，故此逗留時間較⾧
- 人數：眾多，可能以千萬計，以入境旅客為主
- 會議形式：全體會議、小組會議、開幕或閉幕儀式、聚餐，同期或有配合主題的展覽同時舉行
- 觀光：與會者多會趁機會觀光或進行商務活動，因此主辦者會考慮會議城市的旅遊吸引力
- 吸引力：由與會者自費，主辦單位非常着重會議的吸引力
- 舉辦時間：較多在旅遊淡季舉行，節省成本

## B 大型會議的種類

### 1 代表大會 (Congress/ Convention)
- ㇐般會為期數天，其中包括全體會議與多個小組會議
- 團體的會員聚首㇐堂討論㇐個配合團體主旨的特定主題
- 通常有重要的講者增強叫座力
- 同時安排多類活動，包括團體執事會議﹑聚餐及雞尾酒會等社交項目﹑有關會務的會議以至講座等
- 通常定期進行，如每年或每兩年㇐次

### 2 研討會 (Conference)
- 為期較代表大會短；
- 通常有特定的主題；
- 目的主要為商討解決問題、諮詢、交流和答問；
- ㇐般是按需要進行，並非定期舉行；
- 出席人數也較代表大會少

### 3 專題研討會 (Symposium)
- 專業人士就特定課題進行研討
- 包括宣講論文或發表意見﹑討論及研討會
- 完結時由主持人作結論或發表聲明

### 4 講座、論壇 (Forum)
- 講者受邀請就主題發表演講
- 全程有講座主持人負責
- 觀眾可以在答問時間發問

## MICE舉辦地點
大部分MICE都集中在會議展覽中心、酒店、各類學校及社區會堂舉行，但也有在郵輪、博物館甚至主題公園等文化娛樂場所舉行。

這些「另類」舉辦地點有時能給予與會者不少驚喜，帶來新鮮感。事實上郵輪、博物館和主題公園也努力爭取MICE業務，帶來可觀收入。

## B 大型會議的種類（效益與規模）
- 大型會議出席者人數眾多
- 各項消費 (包括餐飲、住宿、交通、會議場地等) 支出巨大
- 觀光、購物、娛樂及商務活動等
- 能為旅遊目的地帶來巨額收益

## 大型會議例子
- 行業會議：業界討論共同利益，分享最新資訊及市場發展等
- 學術會議：學者發表研究報告，㇐般在大學校園舉行，學者也多住在大學宿舍，對酒店及商務會議設施需求不大
- 醫學會議：讓相關領域的醫學界人士分享最新的知識、科研成果及醫療器材和藥物等

## 比較會議與大型會議

| 有關活動資料 | 大型會議 |
| :--- | :--- |
| 聯絡人 | 較公開，可透過主辦團體取得 |
| 籌備需時 | 通常有籌備委員會 |
| 形式 | 較⾧，可能需三數年 |
| 出席者 | 有固定形式，㇐般參照過往形式進行 |
| 費用 | 較自由，會員報名參加 |
| 選址 | 由與會者負責 |

## 3 香港在大型會議方面的優勢
- **四通八達連繫全球**：亞太區交通樞紐，航空與連接內地的水陸交通非常完善，全球半數人口僅需五小時便可飛抵香港。

- **經驗豐富**：舉辦國際會議的經驗豐富，擁有高水平的專業團隊。
- **旅遊城市**：美食之都、購物天堂、文化及歷史景點。

# 11.4 展覽

## A 甚麼是展覽?
- MICE 四類活動中最大型的。
- 屬於商業活動。
- 有別於博物館或藝術中心舉行的文化展覽。

### 1 特點
- 或稱為展覽會 (Exhibition)、商品交易會 (Trade Fair)、博覽會 (Expo) 等。
- 主要分為針對大眾消費者與針對業界兩大類。

#### (1) 性質比較
- **針對大眾消費者（消費展覽會）**：例如香港書展。
- **針對業界（商貿展覽會）**：包括出口貿易展、進口貿易展、地區貿易展及全球貿易展等不同性質，例如香港電子產品展。

#### (2) 入場對象比較
- **針對大眾消費者（香港書展）**：
    - 本地市民為主。
    - 人數較多，例如 2015 年「香港書展」有接近一百萬入場人次。
- **針對業界（香港電子產品展）**：
    - 世界各地機構買家。
    - 人數較少，大多只供業內人士參觀。

#### (3) 銷售方式比較
- **針對大眾消費者**：
    - 參展商展示商品。
    - 即場售賣，交易即場完成。
- **針對業界**：
    - 參展商展示樣品及介紹資料。
    - 買賣雙方需要再作洽談，展覽結束後才能完成交易。

#### (4) 攤位設計需要比較
- **針對大眾消費者**：
    - 方便售賣。
    - 展銷櫃枱靠近人流通道，方便消費者觀看比較。
    - 銷售人員在櫃枱後做推銷及售賣。
- **針對業界**：
    - 方便洽談。
    - 場館位會設有小枱方便買家與參展商洽談。
    - 較少現場發售。

#### (5) 相關活動比較
- **針對大眾消費者**：
    - 增加活動氣氛的相關活動配合。
    - 如香港書展期間會有文化研討會。
- **針對業界**：
    - (未特別註明)

---

- 同期可能會有會議﹑研討會或其他配合活動
- 主要目的讓參加者交流業內最新發展和市場資訊

# A 甚麼是展覽?
- 展覽同時包括業界與消費者兩部分
- 例如：德國法蘭克福書展
    - 全球最大的印刷與電子書業交易會
    - 參展商超過七千
    - 出席者來自全球各地
    - 展期頭三天只限業界參觀，最後兩天開放予大眾消費者

### 觀察以下兩張照片，指出照片攝自針對大眾消費者或針對業界的展覽。試解釋你的答案。
- **針對大眾消費者的展覽**：照片中攤位向外，職員在書攤後方便銷售，另圖中可見參觀者大多穿便服。
- **針對業界的展覽**：照片可見現場設施以方便討論為主，人數較少，同時都穿上班服。

### 展覽對旅遊業的重要性
香港書展的入場人數遠較香港珠寶首飾展覽會多。從旅遊業界的角度，哪個展覽更為重要? 為甚麼?
- **香港珠寶首飾展覽會**：與會者與參展商很多都來自海外，在交通、食宿等各方面的旅遊支出都較香港書展多。而且平均個人消費也會較香港書展的多。
- 此外，香港書展的參展商與入場者大多為本地人，外地遊客也以不過夜旅客為主，整體旅遊支出不高。

# EXPO 何解?
- Exposition 的簡稱，中文多用「博覽」
- 如香港的 Asia World Expo，中文為亞洲國際博覽館
- 商業性質的「博覽」有眾多展銷商在同㇐場地向入場人士展示他們的產品和服務，其本質就是㇐個商品交易會
- 很多商品交易會也以 ”EXPO” 或「博覽」命名

# B 展覽對參展商的優缺點

## 1 優點
- **有效接觸顧客**：大多對產品與服務有興趣，潛力也最大
- **省時**：同㇐時間向大批目標顧客展銷，不用逐㇐推銷
- **市場資訊密集**：同㇐場合可見到同業產品，藉機了解對手的最新情況
- **建立關係**：企業可藉機跟同業及潛在顧客建立關係
- **建立形象**：建造令人難忘的區館，把競爭對手比下去，增加顧客信心

## 2 缺點
- **工作量大**：需要大量籌備工作，要派駐優秀的營銷人員，展覽後又有大批跟進工作等；
- **花費大**：派駐工作人員、租用場館、製作吸引的攤位等均花費巨大
- **保密性低**：由於有大批同業同時參展，有關的營銷策略便容易暴露，對日後市務工作帶來困難

# 香港舉辦展覽的特色
- 大多為消費服務與產品，例如電子、時裝、珠寶、玩具、禮品、鐘錶及燈飾等
- 較少工業生產器材與應用科技器材的博覽會與展銷展
- 原因包括香港缺乏本地買家及生產商，有興趣的都以海外買家及海外生產商為主
- 而且香港展覽場地小，難以擺放大型的機械。

# 規模越大越成功
- 潛在買家越多、規模越大，越能吸引企業參展商
- 如果入場觀眾知道有大批參展商參展，入場意欲也較高
- 展覽模式趨向更大規模、大量觀眾
- 主辦單位常會在期間加插各類可以增加吸引力的節目

# 11.5 會議、獎勵、商務、展覽活動的價值
- 旅遊業重要部分
- 很多亞洲國家地區積極增加相關的設施
- 由公營機構帶動，配合本地特色爭奪市場

## A MICE 對旅遊業界的價值

1. **高消費客群**
    - 多為企業的中高層或專業人士
    - 對旅遊服務要求高
    - 有較高消費能力
    - 香港旅遊發展局的統計數字：2004 至 2014 年間過夜商務旅客的人均消費較過夜非的人均消費高 20% - 45% 不等

2. **增加旅遊淡季收入**
    - MICE 按各行業情況在全年不同時段舉行
    - 有助增加旅遊淡季的收入
    - 幫助減少酒店業淡季的房間空置率

3. **需求穩定及可預計性高**
    - 不少 MICE 活動固定於每年某時段進行
    - 籌備工作多沿用舊年方式
    - 旅遊供應商可提前作準備，減低風險

4. **規模大**
    - MICE 活動參加人數眾多
    - 單㇐活動已可創造大量住宿﹑餐飲﹑展覽和會議空間的需求
    - 是很理想的客源

5. **可提供標準化服務**
    - 與會者有相近的旅遊目的與需求
    - 旅遊供應商可以利用標準化的程序處理

6. **惠及多個行業**
    - 籌辦 MICE 活動需要很多各類的服務
    - 除了旅遊業界，也需要攤位布置﹑娛樂﹑公共關係等

## B MICE 對旅遊目的地的價值

1. **提升目的地國際形象**
    - 藉 MICE 活動接待更多海外旅客
    - 舉辦大型展覽和會議，通過傳媒報導，有助提升國際形象

2. **帶來㇐連串經濟收益**
    - 參展商各類支出帶來直接經濟收益
    - 收益再經倍數效帶來更多經濟收益
    - 推動其他行業發展
    - 增加就業

3. **有助本地企業建立商業網絡**
    - 出席的行業精英或企業高層可能為東道國帶來更多 MICE 以外的商機和投資機會
    - 本地產品與服務對外宣傳的機會

4. **有助引進知識，提供學習的機會**
    - 業界最優秀的人員為本地業界帶來更多知識和學習的機會
    - 對提高本地產業水平有正面的推動作用

5. **毋懼景點不足的缺點**
    - 旅客並非為遊覽景點而來，景點不足的旅遊目的地也可藉 MICE 發展旅遊業
    - 只要有所需的設施、服務良好、交通方便等，便可競爭
