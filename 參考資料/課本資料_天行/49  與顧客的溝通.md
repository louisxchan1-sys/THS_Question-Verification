# 49 與顧客的溝通

## 甚麼是溝通？

溝通簡單來說是一方發出信息，另一方接受的過程。作為服務性行業，與顧客進行有效的溝通是工作非常重要的部分。

## 49.1 概說溝通

### A 噪音的種類
這裏的「噪音」專指干擾信息溝通的各種因素。「噪音」大致可分為三種：
1. 環境噪音
2. 生理噪音
3. 心理噪音

- **1 環境噪音**：任何傳收信息的兩方以外的干擾，影響信息的收發。
- **2 生理噪音**：傳收信息兩方本人的問題，導致兩人不能良好地傳收信息。
- **3 心理噪音**：各種情緒上的問題，例如因怒火中燒或備受感情或經濟困擾，不能有條理地發出或明白信息。雙方的文化、價值觀等差異也可以造成噪音，令溝通出現困難。（例如：「東方人就是不明白！唉！」「有些西方文化很奇怪！唉！」）

### B 回饋的重要性
- 在溝通過程中，回饋非常重要。例如兩人交談時，如果聽者毫無表情、不發一言，說話一方可能便會不知所措，或索性不再說下去了。（例如：「有點反應可以嗎！你是不是凍傻了！唉！」）
- 可見作為客戶服務員工，我們與顧客溝通時，必須留意過程中噪音與回饋等各種可以影響溝通的元素。
- 與顧客的溝通主要有三個途徑：書面溝通、口頭溝通、非口頭溝通（Thank you！）。

### 三類噪音（練習與參考答案）
為甚麼出現溝通錯誤? 試根據三種噪音解釋。

**參考答案：**
- **環境噪音**﹕知客身旁有太多聲音干擾，加上她戴着耳機和口罩，說話和接數信息都有影響；客人帶着助聽器和口罩，距離知客較遠，聽和說不清楚。
- **生理噪音**﹕客人有弱聽問題。
- **心理噪音**﹕知客同時處理客人太多，有分心。

## 49.2 書面溝通

所有重要的協議、紀錄，以至宣傳或通知，均大多以傳統印刷或電子媒介方式分發。

### A 書面溝通的一般要求：準確
- 書面溝通材料，在內容詳略及表達方式上會有分別，例如海報要簡約又吸引；公函內容要完備、行文恰當等。它們都有最重要又相同的要求：準確。
- **準確有多個意義：**
    - 語文要準確，不可有錯別字、詞不達意，以免引起誤解。
    - 內容上要準確。
    - 格式要合度。
    - （例如：張經理，你的辭職信生效日期是 2223年 1月 1 日，不必現在就通知我。）
- 錯誤會令顧客對公司留下不夠專業、管理差勁、員工質素低下等負面印象。一些錯誤更會導致公司負上嚴重損失。

### B 常見的書面溝通方式

1. **公函**
    - 公函就是公司發出的官方文件，例如公司與顧客的協議、銷售安排等。
    - 公函可以是單一式，即給予個別顧客的；也可以是標準式，即同時發給多個顧客的。
    - 所有書面溝通方式中，以公函的格式和要求最為嚴謹和正規。
    - 要使用印有公司標誌、名稱、通訊地址電話、網址等資料的公司信紙。
    - 旅遊業機構的公函必須附上其註冊編號。

2. **便條**
    - 只用於溝通簡單的內容，不可用於傳遞重要信息。
    - 便條的格式和設計與公函大致相同，只是便條大多面積較信紙小，上面加印一些預設的簡單信息。

3. **名片**
    - 印有公司和員工的資料，方便顧客隨時聯絡。
    - 一般除公司標誌、名稱、通訊地址電話、網址等的公司資料，還會印上個別員工的姓名、職銜、聯絡電話及電郵地址等。
    - 個別公司還會加上有助建立形象和拓展業務的簡單信息，例如服務承諾、公司業務或聯營公司名單，或員工的照片等。

4. **小冊子或產品目錄**
    - 不少旅行社或餐飲機構均會把產品與服務製成單張或小冊子，放於互聯網或製成印刷品供顧客索閱。
    - 由於費用不高，加上能向大批潛在顧客推銷，這些都是常用的宣傳媒介。

5. **海報**
    - 海報提供高度概括的產品與服務信息，張貼於潛在顧客常到地方以提醒顧客。
    - 一般內容較小冊子少，只保留最重要的信息，但設計需要吸引顧客注意力。

6. **各類通告**
    - 主要提供有關機構的營運資料，例如時間表、開放時間、設施位置地圖、門票售賣情況等。
    - 內容要非常清楚簡潔，讓人一目了然。

現時各類書面通信大多可改用電子檔案發放，即使由印刷媒體變成電子媒體，但原則是一樣的。

### C 使用電子媒體的書面溝通
- 現時不少公司與顧客間的書信往來，大部分會用電子郵件，甚至短信、WhatsApp 等形式進行，宣傳品及確認信等也可以用各種電子媒體發出。
- **易於出錯要小心**：大部分前述的書面溝通的要求在電子媒體也通用。我們要留意由於電子媒體非常方便，使用時大意出錯的機會卻更多，因此不要掉以輕心。

## 49.3 口頭溝通

口頭溝通包括：
- 員工直接與顧客對話
- 透過電話及各種用話音通信的社交媒體的溝通

### A 口頭溝通的優缺點
1. **優點**
- 容許雙方即時回饋，更容易進行討論，互相了解。

---

- 較書寫快捷方便，特別對不擅長以文字交流的顧客和員工，口頭溝通更適合
- 如果是面對面的溝通，可同時配合非口頭溝通，會更有效果

# A 口頭溝通的優缺點

## 2 缺點
- 口頭溝通不同書面溝通，較難修飾用詞或深思熟慮才落筆，需要頭腦靈活，能隨機應變
- 不適宜用於需要書面確認的內容，例如合作條款及確認信

# B 一般要注意的地方
與顧客溝通時，「說甚麼」與「怎樣」說同樣重要。不論是面談或是通電話，我們都應該：
1. 語速不要太快或太慢
2. 用字準確，不要用專業術語、對方不明白的字詞或語言、或不恰當的俚語俗語
3. 留意聲線和音高，如果說話太大聲或聲音過於尖銳，對方會感到受壓迫和不自然。聲線太弱和說話太低沉，對方聽不清楚，也會感覺你說話帶隱瞞
4. 準確回答問題，不要轉移話題，混淆視聽
5. 語氣上讓對方感到放鬆，有信心說出要說的話

# 第一印象有多重要?
在服務的過程中，顧客往往會視負責員工為公司的代表。客人對這位員工的印象很重要，因為這往往成為顧客日後對公司的印象。

不少研究指出顧客對公司的第一印象特別深刻，即使他們日後滿意公司的產品和服務，負面的第一印象還會長時間影響顧客對公司的信心。

所以員工與顧客的第一次接觸非常重要，所以我們與顧客溝通時必需留意。

# C 聆聽的技巧
無論是跟顧客面談或是通電話，公司的員工能夠專注聆聽是十分重要的。注意以下聆聽的技巧：
1. 留心別人說話的內容
2. 不要分散注意力，邊談話邊處理其他事情，只專注地與對方交談
   （不好意思，後面好像有人談及一些新藥。妳剛才說妳有病嗎？）
3. 看着對方，並以點頭或微笑給對方肯定的態度
4. 對方說話時，小心別打斷對方的說話
5. 有需要時可用筆記下內容及自己要補充的部分

# D 提問的技巧
提問時要注意：
1. 適當時機：在適當時提出問題，不要打斷對方說話
2. 相關內容：不要另開話題或問毫無關連的事情
3. 提問清楚：要對方明白所問
4. 小心語調：用錯語調會令人誤會，對方可能以為你語帶嘲諷、懷疑或壓迫
5. 別重覆問題：不要重覆問別人已提出過的問 題，或顧客已解釋過的內容

## 開放式與封閉式問題
封閉式問題的答案只有「是」或「否」、「有」或「無」等。開放式問題讓對方可以有不同的答案方式，顧客也有較正面的回應。常用的開放式問題以六個W開始，即：
- 何時(When)
- 何地(Where)
- 何人(Who)
- 甚麼(What)
- 為甚麼(Why)
- 怎樣(How)

例如「我可以怎樣幫你?」、「您們打算甚麼時候出發?」等。
