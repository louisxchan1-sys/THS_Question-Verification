## 18.1 酒店的產權、經營權和營運方式

### A 產權及經營權
- 產權是指資產擁有權
- 酒店的產權由酒店股東所有
- My Hotel!
- 經營權是指管理及經營一家企業的權力

#### 1. 產權
- 股東可以是獨立一人、若干合夥人、或一家甚至多家企業
- 酒店可以是上市公司，任何人均可從股票市場購買該酒店的股票成為股東
- 股東決定酒店的經營方式，能分享酒店的盈利，亦須承擔虧損

#### 2. 經營權
- 酒店由股東自行管理︰股東同時擁有酒店的產權和經營權
- 股東授權專業人士或管理公司管理︰股東不參與日常業務，產權和經營權分別由股東和管理人擁有

### B 酒店的營運方式

| | 獨立酒店 | 本地集團酒店 | 國際集團酒店 |
| :--- | :--- | :--- | :--- |
| **酒店數目** | 一家 | 兩家或以上 | 兩家或以上 |
| **業務範圍** | 本地 | 本地 | 跨國 |
| **香港酒店例子** | 恒豐酒店 | 香港信和酒店集團 | 萬豪酒店、香格里拉酒店 |
| **擁有者** | 本地私人投資者 | 本地私人投資者及/或上市公司 | 跨國集團及/或上市公司 |

## 18.2 酒店的管理模式

### A 獨立擁有及經營

**獨立酒店的好處和壞處︰**

| | 好處 | 壞處 |
| :--- | :--- | :--- |
| **擁有人** | - 能全權決定營運方針及發展策略，有較大自主性<br>- 不用支付特許經營權費、管理合同費等，完全自負盈虧 | - 東主未必具備現代酒店管理的專業知識，或會影響經營效率及競爭力 |
| **酒店** | - 可以迅速因應市場變化及成本收益等因素調整經營策略，在營運上有較大的彈性 | - 集資能力較低，業績欠佳時較難籌措資金，有商機時又或因資金不足難以擴張<br>- 難以達到規模經濟效益，也難透過酒店集團網絡提高知名度，增加客源以達致成本效益 |

### B 管理合約

**酒店產權擁有人與酒店管理公司的權責︰**

| 酒店產權擁有人權責 | 酒店管理公司權責 |
| :--- | :--- |
| - 提供土地、酒店物業及營運資金<br>- 不會介入公司日常的業務運作<br>- 酒店的盈利虧損由擁有人承擔 | - 運用專業知識技能提供管理服務<br>- 全權代表酒店產權擁有人負責日常的業務運作<br>- 收取酬金或花紅 |

**管理合約模式的好處和壞處：**

| | 好處 | 壞處 |
| :--- | :--- | :--- |
| **酒店擁有人方面** | - 資金：只需投入資金，不必參與日常營運<br>- 風險：由專業人士管理，失敗風險較低<br>- 知名度：能提升擁有者地位及知名度，對其他業務有幫助 | - 管理費：投資者需花上大筆管理費用聘請管理公司，利潤會被攤薄<br>- 責任承擔：沒有直接參與酒店的營運但卻要承擔業務虧損的責任<br>- 倚賴性：過分依賴管理公司，如果管理合同一旦中斷，酒店便會遇上營運困難 |
| **酒店管理公司方面** | - 資金：酒店集團無需動用大筆資本興建酒店及承擔財務風險，便能把業務在全球各地擴展<br>- 收入：收益較穩定，無論酒店業績如何，管理公司都可收取管理費 | - 分享利潤：全權負責營運但只能分享部分利潤，若合約訂明只收取定額管理費，管理公司所得與業績無關，士氣更低<br>- 股權控制：大部分情況下並不持有酒店股份，若股東資金或產權轉讓出現不利自己的情況，管理公司非常被動 |
| **酒店業務方面** | - 管理質素：由專業人士管理，能提升管理質素<br>- 營運支援：得到酒店集團的強大支援<br>- 營運成本及效益：透過跟集團內其他酒店合作，在宣傳、採購、人事管理等各方面均有更好營運效益，有助降低成本<br>- 品牌建立：作為酒店集團一份子，酒店可以迅速建立品牌，省卻樹立新品牌的漫長過程 | - 關注目標：管理合約經營模式隱含投資者與管理者的利益衝突，前者重視酒店的盈利與收益，後者重視管理權力、酬金及其集團的聲譽。由於雙方關注重點有所不同，如果在經營方針上產生糾紛，會直接影響酒店營運。 |

#### 管理公司與擁有人的收入
- 酒店管理公司派註在酒店的工作人員薪金和各類相關津貼和開支等，都屬於酒店本身的營運開支；
- 酒店管理公司收取的費用主要有兩項﹕根據營業額一個比例的基本管理費，及按照協定的標準 (例如利潤) 的獎勵管理費；
- 扣取支出及支付管理公司的費用後，利潤由擁有人支配，例如可以提取或留在酒店賬內作為儲備；
- 如果酒店入不敷支，擁有人需要依合約注資入酒店應付營運需要。

### C 特許經營
- 指大型連鎖酒店集團把「特許經營權」售予有興趣的投資者，讓其成立使用集團品牌經營酒店
- 投資者需要先支付一筆申請費用予集團
- 特許經營酒店每年要向酒店集團支付特許權費、市場推廣費及訂房系統行政費等
- 特許經營酒店要按規定使用集團品牌名稱和經營模式、使用指定的採購網絡、質量控制準則及營運系統等
- 集團對特許經營酒店有一定的控制權，但管理權與產權基本上仍屬於加盟的投資者

# 世界知名酒店集團

現今世界知名的酒店集團包括有美國萬豪集團、洲際酒店集團、希爾頓酒店公司等。

美國萬豪集團是全球最大的酒店集團，旗下品牌包括喜達屋 (Starwood), 萬豪國際 (JW Marriott), 麗思卡爾頓 (Ritz-Carlton), 喜來登 (Sheraton) 和威斯汀 (Westin) 等，管理多達 110 萬間客房。

洲際酒店集團品牌包括洲際 (Intercontinental)、假日酒店 (Holiday Inn)、皇冠假日 (Crowne Plaza)、英迪格 (Indigo) 等，管理近 5400 家酒店和 80 萬間客房。

這些酒店集團名下的酒店有些是由集團直接經營，也有部分是特許經營及管理模式經營，由於運作上相同，外人一般不易分辨。

## C 特許經營

特許經營模式的好處和壞處︰

### 加盟的特許經營者方面
**好處：**
- 縮短開業成長期：參照酒店集團的專業營運標準開業，縮短創業初期的學習及投入
- 掌控制權：擁有者能保留對酒店的控制權，掌握營運及利潤。

**壞處：**
- 被動：成員酒店處於被動狀態，有被終止合約的風險
- 龐大固定支出：無論盈虧情況如何，都需要繳交加盟費及年費

### 擁有特許經營的酒店集團方面
**好處：**
- 收入穩定：獲得穩定的特許經營權費
- 風險較低：無需負擔成員酒店的開支
- 擴展迅速：能較快地擴展集團的業務
- 提升知名度：一步提升品牌的知名度

**壞處：**
- 收益有限：只向成員酒店收取一定的特許權費

### 擁有特許經營的酒店集團方面 (續)
**好處：**
- 擴展迅速：能較快地擴展集團的業務
- 提升知名度：一步提升品牌的知名度

**壞處：**
- 品質管理較差：難以保證成員酒店能否按照合約規定提供服務，及確保其品牌在市場上的質素及形象

### 酒店業務方面
**好處：**
- 利用已有商譽：使用酒店已有商標、品牌和商譽，省卻逐步建立商譽的漫長歷程
- 有強大支援：有集團的專業知識、營運系統和諮詢服務
- 成本效益較高：減少營運上的錯誤，加上集團採購，成本較低
- 成本分擔：酒店可跟其他成員共同分擔推銷及其他費用，成本因而較低
- 較能保證入住率：加盟後即享有國際知名度，加上利用集團的國際訂位系統容易接受訂房

**壞處：**
- 難以創新：依既定的運作模式營業，缺乏經營的獨立性
- 難以建立新品牌：加盟成員不可以自行建立另一品牌

### 酒店業務方面 (續)
**好處：**
- 成本效益較高：減少營運上的錯誤，加上集團採購，成本較低
- 成本分擔：酒店可跟其他成員共同分擔推銷及其他費用，成本因而較低
- 較能保證入住率：加盟後即享有國際知名度，加上利用集團的國際訂位系統容易接受訂房
