驗證文件：$ARGUMENTS

按 `AGENTS.md`「單份驗證流程」第 1–5 步執行，不可省略：

1. 讀標準：`驗證流程/驗證清單.md`、對應題型 `考評標準/XX_出題規格.md`（含難度錨點）、`考評標準/評分準則撰寫標準.md`、`考評標準/範本對照表.md`，**另讀 `進化/經驗庫.md` 的「現行待觀察模式」**，驗證時逐條留意。
2. 讀待驗文件全文（docx 用 python-docx／pandoc 轉文字，逐格讀表格）。
3. 六維對照（A–F），知識回查 `參考資料/課本資料/`，難度對照 `參考資料/公開試/` 最新三年＋`04_選擇題答案/`（MC 逐題答對率）＋`07_考生表現/`（表現評語）。
4. 按 `驗證流程/驗證報告範本.md` 寫報告，命名與存放按 `驗證報告/說明.md`。
5. 用戶要求時產出修訂版 docx（原檔不動），逐題核對答案總表與題解。
6. **進化步驟**：按 `進化/進化守則.md` §二 執行（更新經驗庫 → 判斷是否達觸發門檻 → 自動修訂規則 → 寫 CHANGELOG → 獨立 commit 並 push）。

最後向用戶簡報：總評、首要問題、本次經驗庫／規則有何變動。
